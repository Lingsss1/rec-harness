## 真实 Amazon NextItNet 自动研究

同一 `autoresearch` 进程自动推进两轮、达到冻结轮次上限后停止。该 campaign 共 11 次真实 Codex 调用，包含两次对照 ID 字段自动修复；没有手动传递阶段结果或启动第二轮。

| 轮次 | 候选 | 结果 |
|---|---|---|
| 1 | 按通道学习的残差门控 | 四品类均完成训练；HR@10 宏平均 0.5545，对 incumbent 增加 0.001，未过 0.005 门槛；自动丢弃并完成六角色及知识归档 |
| 2 | 零初始化残差读出映射 | 训练后尾部表示读出契约失败，四品类全部无效；保留失败与费用，拒绝进入选模 |

第一轮四个 checkpoint 的独立 CPU 复评分均为 0 个排名差异、0 个并列正样本。没有释放确认训练或访问最终测试；incumbent 保持不变。

本次八个 GPU 作业合计 2205.929828 GPU 秒（含第二轮无效实验）。继承历史成本后的 study 累计 12250.595499 / 18400 GPU 秒，剩余 6149.404501。停止后重新执行入口，报告、事件头与费用完全一致。核验 9 份被接受的角色输出和 34 个周期归档产物通过。

第二轮暴露了零初始化掩盖契约错误的问题：初始化时附加映射为零，因此初始 CPU 检查通过，参数学习后才出现不一致。已新增训练前的隔离 CPU 梯度压力检查，并在角色上下文中明确 `encode_sequence`、训练打分和候选打分的一致性要求。用同三份真实源码重新验证：incumbent 与第一轮候选通过，第二轮候选在 CPU 中即被拒绝；额外 GPU 消耗为 0。另有回归测试覆盖仅训练 forward 改变而候选打分未变的情况。

该结果证明自动执行、决策拒绝、失败保留及预算停止路径可运行，不证明这两项改造提高了 NextItNet，也不代表完整方案中的工具/Harness 在线自进化已完成。

预声明测量覆盖要求的控制器验收：缺失输出时只调用 evidence、不启动候选训练，生成 MeasurementGap 与 BLOCKS 关系并可精确恢复；工具执行失败不生成能力不足结论；测量存在时正常完成模型研究。工具开发交接固定触发时图版本，在随后添加未来事件后交接上下文仍完全一致。这些是控制流与信息边界测试，不是诊断工具在线收益验收。

### 结论升级的来源训练独立性

`Store._claim` 对 supported/confirmed_in_scope 的成对证据递归核对 `source_experiment_ids`。两份汇总的底层训练身份必须不相交；重新命名、嵌套汇总或改变比较标识不会增加独立训练数量。显式开发分区、非独立来源、缺失来源、环和无来源的 derived 记录不能支持升级。confirmed_in_scope 还要求有效独立证据对包含机制对照。旧未声明分区的本地记录保留原兼容口径，不能据此声称其分区已验证。

`evidence_dependency_ids` 只表示回放可用性，不能用来推断训练独立性：同一研究 attempt 中的不同 seed 仍可独立。来源训练的 task 可以是类别任务，汇总 task 可以是配对比较，但协议必须一致。

全套回归 372 项，352 通过、20 项环境相关跳过；随后新增的成对比较生产器→图升级集成测试与该文件另两项测试均通过。覆盖不同确认 seed 的合法汇总、重复分析拒绝、重标开发来源拒绝和重叠机制对照拒绝。没有新增 Codex、训练、推理或真实科学结论升级。该检查验证已声明来源，不能证明遗漏或伪造来源不存在。

### 后继模型的旧缺口适用性复查

### 实现作者检查与限制交接

### 传输故障停止整个研究流程

发现并修复多轮调度缺口：单个角色拒绝自动重试传输故障，但原控制器仍可能在失败后开始新轮次。现在 RoleTransportFailure 会提交 role_transport 失败并使 campaign 停在 role_transport_failure，重复恢复无新调用。已授权的显式预准入重开绑定失败文件后归档该角色，保留成功角色及历史成本；新旧传输收据均可识别，成功接受的角色不被归档。准入后仍沿既有独立评审恢复入口处理。

ResearchProject 在同一模型阶段保留未完成状态，记录幂等的子传输故障提示并退出，不会把它当成正常完成进而调用工具/Harness。子 campaign 修复重开后，项目可从原阶段接续；只读 status 暴露 attention，后续阶段事件提交后清除该提示。

控制器故障注入测试配置三个轮次：首次服务失败只收费/调用一次，重复 run 的事件与费用不变；显式修复后旧输出归档、完成三个轮次，总四次调用，重开血缘核验通过。项目测试验证重复故障不新增提示事件、不触发演化，修复后进入原定后续阶段。384 项全量回归通过（20 跳过），最终补充状态与控制器回归分别 3/21 项通过。此处是本地故障注入，不声称实际远端服务故障已经重现；没有新增真实 Codex、训练或推理调用。
