## 冻结结构

| 模型 | 条件类型 | 作用位置 | 新增参数 |
|---|---|---|---:|
| r11_field_embedding | 广播轮次向量 | field | 256 |
| r11_history_embedding | 广播轮次向量 | history | 256 |
| r11_both_embedding | 广播轮次向量 | both | 512 |
| r11_query_embedding | 逐 Query 轮次向量 | both | 4096 |
| r11_field_gate | Query 输入门控 | field | 257 |
| r11_history_gate | Query 输入门控 | history | 257 |
| r11_both_gate | Query 输入门控 | both | 514 |
| r11_embedding_gate | 轮次向量 + 门控 | both | 1026 |

轮次向量加到重复 block 输入。门控以原始输入 Query q 计算 δ=tanh(Wq+b)，将完整 block 输出 y 改为 y+δ·(y−q)，完整更新系数为 1+δ，初始为 1。字段门控位于字段 final norm 后，历史门控位于序列末尾 norm 前。
新增参数全部零初始化，沿用原 dense 优化器组设置；原参数初始化及初始函数保持一致，包括 BF16。首次/重复角色有区分，诊断第三次调用复用重复角色参数，不代表任意深度均有独立编码。
