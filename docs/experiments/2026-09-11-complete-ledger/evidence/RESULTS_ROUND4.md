# KuaiRec 第四轮：字段回读内容与接口结构

本轮完成四种结构 × 三个 seed 的 12 次完整训练，没有按单 seed 筛掉任何方案。重点区分额外字段回读应该读取什么，以及归一化接口是否影响结果。

本轮按平均 AUC 排序的首选是 **历史后只回读用户/上下文**。候选保留、超过原结构和超过基线分别报告；测试集未使用。

## 四种结构

初始字段编码始终读取全部 37 个字段；只限制历史之后的额外回读。目标物品包含 7 个字段，用户/上下文包含 30 个字段。被排除的字段仍能经初始 Query 影响预测。

| 实验 | 额外回读来源/位置 | 字段 final norm 次数 |
|---|---|---:|
| 上轮字段反馈 | 历史后全部字段 | 2 |
| feedback_target | 历史后 7 个目标物品字段 | 2 |
| feedback_context | 历史后 30 个用户/上下文字段 | 2 |
| feedback_no_norm | 历史后全部字段 | 1 |
| field_norm_matched | 历史前全部字段，逐次归一化 | 2 |

四种新结构均为 6 次 QFormer 块调用、11.408M 参数，继续共享第二个字段块。来源子集改变注意力计算量，因此另测延迟。移除的是额外字段 final norm，不是块内部的注意力/FFN LayerNorm。

**结果解释：** `feedback_context` 的平均 AUC 为 0.869887，较 Cross8 原始设置增加 0.000523，较 Cross11 全 Query 增加 0.000192，较上轮全部字段反馈增加 0.000628；平均 Logloss 为 0.189054。对上轮字段反馈三个 seed 的 AUC 差值均为正，但 seed 29 仅增加 0.0000035，且其 seed 标准差从 0.000469 增至 0.001235。相对 Cross8 原始设置仍是两个 seed 上升、一个下降。

代价是平均 NDCG@10 从上轮字段反馈的 0.410504 降至 0.407190；因此将上下文回读列为 AUC/Logloss 优先候选，保留全部字段反馈作为排序指标候选。新结构相对 Cross11 和 Cross8 匹配优化设置的条件 bootstrap 区间跨零，尚不宣称稳定超过优化基线。

归一化对照中，去掉额外 final norm 的三个 seed AUC 均低于上轮字段反馈；字段内循环补齐归一化次数后，平均 AUC 只比原字段内循环高 0.000014，未重现上下文回读收益。这些对照支持继续研究回读内容与位置，不能据此把归一化、位置、来源的所有交互效应分解完毕。目标物品单独回读的平均 AUC 较低，但其 NDCG@10 为 0.409435；保留为机制与排序指标分支。

三个 seed 固定为 20262027/28/29；相同数据 SHA-256、标签与时间切分、1 epoch、batch=8192、1240 更新、优化器和学习率。所有新模型训练/验证均保留全部 Query。Cross11 全 Query 采用先前同 checkpoint 路由对照，Cross8 原始/同优化设置均保留。标准差是三次训练的样本标准差。

## 冻结 checkpoint 的 rec-harness 诊断

使用上一轮字段反馈的 seed=20262027 权重，在固定的 57,408 条验证事件（7,176 用户、4,472 正例）上切换回读来源/额外归一化，不更新权重。原行为与旧导出逐样本核对。

| 同权重干预 | 子集 AUC | 子集 Logloss |
|---|---:|---:|
| all | 0.859935 | 0.204027 |
| target | 0.853665 | 0.209483 |
| context | 0.859892 | 0.203972 |
| no_extra_norm | 0.859956 | 0.204019 |

子集按用户均匀抽样，分布不同于完整事件集；干预结果只诊断当前权重的依赖，不能替代从头重训，也不用于选择模型。各来源宽度为 7/30/37，不把它们当等计算量的控制组。配对 Logloss 分析采用 rec-harness 原有 `analyze_perturbations.py`，详见 [诊断 JSON](reports/round4/source-probe/summary.json) 和 [工具报告](reports/round4/source-probe/toolkit/perturbation_report.md)。

训练后的 `feedback_context` seed 27 另完成 Hook、7 个阶段状态的几何诊断及 Zero/Shuffle 干预，共 9 次 rec-harness 工具调用全部成功。八个 Query 均有非零梯度，逐个 Shuffle 均增加分块 Logloss（各自条件区间为正）。最终状态有效秩 8.27/256、无死维度；中等维度集中提示只作为几何观察，不能解释为模型失效。

同 checkpoint 推理改为一次字段读取，分块 Logloss 增加 0.004942，95% 区间 [0.003991, 0.005886]；改为三次增加 0.002549，区间 [0.001885, 0.003212]。这说明当前权重依赖训练时的两次读取，不证明其他深度重训后必然较差。原 checkpoint 在诊断后哈希不变，完整报告见 [干预报告](reports/round4/feedback_context/toolkit-perturbations/perturbation_report.md)。

## 配对不确定性

- feedback_context 对 place_feedback2 (native)：三 seed 平均 ΔAUC=+0.000628，配对用户 bootstrap 95% 区间 [+0.000354, +0.000924]。
- feedback_context 对 baseline (all_queries)：三 seed 平均 ΔAUC=+0.000192，配对用户 bootstrap 95% 区间 [-0.000095, +0.000466]。
- feedback_context 对 cross8_matched (native)：三 seed 平均 ΔAUC=+0.000117，配对用户 bootstrap 95% 区间 [-0.000209, +0.000433]。
- feedback_context 对 cross8_original (native)：三 seed 平均 ΔAUC=+0.000523，配对用户 bootstrap 95% 区间 [+0.000196, +0.000855]。

共享同一次用户重采样后对三个固定 seed 配对结果取平均；区间不包含训练 seed 的总体不确定性，也未校正本轮四种候选的选择效应。保留接近 Cross8 或 Cross11 的模型不等于证明统计等价或稳定提升。
