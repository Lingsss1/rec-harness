# KuaiRec 第五轮：减层、共享循环与额外 self-attention

六种新结构均完成三个固定 seed，共 18 次完整训练。Cross8 是主基线，Cross11 是优化参考；接近任一基线的结构继续保留为优化候选。测试集未评估。

## 实际结构

Cross11 原始每个 block 已含 self-attention、CrossValue 和 FFN。本轮 A 是额外的 Query self-attention + 残差 LayerNorm，在两次字段读取前共享使用。源字段和历史 K/V 保持不变；初始 Query 与第一次字段读取使用全部字段，第二次只读用户/上下文。

| 模型 | 独立字段 / 历史块 | 调用顺序 | 完整块 / 额外 A 调用 |
|---|---:|---|---:|
| 上轮 feedback_context | 2 / 3 | N0 N1 S0 N1(context) S1 S2 | 6 / 0 |
| compact_seq2 | 2 / 2 | N0 N1 S0 N1(context) S0 S1 | 6 / 0 |
| compact_seq1 | 2 / 1 | N0 N1 S0 N1(context) S0 | 5 / 0 |
| attn_full | 2 / 3 | N0 A N1 S0 A N1(context) S1 S2 | 6 / 2 |
| attn_seq2 | 2 / 2 | N0 A N1 S0 A N1(context) S0 S1 | 6 / 2 |
| attn_seq1 | 2 / 1 | N0 A N1 S0 A N1(context) S0 | 5 / 2 |
| attn_small | 1 / 1 | A N0 S0 A N0(context) S0 | 4 / 2 |

同名块共享权重。减少独立块会改变参数量、初始化随机数消耗与执行图；同一个 seed 不表示所有公共模块具有相同初始参数。固定数据、初始化种子集合和更新预算，从头训练比较最终效果。额外 A 只有注意力而完整块还有 CrossValue/FFN，调用次数不等于计算量。

## 本轮结论与候选保留

**优先继续优化 `compact_seq1`，同时保留 `attn_full` 作为 AUC 优先分支。**

- `compact_seq1` 保留 2 个独立字段块与 1 个历史块，执行
  `N0 → N1 → S0 → N1(context) → S0`。三个 seed 平均 AUC=0.870296，
  较 Cross8 增加 0.000932，三个配对 seed 均为正；较 Cross11 全 Query
  增加 0.000602。相对这两组参考的条件用户 bootstrap 区间均为正。
  AUC seed 标准差为 0.000417，低于本轮完整深度加 attention 的 0.001164。
  相对 Cross11 和父结构不是每个 seed 都改善，不能外推到所有训练初始化。
- 参数为 9.037M，较 Cross8 少约 2.1%、较 Cross11 少约 20.8%。
  同卡 p50=13.76 ms，Cross8=13.68 ms：没有测出速度优势，属于接近；
  比父结构 16.33 ms 快约 15.8%，比 `attn_full` 17.28 ms 快约 20.4%。
  平均 Logloss=0.188736，NDCG@10=0.408556，均优于父结构上下文回读；
  UAUC=0.790414，略低于父结构 0.790859。上轮全部字段反馈仍有更高 NDCG。
- `attn_full` 平均 AUC=0.870442，本轮最高；相对 Cross8 和 Cross11 的
  条件用户 bootstrap 区间均为正。但它与 `compact_seq1` 的平均差只有
  +0.000146，区间 [-0.000102, +0.000396] 跨零，同时参数增至 11.672M。
  因而保留其精度方向，不把这点均值差作为付出更高成本的充分依据。
- 额外 self-attention 的效果依赖深度：完整历史深度较父结构提高
  0.000555；两历史块时较对应无额外 attention 对照提高 0.000328；
  单历史块时却下降 0.000530。不能概括为 attention 总是有效或总是多余。
- `attn_small` 为 8.115M、13.12 ms，但 AUC=0.868486，低于 Cross8
  0.000878；保留为进一步压缩的优化候选，当前优先级低于前两者。
  其余结构也按用户要求保留，不因未超过 Cross11 而删除。

这些结论来自固定一轮训练与同一验证集的连续结构探索。条件区间不是独立
确认试验；固定 GPU 时间预算、更长训练和独立 seed 的收益仍未验证。
本轮也未单独训练单历史块的无循环版本，不能将整体收益完全归因于权重共享。
