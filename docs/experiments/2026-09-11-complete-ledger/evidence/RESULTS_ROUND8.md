# KuaiRec 第八轮：首次 attention 改造与循环次数重训

八组均只使用已有 seed=20262027，未新增训练 seed 或复测；本轮全部从头训练。Cross8 为主基线，Cross11 全 Query 为优化参考。测试集未评估。

直接父模型为 r7_small_attention_first：N(全部字段) → S(历史) → A → N(上下文) → S(历史) → 最终序列 norm。N/S 分别共享一个字段块/历史块，A 是额外 Query self-attention，原始块内部 attention 保留。

## 冻结改动

| 模型 | 相对直接父模型的改动 |
|---|---|
| r8_first_midnorm | 每次 S 后使用序列 norm，取消末尾重复 norm |
| r8_first_half | 额外 A 残差乘 0.5，再做其原有 post norm |
| r8_first_double | 额外 A 残差乘 2，再做其原有 post norm |
| r8_first_prenorm | 额外 A 改为 pre norm，保留原始残差直通 |
| r8_first_prenorm_half | A pre norm + 残差 0.5 |
| r8_first_midnorm_half | 每次 S 后的序列 norm + A 残差 0.5 |
| r8_first_loop1 | 从头训练一次 N S A，无第二次字段/历史回读 |
| r8_first_loop3 | 从头训练三次共享 N/S 循环，仅第一次有 A |

A 的 post norm 为 `LN(q + α·Attn(q))`，pre norm 为 `q + α·Attn(LN(q))`；残差分支保留原有 dropout。
八组均保留 8,115,473 个参数、相同参数键/形状与初始化流程。只重组原有 attention/norm 模块，优化器引用不变。一次/三次循环改变计算量和上下文回读次数，属于等参数、等训练更新预算对照，不是等 FLOPs 对照。

## 本轮判断

本轮八组均未超过 `r7_small_attention_first` 的 AUC=0.871234，继续保留它为当前固定 seed 的 AUC 首选。此前“仅第一次额外 attention”与“每轮序列 norm”各自的改善没有简单叠加，继续微调附近残差标量的优先级降低。

**完整训练的深度对照支持两次循环。** 从一次增至两次，AUC 增加 0.001138；从两次增至三次，AUC 变化 -0.003163。三者参数均为 8.115M，A 均仅在首次历史读取后执行。该对照说明当前结构的第二次上下文/历史回读有助于 AUC，同时增加计算；不能把差异全部归为权重共享本身。

一次循环 `r8_first_loop1` 保留为低成本排序候选：AUC=0.870096，比 Cross8 高 0.000549，比 Cross11 全 Query 高 0.000122；UAUC=0.792501、NDCG=0.412650，均高于两次循环父模型的 0.790837、0.409856。前向 p50 从 12.68 降至 8.53 ms，减少 32.7%；代价是 AUC 与 Logloss 退化。三次循环 p50=16.75 ms，质量与成本均不占优，保留为负面对照。

`r8_first_prenorm_half` 是本轮新结构中 AUC 最高的候选（0.870984，距父模型 -0.000250），NDCG=0.411016 更高，但 UAUC=0.788638 更低。`r8_first_midnorm` AUC=0.870863，UAUC=0.791510、NDCG=0.410313，前向耗时接近父模型，保留用户排序指标取舍。所有接近 Cross8 或 Cross11 的结构及较差对照均保存。

八个初次启动任务因 YAML 重复锚点在配置解析阶段退出，未加载模型或开始训练。已保留初始配置/哈希/日志，修正序列化后检查新旧配置语义，再重新冻结并成功完成八次训练；这不构成八次模型效果失败或额外 seed 复测。见 [失败启动状态](reports/round8/training-launch-failed/status.json)。累计成功训练 95 次，历史证据追加保存。

后续结构方向优先分离第二次上下文回读的作用，以及共享变换配合分轮归一化；这些是尚未运行的候选，不将诊断结果当作训练收益。
