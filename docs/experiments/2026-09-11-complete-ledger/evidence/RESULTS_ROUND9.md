# KuaiRec 第九轮：回读位置、权重共享与分轮归一化

八组完整训练仍只使用已有 seed=20262027；没有新增 seed 或测试集评估。主基线 Cross8，优化参考 Cross11 全 Query。

父模型 r7_small_attention_first 的主调用顺序为 N(全部字段) → S(历史) → A → N(上下文) → S(历史)。N/S 共享，额外 A 仅在第一次 S 后执行。

## 结构对照

| 模型 | 改动 |
|---|---|
| r9_feedback_omit | N S A S；去掉第二次字段读取 |
| r9_history_replace | N S A S S；用历史读取替代第二次字段读取 |
| r9_feedback_before | N N(context) S A S；字段回读提前 |
| r9_feedback_after | N S A S N(context)；字段回读后移 |
| r9_field_splitnorm | 两次字段输出 norm 参数独立 |
| r9_history_splitnorm | 每次 S 后有 norm，两次参数独立 |
| r9_both_splitnorm | 字段和历史接口 norm 均按轮独立 |
| r9_untied_clone | 第二次历史块从第一次精确复制后独立训练 |

字段 splitnorm 增加 512 个参数；历史 splitnorm 增加 512 个，二者组合增加 1024 个。历史/组合分轮 norm 的直接父模型为 r8_first_midnorm，其归一化位置相同，便于比较共享与独立参数。其余直接父模型为 r7_small_attention_first。
独立历史块从共享块精确复制，初始输出一致，不额外抽取随机数；新增参数使用原优化器类型和组设置，测试覆盖真实更新。它增加 1,185,536 个参数，因此不是等参数对照。去掉字段读取降低计算量；相同 block 调用次数也不等于相同 FLOPs。

## 本轮结论

八组均未刷新当前固定 seed 的最高 AUC=0.871234，继续保留 `r7_small_attention_first`。累计完成 103 次完整训练；本轮无训练失败，全部仍用已有 seed=20262027。

第二次上下文回读在当前结构中有价值：去掉它，AUC 从 0.871234 降到 0.869712（-0.001522），而两次历史读取仍保留。用历史块替换该字段块，AUC=0.870561；提前或后移回读分别为 0.869213 和 0.867980。原始交替顺序在本轮对照中更好。这是当前结构与预算下的证据，不能概括为所有模型都应该交替回读。

相同初始函数的独立历史权重对照 AUC=0.870773，较共享父模型低 0.000461；参数从 8.115M 增到 9.301M，增加 14.6%，同卡前向约 12.66 ms，与共享的 12.63 ms 接近。它也未改善父模型的 Logloss、UAUC、gAUC、NDCG。保留为高容量机制对照，继续优先共享权重；这里不做跨 seed 稳定性结论。

本轮新结构最高为字段分轮 norm，AUC=0.870864，但相对共享 norm 父模型仍下降。历史/双接口分轮 norm 应与 norm 位置匹配的 `r8_first_midnorm`（0.870863）比较，分别为 0.869939/0.870749；双接口版本的 Logloss 略好，但排序指标退化，不能把它当成纯收益。

去掉回读的 p50=11.10 ms，尽管更快，仍被已有一次循环模型（AUC=0.870096、8.51 ms、NDCG=0.412650）在这些指标上超过。因此 AUC 首选仍为两次交替共享循环，低成本排序首选仍为一次循环。

最近两轮已完成 16 个未超过父模型 AUC 的结构对照，进入新结构方向：保留已验证的交替位置，研究第二次字段/历史 block 是否需要再次执行完整 self-attention、CrossValue 和 FFN。下一轮会比较共享子层的选择性执行，不再只在相近 norm/attention 标量上搜索。该方向尚未训练，不能预先宣称有效。
