## 本轮保留的优化方向

所有数字都是已有 seed=20262027 的完整验证结果。首批八个实验和四个组合
均已完成，没有新增 seed，也没有补跑其他已有 seed。

**AUC 方向保留 `r6_field_after`；压缩方向优先保留
`r6_small_attention_after`，同时保留更小更快的 `r6_small`。**

1. **末尾上下文回读**：`N0 → N1 → S0 → S0 → N1(context)`。
   AUC=0.870420，较同 seed Cross8 增加 0.000873、较 Cross11 全 Query
   增加 0.000447、较父结构增加 0.000223。参数仍为 9.037M，p50=13.66 ms，
   与父结构相同。相对父结构，Logloss 从 0.188830 升至 0.189043，
   NDCG 从 0.409850 降至 0.409432，UAUC 也略降，因此不是所有指标都改善。
2. **单字段 / 单历史块，加历史后 attention**：
   `N0 → S0 → A → N0(context) → S0 → A`。AUC=0.870153，
   比父结构仅低 0.000045；参数从 9.037M 降至 8.115M，p50=13.01 ms。
   相对 Cross8，AUC 提高 0.000606，参数少约 12.1%，本次前向耗时少约 4.2%。
   Logloss=0.188567，是本轮最低；NDCG=0.410036，略高于父结构，
   但 UAUC=0.788920，低于父结构的 0.790914。注意力放在历史后，较同样
   参数量的旧 `attn_small`（放在字段前）AUC 增加 0.000505。
3. **更小的共享循环**：`r6_small` 只有 7.852M 参数、12.10 ms，
   AUC=0.869915，接近 Cross11 的 0.869973，并高于 Cross8 的 0.869547。
   相对 Cross8，参数少约 14.9%，本次前向耗时少约 10.9%。
4. **极低成本对照**：`r6_shallow` 不做额外循环，AUC=0.869364、9.55 ms；
   较 Cross8 低 0.000183，前向耗时少约 29.6%。保留为低成本候选。
   但与同参数父结构相比，额外字段—历史循环改善 AUC 0.000834，也改善
   Logloss、UAUC 和 NDCG；因此本轮对照支持保留这一轮交互的精度价值。

## 结构对照得到的边界

- 将额外回读放到历史之前、把五次调用更多分给历史、或从头训练三次循环，
  都没有超过父结构。三次循环 AUC=0.868595，p50=17.82 ms，不能靠继续
  增加深度解决本轮问题。
- 在五次完整 block 调用下，不共享两个历史层的 `r6_untied` 为
  10.223M、AUC=0.869809；共享版本为 9.037M、AUC=0.870197。
  这组固定 seed 对照支持共享设计，没有发现独立历史权重的优势。
  初始化消费与参数量也随不共享变化，结论限定于这组实现和预算。
- 首批收益不能直接相加：去掉字段前置块后再改末尾回读，AUC 降至
  0.868994；相反，在小模型中将额外 attention 放到历史之后有收益。
- 末尾回读目标字段和全部字段的 NDCG 分别达到 0.414381、0.412987，
  但 AUC 只有 0.868484、0.868398。保留为排序指标分支，不将其描述为
  AUC 优化成功。相应来源宽度为 7/37，而默认上下文为 30，计算量不相同。

## rec-harness 诊断

对末尾上下文回读和小型历史后 attention 两个已训练 checkpoint 使用原先
固定的 57,408 条验证事件、7,176 用户、4,472 正例子集。导出未更新权重，
前后 checkpoint 哈希不变。全部 17 次既有工具调用成功，JSON 和 Markdown
结果均已核对。这里的子集效果不用于选择模型。

| 模型 | 同权重干预 | 分块 ΔLogloss | 条件 95% 分块区间 |
|---|---|---:|---|
| 末尾上下文回读 | 改为一次循环 | +0.051843 | [0.049114, 0.054388] |
| 末尾上下文回读 | 改为三次循环 | +0.007650 | [0.006629, 0.008788] |
| 小型历史后 attention | 关闭额外 attention | +0.016494 | [0.014670, 0.018071] |
| 小型历史后 attention | 改为一次循环 | +0.098876 | [0.096225, 0.101311] |
| 小型历史后 attention | 改为三次循环 | +0.026267 | [0.023912, 0.028713] |

两个模型的八个 Query 梯度均有限且非零。最终表示有效秩分别为
12.60/256、8.90/256，各导出阶段无死维度；几何上的中等维度集中提示
不等于模型失效。末尾回读的 Q3 Shuffle 接近零，但 Zero 会损害 Logloss，
不能仅据 Shuffle 直接删除；Q2 Zero 和 Q3 半权重在子集上改善 Logloss，
本轮没有据此再调路由，保留统一全 Query 的结构比较。

诊断只说明当前权重对组件和训练时循环次数的依赖，不能代替从头重训。
