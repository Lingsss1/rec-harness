## 本轮判断

本轮八组均未超过 `r7_small_attention_first` 的 AUC=0.871234，继续保留它为当前固定 seed 的 AUC 首选。此前“仅第一次额外 attention”与“每轮序列 norm”各自的改善没有简单叠加，继续微调附近残差标量的优先级降低。

**完整训练的深度对照支持两次循环。** 从一次增至两次，AUC 增加 0.001138；从两次增至三次，AUC 变化 -0.003163。三者参数均为 8.115M，A 均仅在首次历史读取后执行。该对照说明当前结构的第二次上下文/历史回读有助于 AUC，同时增加计算；不能把差异全部归为权重共享本身。

一次循环 `r8_first_loop1` 保留为低成本排序候选：AUC=0.870096，比 Cross8 高 0.000549，比 Cross11 全 Query 高 0.000122；UAUC=0.792501、NDCG=0.412650，均高于两次循环父模型的 0.790837、0.409856。前向 p50 从 12.68 降至 8.53 ms，减少 32.7%；代价是 AUC 与 Logloss 退化。三次循环 p50=16.75 ms，质量与成本均不占优，保留为负面对照。

`r8_first_prenorm_half` 是本轮新结构中 AUC 最高的候选（0.870984，距父模型 -0.000250），NDCG=0.411016 更高，但 UAUC=0.788638 更低。`r8_first_midnorm` AUC=0.870863，UAUC=0.791510、NDCG=0.410313，前向耗时接近父模型，保留用户排序指标取舍。所有接近 Cross8 或 Cross11 的结构及较差对照均保存。
