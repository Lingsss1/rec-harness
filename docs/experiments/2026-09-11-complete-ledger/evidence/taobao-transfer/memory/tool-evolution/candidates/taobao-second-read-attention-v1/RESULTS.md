# 第二轮 attention 重分配诊断

候选状态：**accepted（仓库内诊断工具）**。六项 gate 均通过；已记入 rec-harness memory，训练记录仍为109条。尚未宣称稳定 toolkit 部署或任何训练 AUC 提升。

当前 q4 的购买任务使用了第二轮不同的历史注意力分配。将第二轮检索用的 P2 替换成同样本首轮 P1，同时保留第二轮查询交互和残差，购买 BCE 上升，达到预先规定的方向门槛。其余七项为不确定，不能称为零效应或等价。

两家各5514条固定验证样本、4647用户；原生SDPA、CPU FP32。三条件的首轮九项签名、第二轮外部query/interaction严格一致；native/identity概率和BCE逐字节相等。实际19条全padding样本的native/reuse概率及BCE也逐字节相等，分布指标保留N/A。

此结果未支持复用首轮attention的训练分支，也不支持增大查询变化、降低attention重叠或引入novelty penalty。新查询结构仍需独立假设与训练对照；本次支持的动作是保留当前q4行为，因此未创建模型编辑handoff。

29项离线测试通过，其中attention测试含12个已知机制样例。两次真实导出加聚合耗时120.654秒、CPU417.535秒，峰值RSS1,982,283,776字节；GPU、训练更新、test评估均为0。完整成本记录区分实际测量与预留预算。

这测量的是第二次注意力重分配的条件作用。整轮R1/R2消融还会改变工作状态与预测状态，不能混为同一问题。用户提出的任务差异见[已有逐任务证据](../../../../recurrence-research/TASKWISE_RECURRENCE_EVIDENCE.md)。
