## Target decision

The [pre-search target decision](target-decision.md) asks whether replacing second-read attention probabilities changes predictions while keeping its interaction and residual paths intact. No-tool AUC ranking, existing query geometry, whole-entry/work zero/shuffle, gate perturbations and correction-route interventions do not isolate this quantity. Changing the whole q2 can alter retrieval, `w_qi(q2)` and the residual simultaneously. Opportunity score was declared before search: **8/10** (decision2, recurrence2, readiness1, plausibility1, cost2).

Fixed original checkpoints: `ctx_q4` and `explore_dual_no_feedback`, two shared cycles, no prediction-to-work feedback, unchanged H memory, original training seed20262027. No q4 mechanism is assumed to generalize to q8. High attention overlap is not evidence of redundancy.

## Local estimator (agent inference from frozen source)

The shared `unified_qformer.layers[1]` is L2. Let `e=L1(q,H)`, `z1=L2(e,H)`, `y1=L3(e,z1,None)`, `q2=(e+z1)/2`, `z2=L2(q2,H)`, `y2=L3(y1,z2,None)`. Original post self-attention/FFN follows once. Keep the first L2 call native and unchanged.

For q1=e and q2 as above, with head split h4,d96:

```
Q_t = q_norm(heads(w_q(q_t)))
K = k_norm(heads(w_k(H)))
V = heads(w_fi(H))
P_t = masked_softmax(Q_t K^T * scale)
scale = 1 / sqrt(d) / attention_temperature
I2 = heads(w_qi(q2))
C(P) = w_o(w_v_pair(flatten_heads(I2 * (P V))))
Z(P) = q2 + effective_residual_scale * dropout(C(P))
```

The sole substantive intervention is **Z(P2) replaced by Z(P1)** on the second L2 call. P1 uses the same example/head/query slot and shared weights. Keep K,V,mask,q2,I2,residual,all affine biases and downstream modules fixed; changes propagated from Z are the measured effect. No labels, donor, mask edits or gradient enter the intervention. Verify identical first/second H and mask before reuse, rather than remapping positions. Preserve any learned residual-scale tensor faithfully. Configurations have D384,qk_norm=True, attention temperature default1. SDPA dropout=0 and is_causal=False; require eval/no_grad and no model/input/state/RNG mutation.

Existing L2 pre-hooks can capture q1/q2,H,mask for offline Q/K/P descriptors. The preferred future intervention is smaller: attach a temporary forward_pre_hook to exactly `unified_qformer.layers[1].cross_attn.w_q`; cache its first input q1=e and replace only its second input with that cached tensor. `w_qi(queries)` still receives the outer q2, and the layer residual remains q2. Source lines181–213 show these projections are independent. No global SDPA patch or manual-softmax prediction path is needed. Require exact class/source, eval/no_grad, precisely two w_q calls, identical K/V/mask/scale and normalization weights, state/input/RNG preservation, no labels, and restoration on exceptions. The candidate-only implementation now follows this recorded plan; see current results.

### Kernel identity and all-padding

Predeclare three paired conditions per checkpoint: **native original**, **explicit P2 identity**, **explicit P1 reuse**. These names denote probability conditions, not different numerical kernels. There is no uniform-attention condition in the three-condition budget. If separately proposed later, zeroing w_q input is not necessarily uniform because projection/q_norm affine biases can produce nonzero Q; uniform requires a correctly masked zero post-q_norm Q with no additional positional score terms, separately validated. In the identity condition the second w_q hook returns the original input unchanged. In reuse it returns cached q1, so with shared w_q/q_norm, exact K/V/H/mask and scale, the original SDPA computes exactly the first-round probability distribution while all second-round interaction/residual paths stay intact. SDPA dropout is explicitly zero. This uses the same native kernel in all conditions; primary contrast is native P1-reuse minus native P2-identity. An unmodified native condition verifies hook identity. This differs from earlier drop_retrieval-correction tests, which restored the corrected query to the q2 mean rather than setting only retrieval projection input to first-round e.

Require bitwise identity of final probabilities/BCE and captured intermediate outputs between unmodified and identity-hook runs on deterministic CPU execution. Do not weaken this after observing results. Verify two w_q calls; first call identical; second retrieval input exactly cached e; outer q2/w_qi/residual and K/V/mask unchanged. Record actual dtype, backend, installed torch version and hashes. PyTorch documents boolean True as participating in attention, explicit functional dropout, and backend rounding differences. [Official SDPA documentation](https://docs.pytorch.org/docs/2.10/generated/torch.nn.functional.scaled_dot_product_attention.html)

Offline softmax/P@V is used only for entropy/overlap/JS and value descriptors, with FP64 hand-formula atol1e-10/rtol1e-9 and FP32 native attended-feature atol2e-6/rtol2e-5. Its rounding cannot become a prediction intervention or a performance effect. Descriptor calibration failure marks descriptors invalid; intervention conclusions still require every native hook/path invariant. The gate cannot pass with unvalidated requested descriptors.

All `-inf` softmax is undefined. For zero valid keys, offline probability storage is zero and attention distribution summaries N/A; verify against native attended features in fixtures. The intervention preserves original native behavior. Keep affine biases: zero attended features need not imply zero cross output. Do not invent uniform attention on padding or omit all-padding samples from losses. Length1 entropy=0, normalized entropy=N/A. Nonfinite native outputs fail, without silent repair. All-padding P1 reuse must be prediction-invariant because no valid retrieval probability can change.

### Inputs, outputs and null behavior

Inputs: hashed original checkpoint/config/source identities; fixed subset sample/user IDs, stratum and inclusion weight; q1,q2,H,mask and frozen attention parameters. Four labels may be used only by the post-intervention loss evaluator. Preserve the fixed subset5514/4647 users and its 16-stratum inverse-selection weights.

Descriptors: per-sample/head/slot masked entropy `-sum P log P`, normalized entropy for valid length>1, overlap `sum min(P1,P2)=1-0.5||P1-P2||_1`, JS divergence, `||(P2-P1)V||_2`, and `||C(P2)-C(P1)||_2`. Store absolute norms and validity counts. Descriptive length bins only:0,1,2–9,10–29,30–59,60–100. No head/bin/label subgroup selected by effect size. Low overlap need not change value output; a norm change need not improve prediction.

Paired output schema: immutable sample/user/stratum/weight, four labels for evaluation, native/identity/reuse probabilities and BCE, identity calibration differences, descriptor aggregates and valid counts. `delta_t=BCE(reuse)_t-BCE(identity)_t`: positive means reuse harms this frozen checkpoint/task. Use fixed 10000-replicate paired user-cluster bootstrap, diagnostic RNG seed20262027, with matched resamples across contrasts; this is no additional training seed.

Report per-task/macro estimates and95% intervals descriptively; directional claims additionally require simultaneous99.375% intervals (Bonferroni over2checkpoints×4tasks). Let `epsilon_t=max(1e-6,10*IPW_mean(abs(BCE_identity-BCE_native)))`; with required exact native identity this floor is1e-6. Interval wholly above epsilon supports retaining second redistribution for that checkpoint/task; wholly below -epsilon supports only further separately scoped investigation of reuse, requiring consistency against native. Otherwise inconclusive. CI crossing zero does not establish equivalence. A tight null bounds this specific replacement in this frozen subset, not all possible attention interventions or retraining. Do not pool q4/q8 or erase task tradeoffs with macro results. No model change is authorized.

## Precommitted validation

See [machine-readable thresholds](precommit-thresholds.json). These thresholds were frozen before implementation; current gate results are recorded below:

1. Paper fidelity: independently verify local equations/source, mask polarity, normalization axes, scale, projections and biases against FP64 hand calculations. Distinguish paper claims from local adaptation.
2. Synthetic correctness: deterministic identical-P, distinct-P/equal-values, relevant-value difference, and attention-invariant q1/q2 with interaction/residual effects. Analytic downstream heads provide known harmful/helpful signs. Require every analytic and restoration case to pass.
3. Robustness: q4/q8, partial/all/one valid masks, large finite logits, equal values, padding perturbation, head permutation equivariance, no-feedback invariants, immutable inputs/state/RNG/checkpoint, invalid-stage/train/grad-enabled rejection and exception restoration. No new training seed or real-data repetition.
4. Shadow data: only two original checkpoints, frozen5514 validation rows, all three conditions, complete pairing/identities, finite outputs and successful identity calibration. Null/negative effects are valid observations; positive significance is not a gate.
5. Incremental utility: predeclared balanced12-case analytic suite:4attention-driven (2helpful/2harmful),4whole-query-confounded but probability-null,4identical/equal-value null controls. Require12/12 correct mechanism classifications and no false attention claim on8null cases. Existing whole-query/no-tool answers are `not identified` where their evidence cannot decide, not fabricated wrong answers. Utility comes from resolving injected mechanisms while preserving other paths, not requiring a real effect of a chosen sign. Report real null/negative/inconclusive outcomes completely.
6. Cost: future observed wall/CPUtime,peakRSS,artifactbytes must satisfy the single shared ceiling; stop on overrun, do not create retry/shadow budgets under the alias.
