# 四组优化器对照解读

四组均完成 2193 次更新和完整验证。各自仅修改稠密优化器配置，保留结构、clip1、学习率和原训练 seed；主组及并行组审计均通过。

PSGDKron 的 macro AUC 在四种结构上均高于各自 AdamW：Cross8 +0.002688744、384 单轮 +0.003411249、post-half +0.002117806、tail-half +0.000776442。前三组四个任务的 AUC 均提升；tail-half 的加购 AUC 略降。

目前最高是 384 单轮 0.827466136，超过 PSGDKron tail-half 0.001248350、post-half 0.000378567。因此在本次固定预算下，额外循环没有超过同宽单轮；此前 AdamW 下的循环优势不能直接推广至另一优化器。post-half 的加购 AUC 0.866191175 仍是这四组最高，保留任务偏好候选。Cross8 参数更少，保留成本候选。

384 单轮相对自身 AdamW 的购买 AUC 增量为 0.005421283，约占 macro 增量的 39.7%；其他三个任务同向提高，并非单一任务独占收益。其 macro AUC 相对原 Cross8 提高约 0.006396465，相对 Cross8 clip1 提高约 0.004417010。

500 次用户配对 bootstrap 已完成：Cross8 增量 95% 区间 [0.001725, 0.003590]，384 单轮 [0.002370, 0.004416]，post-half [0.001174, 0.003095]，均高于零；tail-half [-0.000191, 0.001695] 跨零。跨结构排序尚无直接配对区间，不宣称跨结构差异统计显著。全部结论固定一个训练 seed，验证集参与多次候选选择；没有额外训练 seed，没有评估 test。本轮未重新测量推理性能。

区间诊断和统一归档已完成，共 26 次淘宝训练、33 条实验及诊断记录。若继续优化，优先围绕 PSGDKron 的预条件器设置做同结构实验，保持用户指定学习率、clip1 和模型结构，不因旧 AdamW 结果直接扩大循环次数。
