# 两轮循环的容量分配

保留当前最佳循环候选的动态工作记忆、两轮、入口混合0.5与width384。主对比最佳单轮0.828623533，结构参考候选0.828521213。此前改变状态路径/归一化/减半更新未改善，因此本轮测试容量分配。

|GPU|实验|唯一容量改动|
|---|---|---|
|0|layout_q4|查询槽8→4|
|1|layout_q6|查询槽8→6|
|2|layout_q12|查询槽8→12|
|3|layout_ns1|非序列入口层数2→1|
|4|layout_ns3|非序列入口层数2→3|
|5|layout_postffn2|序列读出FFN倍率4→2|
|6|layout_postffn8|序列读出FFN倍率4→8|
|7|layout_ffn2|全局FFN倍率4→2（入口及序列读出均变化）|

查询数变化时，两组全1融合系数数组同步调整长度，系数语义不变；查询数也改变flatten tower维度和未启用task gate参数数量，不将其视为仅工作记忆容量的纯干预。不比较未训练模型的初始化等价；不同形状/层数会改变随机数消耗。若某种容量胜出，后续补相同容量的单轮对照，才讨论循环独立贡献。

固定训练seed20262027、PSGDKron每步预条件更新、dense LR1e-4、Adagrad0.05、clip1、batch8192、BF16、2193更新、四任务末轮损失、同一train/valid；不读取test。实际模型参数计数由完整特征映射预检生成，再在真实smoke与完整训练复核。CPU/CUDA检查八种形状的更新、梯度、mask/标签隔离和检查点恢复，真实batch8192 smoke通过后才完整训练。每组独立编译缓存。
