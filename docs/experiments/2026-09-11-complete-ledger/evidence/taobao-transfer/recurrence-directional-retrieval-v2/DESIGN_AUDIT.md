**结论：支持根代理最新的四种来源、同一有界切向更新方案进入前瞻协议；不建议本轮另外加入完全正交化或更多几何系数。** 四类有可区分的结构假设，足以构成 q4/q8 各四组；这不是诊断已证明它们能提升。审查只读本地代码/小型记录和原始论文，没有读取真实数组、权重或执行模型、训练、bootstrap；未改全局 memory。

当前账本为 **117 次已完成训练、181 条 episode**。在先前 [检索替代查重](../optimizer-layout-replay/retrieval-alternatives-audit.md) 基础上，新增两条分别是优化器合成诊断与方向/范数固定权重诊断；重新检索 `recurrence-*` 人工源码及 episode 的 centroid/Hopfield/mean-key/directional 描述，未发现下列四种精确训练设计。近邻仍是 whole-input 固定混合、rank16 retrieval-only correction、全 Wq/q_norm 解共享与已失败的 learned mixing；都不是本次在 q_norm 后用首轮 key 几何引导第二次检索。

[最新诊断](../recurrence-query-direction-norm/RESULTS.md) 仅支持原 q4.buy 在指定替换中主要依赖第二 Q 的方向：方向替换 ΔBCE=+1.42098e−5，范数替换约 +1.18736e−7，且预定联合门槛通过。其余七项不确定。两家旧 native/reuse 被逐位复现，故这是同一 checkpoint 效应的分解；它既不说明外推会更好，也不说明将方向转向某类 key 会更好。

统一公式固定在每个样本/head/query-slot 上。`Q2` 是第二次 L2 原 q_norm 输出，`n2=||Q2||`，`u2=Q2/n2`；`d` 为 head_dim。对来源 `s`：

`v = s / max(||s||, 0.1*sqrt(d))`

`t = v - <v,u2>*u2`

`Q2' = n2 * (u2 + 0.25*t) / ||u2 + 0.25*t||`。

所有来源使用同一 floor、λ=.25、归一化位置和回退规则，不新增可训练参数。原 Q2 或源范数≤1e−12 时回退原 Q2；该阈值处理零方向，较大的统一 floor 负责抑制小源的噪声和梯度放大，两者作用不同。第一轮输出、历史 K/V/mask、第二轮 `w_qi` 输入和 residual 输入均保持原路径；prediction 不反馈给 work，仍是两轮。

| 来源 / 建议保留 | 可证伪的结构假设 | 最近邻与关键区别 |
| --- | --- | --- |
| `s=-Q1`，几何外推参照 | 沿第一方向在 Q2 切平面上的反方向，小幅延续已有方向变化可能有用。 | 不额外读取历史，是其余三种记忆引导的几何参照；不同于直接 `Q2−αQ1` 后任意缩放，也不同于旧 whole-input 差值网络。 |
| `s=SDPA(zeros_like(Q1),K,K,mask)`，uniform-key 质心 | 同一历史中的共同 key 方向本身可能有用，不需要首轮选择权重。 | 无新参数，但不是无关/随机负例；其源在 query slots 间相同，切向投影仍依赖各 slot 的 Q2。 |
| `s=SDPA(Q1,K,K,mask)`，首轮加权 key 质心 | 首轮 P1 所选择的 key 方向，比均匀共同方向更适合引导下一检索。 | 使用 K 作 value，而原 CrossValue 汇聚的是 `w_fi(H)`；不能等同于复用旧 attention output。 |
| `s=SDPA(Q1,K,K−μ,mask)`，居中加权质心 | 剔除历史共同方向后的首轮选择偏差可能比原加权质心更有用。 | `μ` 是同一有效 mask 下的 key 均值；只改变额外 attention 的 values，不改变其 keys/logits。实数下等于 `P1K−μ`，不承诺 BF16 逐位等价。 |

三个 key 来源都只在第一轮使用缓存的原 `Q1/K`，额外 attention 各一次；居中分支计算有效 key 均值后只需一次 SDPA。几何参照没有这次 SDPA，计算开销必须单独报告，不能声称四组 FLOPs 一样。全部梯度保持连接，不 detach Q1、K、μ、源范数或 n2。

数学与归因边界：

- 实数下 `||v||≤1`、`t⊥u2`、`||t||≤1`，所以最终归一化分母≥1，旋转≤`atan(.25)≈14.04°`，保留与原 Q2 的正向分量。各来源实际角位移仍随 `||t||` 不同；统一上限不是等角度干预。FP32 几何再转 BF16 只能按预定容差核验范数/角度，不能宣称逐位保持范数。
- floor 将源归一化 Jacobian 的放大量约束在 `1/(0.1*sqrt(d))` 量级，避免居中源接近零时任意单位化。中心量很小会自然产生小更新，不应另为此候选放大系数。分母必须先安全化，不能先计算除零/NaN 再依赖 `where` 隐藏；零/平行源与无有效历史的回退都要记录。
- `s` 与 Q2 平行或反平行时切向分量为零，更新退化为原方向；不应人为发明旋转轴。均匀 P1 时居中源为零；单一有效 key 时均匀和加权质心相同、居中源为零；全 padding 的 key 均值和额外 attention 必须安全输出零。这些是结构退化，不是失败数据，原行保留。
- 范数保持并不固定实际 logits 方差/attention 熵：K 各向异性时，改变方向也会改变打分分布。不能因此称其与所有“温度效应”完全分离。
- `K` 作为 value 会引入原评分分支没有的梯度用途。原 logits 对所有 key 的共同平移仅增加逐 query 常数，softmax 不变；uniform/attended 质心却会保留这项平移，包括 `k_norm.bias`。居中源在实数下消去共同平移，因而 attended-vs-centered 同时比较共同分量和相关梯度路径；不能把均值直接称作无关历史。
- 参数名称、形状、注册顺序、初始化 RNG 可以保持原样；但新的结构必然改变已有参数的梯度、clip 和 PSGDKron 状态。这是本轮结构效应的一部分，不能宣称优化器更新相同。需要核第一轮仍恰好一次原 L2 路径，额外 SDPA 不替换原输出，也不缓存跨 batch 的陈旧计算图。

最小必要比较为 **八个 candidate−同 q 原循环**，加 **两家 attended−uniform** 和 **两家 centered−attended**，共十二个预定配对，全部保留正负结果。前者决定是否改善，后两者决定指定加权路径或共同分量移除是否优于其直接控制；如果两种新路径都低于原模型，它们相互之间获胜不构成候选提升。全八组都报告四任务、macro AUC、原 best Cross8 的点差和计算开销。若额外做最多两个 best Cross8 配对，选择规则需训练结果出现前固定，且保留选择未校正范围；不新增训练 seed。

继续沿用原 seed20262027、PSGDKron/LR/clip1、2193 更新和相同数据协议。q4/q8 的分歧应按各自对照解释；不得按已知 q4.buy 诊断筛任务或把某任务过门槛、另一项未过门槛当作任务差异。模型保留需依据已接受的完整质量/计算规则，不能由本轮几何变化量或 perturbation 敏感性直接决定。

不建议同时加入完整 90° 正交化：它把目前约 25° 的典型首二轮夹角强推到直角，并在近共线时放大不稳定分量；新有界切向方案已经提供更局部的可证伪方向变化。也不把“log P1 先验”、固定归一化线性组合和多个角度系数重复列成独立机制。原四种纯几何方案大多仍在 `span(Q1,Q2)` 内，本版的 key 来源能引入该平面之外的记忆方向，因此结构区别更清楚。
