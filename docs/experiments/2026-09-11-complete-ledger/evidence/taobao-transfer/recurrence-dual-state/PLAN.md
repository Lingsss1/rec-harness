# 工作状态与预测状态分离

上一轮第二次输出投影 rank8 LoRA 平均 AUC 0.826446913，相对纯 R2 +0.000256048，但 click AUC 与平均 logloss 变差，低于最佳单轮 0.828623533。下一轮改变状态更新结构，不扫描 LoRA rank。

受 TRM 的工作状态/答案状态分离启发，本实现使用两个不同的共享变换 F、G，不复现 TRM 单网络、深监督或多次 optimizer 更新。预测状态 y 是八个 query 的隐向量，最后由原四任务 tower 读出；不是标签或四个真实答案。

固定入口 e=L1(q,H)，初始 z=y=e。第一轮执行 z=L2(e,H)，y=L3(y,z)；此后每轮执行 z=L2((e+z+y)/3,H)，y=L3(y,z)。L2/L3 均包含原残差更新。历史掩码只用于 L1/L2，八个工作槽全部有效。最终 y 经过原 post attention、norm、FFN 和四任务 tower，各执行一次。全过程反向传播，单批一次更新，无辅助监督。平均输入是本项目待检验的缩放选择，不是论文公式。

对照 `dual_state_r1` 和 `dual_state_r2` 的参数、初始化、优化器与预算一致，仅循环次数变化。两组各 81,616,324 参数，无新增参数。一轮也改变了原第三层读取的对象，因此它不等价于原 Cross8 单轮；必须独立训练。两轮增加计算：历史读取从 2 次变为 3 次，工作槽读取从 1 次变为 2 次；不是等 FLOPs 对照。报告实际训练耗时和显存。

固定 width384、PSGDKron 每步预条件更新、dense LR1e-4、sparse Adagrad0.05、clip1、seed20262027、2193 更新、batch8192、BF16、相同 train/valid。保留最佳单轮与 Cross8 参考，不访问 test。主结果比较最佳单轮，另报告双状态 R2−R1；任一正平均增量触发 500 次配对用户 bootstrap，无新增训练 seed。

CPU 三项和 CUDA/BF16 三项契约均通过：初始参数与 RNG 完全一致、优化器唯一完整覆盖、显式手工展开输出/输入梯度/共享权重梯度一致、历史与工作槽调用顺序正确、四任务参数更新、修改 padding/目标 action/标签不改变预测、检查点恢复一致。真实 batch8192 smoke 另验证 PSGDKron、参数量和状态读取路径，之后才完整训练。
