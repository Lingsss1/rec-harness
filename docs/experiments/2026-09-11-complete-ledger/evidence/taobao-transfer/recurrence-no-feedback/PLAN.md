# 接近最佳的去反馈循环候选

基准 explore_dual_no_feedback 的完整验证平均AUC为0.828521213，最佳单轮为0.828623533，差值-0.000102319。按用户要求保留接近基线的优化候选。本轮复用原参数、初始化与读出路径，将去反馈状态更新参数化；默认两轮、入口权重0.5时，CPU与CUDA的参数、RNG、预测、原参数梯度均精确复现原实现，不重复训练同一对照。

入口 e=L1(q,H)，第一轮 z=L2(e,H)、y=L3(e,z)；后续 z=L2(a e+(1-a)z,H)、y=L3(y,z)。a=0.5时保留原算式(e+z)/2，确保浮点运算一致。工作更新不含预测状态y；post attention、FFN和四任务tower只在末轮执行。
