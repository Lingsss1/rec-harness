# 两轮表示读出与第二轮检索参数共享

本轮从原 q4/q8 两轮无反馈模型出发，分别研究怎样使用两轮结果、第二轮检索是否需要独立的 query 参数。任务收益差异提供读出对照的动机；检索参数共享是已经查重的独立假设。两类改动不组合，不把读出改善直接归因为检索改善。

|---:|---|---|---:|
| 0 | role_q4_read_shared | 共用首轮／末轮残差系数 | 1 |
| 1 | role_q4_read_task | 四任务各自的残差系数 | 4 |
| 2 | role_q4_query_norm | 第二次 L2 独立 q_norm affine | 192 |
| 3 | role_q4_query_projection | 第二次 L2 独立完整 Wq 与 bias | 147840 |

## 读出假设

保持原 `e=L1(q,H), z1=L2(e,H), y1=L3(e,z1), z2=L2((e+z1)/2,H), y2=L3(y1,z2)`。完整后处理 `T` 包含原末尾 attention、FFN 和归一化；先计算原 `h2=T(y2)`，再以相同权重计算 `h1=T(y1)`。

`r_t=h2+a_t*(h1-h2)`：共享版共用一个 a，任务版使用四个 a；原始参数直接作为系数，零初始化，不是深度概率或严格凸混合。h1 不 detach，不加入辅助 loss，也不反馈到任何工作状态。原四头 BCE 仍各自取 mean 后求和，dense clip1 和优化器保持。

初始原预测、参数和构造 RNG 应一致；初始原参数的未裁剪梯度应一致。新增 a 的梯度会改变全 dense 裁剪范数，故不宣称第一步更新或训练轨迹相同。任务版相对共享版多三个标量，结果包括解共享及其优化影响。额外 T(h1) 实际执行一次 post attention/FFN，要计入训练、显存和延迟开销。

## 检索参数假设

两组均只改第二次 L2 的 query 路径，保留查询 `(e+z1)/2`、K/V、mask、interaction、residual 和后续读出。q_norm 方案克隆 96 维的 gamma/beta；Wq 方案克隆完整 384×384 weight 与 384 bias。克隆完成于原初始化之后，不增加随机数消耗，初始函数和原模型一致；之后两轮参数独立训练。

完整 Wq 克隆检验投影参数共享，并非研究笔记中的 rank8 LoRA，也不与其参数预算混用。此前整层解共享、非线性 retrieval-only 修正和输出 LoRA 的负结果全部保留；这轮只检验不同的局部位置，不预设独立参数会带来收益。检索效果若改善，也需进一步诊断，不能直接归因于注意力更分散、熵更大或某个任务更复杂。

初始 q_norm/Wq 的原参数与克隆参数梯度之和应等于原共享参数梯度；分开后的梯度裁剪和预条件过程可能不同，这属于本次结构改变。原生 L2 通过 functional_call 替换指定参数，沿用原 SDPA 运算。

## 固定训练与验证

八组从原 seed20262027 的随机初始化训练，不加载训练过的参考 checkpoint。每组 1 epoch、2193 updates、batch8192、训练17,822,296行、验证2,871,767行；BF16、PSGDKron每步预条件、dense LR1e-4、sparse Adagrad LR0.05、clip1。两轮和无预测反馈保持，不读取 test，不新增训练 seed。

全部模型先通过合成 CPU 正确性检查，再在分配的 GPU 上做原尺寸两步 smoke：与新建原模型的初始 state/prediction 完全一致，原分路次数正确，四头及新参数有实际更新且进入原优化器。CPU 编译器不支持的合成测试可以记录并用 eager 数学验证；正式 GPU 路径仍使用原配置。没有预先加入 query-mixing 专属 A deferral 或 PSGD 初始化补丁。

全部 smoke 审核通过后才启动本矩阵正式训练。每组最多7200秒训练墙钟；超时记录为执行失败，不自动重启、不当作科学负结论。正式训练每组只启动一次。

## 完成后全部对比

预先固定十个用户配对比较：每个新模型减同 q 原循环，共八个；同 q 的 task 减 shared，共两个。不按 AUC 正负筛选。每个比较报告 macro 与四任务 AUC/logloss；500次用户配对抽样、分析 RNG20260906、268201用户、95%探索区间，不覆盖训练 seed 方差或候选选择。task−shared 另保留六个直接任务效果差区间，防止用不同单任务显著性替代差异检验。

八组全部报告相对最佳单次模型的点估计差值。三条参考和八个新 checkpoint 在独占同一 GPU、相同真实验证 batch1024、BF16 下分别进行10次预热与40次前向计时，记录批次和模型 hash、峰值显存，计时期间没有其他训练。不得用并行训练墙钟替代前向延迟。

保留策略：相对原循环的质量提升需完整展示任务取舍与开销；近似候选沿用 ΔmacroAUC≥−0.0001 且前向时间比例≤1.05 的队列门槛。这不构成等价证明或自动更换最佳模型。task−shared 无改善将限制任务独立读出假设，即使 shared 整体有益，也不能归因于任务差异。

两个 task 模型训练成功后，在事前固定的验证子集上做同权重 `a_t→mean(a_t)` 与 `a_t→0`：前者检查当前模型是否使用任务差异，后者检查首轮读出通路是否被使用。子集沿用已有固定样本，必须在执行前冻结；两项干预不替代分别训练的主对照。
