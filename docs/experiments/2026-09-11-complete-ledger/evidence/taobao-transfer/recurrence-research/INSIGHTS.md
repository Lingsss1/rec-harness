# 循环结构研究与淘宝实验建议

检索日期：2026-09-07。阅读下列原始论文的架构、训练目标和相关消融；这是一份面向本仓库的定向研究，不是系统综述。论文结果与淘宝上的假设分开记录。

## 已有证据

当前默认 PSGDKron：384 单轮 macro AUC 0.827466136，post-half 0.827087569，tail-half 0.826217786，Cross8 0.825737871。AdamW 下 tail-half 高于384单轮；优化器改变了已测结构的排序。旧整段循环和 tail 强度/深度扫描未提供稳定新收益。不能据此推出所有循环无效。

`QFormerCross8SelectiveLoop.py` 每轮 cross/tail 都会重新读取固定历史 K/V；因此不能把失败归因于“没有重读输入”。尚可测试的差异是：初始 query 的持续注入、中间层循环、轮次专属小参数、中间输出监督和可变深度训练。没有测量过的表征坍缩/梯度冲突只是待验证解释。

## 原始文献及可迁移 insight

1. [Huginn / Scaling up Test-Time Compute with Latent Reasoning](https://arxiv.org/html/2502.05171v1)，2025，§3–4。划分输入处理、共享循环核心、输出处理；核心每轮接收固定输入和状态，使用 sandwich normalization，并在训练时采样循环次数。对本任务的启发：固定历史之外还保留初始 query，在中间循环核心反复注入。注意该文发现显式轮次条件不利于其深度外推；不要把“轮次专属参数”和“无限深度外推”混为一个目标。

2. [Reasoning with Latent Thoughts: On the Power of Looped Transformers](https://arxiv.org/html/2502.17416v1)，2025，§2–3。区分同参数和同计算量对照；循环的推理收益并不意味着语言建模困惑度更好。迁移假设：CTR 同样未必随深度单调提升，应同时报告 macro AUC、四任务 logloss、实际耗时，并按历史长度分组。长度分组只能诊断，不能预设长历史一定获益。

3. [Relaxed Recursive Transformers](https://arxiv.org/html/2410.20672v1)，2024 / ICLR 2025，§2.3。共享大权重，给不同轮次独立 LoRA，以缓解严格共享约束。迁移：先试轮次独立归一化，再考虑 rank8 adapter。独立归一化是我们的廉价近似，不是论文已验证的替代；从头训练也不等同于论文的预训练权重转换与 SVD 初始化。

4. [Ouro / Scaling Latent Reasoning via Looped Language Models](https://arxiv.org/html/2510.25741v1)，2025，§3。每轮有任务损失，以熵正则避免退出分布过早集中，再单独训练退出门。启发：先让第二轮承担明确监督，再做动态退出。淘宝首次实验可用共享四任务 tower，对两个轮次的 BCE 加权并归一化；这只是借鉴训练信号，不是复现 Ouro 的门控目标。

5. [Less is More: Recursive Reasoning with Tiny Networks (TRM)](https://arxiv.org/html/2510.04871v1)，2025，§4 / Algorithm 3。区分潜在工作状态 z 与答案状态 y；通过深监督反复改进答案，完整反传一个递归过程。启发：后续可把历史工作状态和四任务输出状态分开更新，不必强制 self-attention。原方案每批可能多次 optimizer.step，直接照搬会改变训练预算；本任务先将多轮损失合成一次更新，不喂入真实标签作为循环输入。数独/ARC 结果不能作为推荐收益的证据。

6. [Universal Transformers](https://arxiv.org/html/1807.03819)，2018 / ICLR 2019，§2.2–3。共享递归变换并可按位置决定停止。启发：循环收益可能只集中于部分样本/任务。但在静态第二轮尚未改善前，不优先引入 ACT；先检查每轮指标，再决定是否值得支付门控成本。

## 第一轮优先实验：改变循环位置与输入通路

冻结默认 PSGDKron、dense LR1e-4、sparse Adagrad0.05、clip1、width384、原seed20262027、2193更新。保留 Cross8 主要对照及已完成的最佳单轮模型；不额外seed。现有优化器三组跑完后归档，不继续扩展优化器搜索。

原单轮历史阶段记为 L1→L2→L3→post。先建立一个可配置中间循环实现，并证明 R=1 与原单轮的参数、初始输出、梯度一致。post和预测tower在循环外。

| 候选 | 历史阶段/变化 | 检验假设 |
|---|---|---|
| M2 | L1→L2→L2→L3→post | 输入和输出处理层固定，只复用中间处理层是否更合适 |
| M2-anchor | M2第二次L2前混入固定入口状态e=L1(q,H) | 持续保留query入口信息是否改善迭代 |
| M2-anchor-norm | 在anchor上增加轮次独立归一化 | 严格共享的状态分布差异是否限制收益 |
| M2-anchor-supervised | anchor加共享tower的中间轮次辅助损失 | 第二轮是否缺乏可学习的改进信号 |

anchor的首选小改动为 q_in=(1-a)q+a e，固定a=0.1；这是明确可消融的工程假设，不是论文公式的直接复现。保留旧half残差方案作为已有参考，不同时改变所有残差尺度。

辅助损失先用 L=(0.25 L_first+L_final)/1.25，每个L都是四任务BCE之和；每批只更新一次。中间输出必须经过同一输出路径，避免把不同读出头能力混入循环比较。执行时先做M2和anchor，确认契约与成本后再扩展后两项。

## 必须回答的诊断问题

- 同一checkpoint下R=1/2/3/4的AUC与logloss是否改善？仅对支持额外轮次的共享版本做外推；轮次专属参数版本只评估已定义轮次。
- 每轮query更新范数、query间余弦相似度、注意力熵怎样变化？相似度上升不能单独证明坍缩，必须与输出和指标关联。
- 是否仅某些任务/历史长度组获益？使用统一预定义分组和配对用户诊断，不用诊断挑样本重新报告总体收益。
- 比较真实forward耗时与参与计算参数，必要时加同有效深度非共享对照，区分增加计算和权重共享。

## 2026-09-08 实验反馈

优化器轮次已结束，当前最佳为单轮 + 每步预条件更新，macro AUC 0.828623533。以下结构消融仍冻结默认 PSGDKron。

纯中间循环 R2=0.827502882，与默认单轮0.827466136基本持平；入口注入0.1降至0.826446521。纯中间循环同checkpoint深度1/2/3/4为0.824015/0.827503/0.825745/0.819784，原生R2预测完全复现。第二轮被模型利用，但尚无深度外推收益；这不能证明循环普遍无效。

据此把优先级调整为多深度训练和中间监督，而不是继续增加固定轮数。两组已通过CPU与CUDA/BF16测试，并进入真实批量smoke→训练队列，配置见[下一轮](../recurrence-training/PLAN.md)。多深度使用等比例循环调度，是对论文随机深度思路的受控改编；辅助监督当前重算前缀，明确增加训练计算。均不增加optimizer更新次数，不增加seed，不评估test。


## 2026-09-08 后续反馈与当前优先级

多深度训练和辅助监督已完成：mixed123 的原生 R2 macro AUC 为 0.826472683，supervised12 为 0.825484529，均低于固定 R2 的 0.827502882。mixed123 在 R4 为 0.825914875，深度增加时退化更小，但峰值指标没有提升。mixed123 训练见过 R1/R2/R3，只有 R4 属于未训练深度；不能把鲁棒性提升写成 AUC 提升。

循环核心消融已完成：重复更新减半为 0.824856705；有界交互门控为 0.827147308。后者与默认单轮较接近，保留候选，但不能声称统计等价，也不能据此认定原模型发生了状态发散。

当前正在用最佳单轮的同一优化器配置（PSGDKron 每步更新预条件器）训练纯中间 R2 和有界交互 R2；基准为最佳单轮 0.828623533。该轮只比较结构差异，保持 seed20262027、LR、clip1 与训练更新预算。当前训练尚未完成，不以训练 loss 推断验证排名。

下一步优先检验的结构假设：

1. **放松严格共享约束。** 参考 Relaxed Recursive Transformers 的轮次独立 LoRA，共享主权重，给第二次核心调用配置小型 adapter；轮次独立归一化可作廉价消融，但不是论文直接验证的方案。应增加同有效深度的非共享层对照，区分增加计算、增加参数和共享方式。我们从头训练，不能照搬论文预训练权重转换的收益结论。
2. **区分工作状态和任务答案状态。** 参考 TRM，保留历史工作状态 z 与四任务状态 y，交替执行 z←F(H,z,y)、y←G(y,z)，最后由 y 读出。这里 y 是模型隐状态而非真实标签；该迁移是待验证假设，不是已证实适用于推荐的结果。先固定两轮、一次 optimizer 更新，再考虑动态退出。
3. **测量循环状态，再决定归一化改造。** Huginn 的 sandwich normalization 和持续输入提示需关注整个状态更新通路。已有实现每轮重读历史，anchor0.1也未改善，故不能把缺少固定输入当成已确认原因。记录每轮更新范数、跨 query 相似度及任务预测变化，再决定是否增加完整核心的前后归一化。

暂不优先：继续增加固定轮数、重复扫描残差强度、静态循环尚无增益时引入 ACT。以上顺序服从当前最佳优化器下两组结果；论文的语言推理或数独指标不能充当淘宝收益证据。

## 查询形成实验检查点：区分修正来源与作用位置

截至本检查点，最佳单轮仍为 `psgd_precond_every_step`（macro AUC 0.828623533），最佳双状态去反馈循环为 `explore_dual_no_feedback`（0.828521213），小模型 `ctx_q4` 为 0.828472565。后续实验固定两轮、seed20262027、PSGDKron 每步预条件更新、clip1 和 2193 次更新。这里的“去反馈”指预测状态不进入工作状态更新。

已经排除的局部方向包括：已测第二轮 memory 拼接、已测 q4 FFN 容量和入口深度扩展。它们的失败只约束对应配置，不证明上下文、容量或循环本身无用。小模型从单轮到两轮的 macro AUC 增量为 0.001960375，用户配对条件区间为 [0.000997665, 0.002777111]；这支持当前 q4 结构使用第二轮，但不能解释第二轮如何获益。见 [q4 容量轮](../recurrence-q4-capacity/RESULTS.md) 和 [memory 来源轮](../recurrence-memory-sources/RESULTS.md)。

查询修正保留 `q2=(e+z1)/2`，再加零初始化输出投影的 rank16 修正，分别读取入口 e、工作状态 z1、均值或差值 z1−e。七个完成模型中，q4-work 为 0.828465777，与原 q4 的差值为 −0.000006789，条件区间跨零；它保留为候选，并非已证实等价或更好。q8-entry 为 0.828221007，低于原 q8 循环。q4 差值模型先前遇到优化器对微小非零梯度的误判，现已完成单独重跑及审计：AUC 0.825550580，相对均值修正为 −0.001193799，条件区间 [−0.002051331, −0.000376794]；相对原 q4 为 −0.002921985，条件区间 [−0.003753410, −0.002109276]。完整训练未触发兼容恢复分支；两步 smoke 触发过，原自动尺度精确保留。现在可按质量结果放弃这一差值加法修正，而不是按旧运行失败判定。见 [七组已完成结果](../recurrence-query-correction-v2/PARTIAL_RESULTS.md) 和 [差值重跑记录](../recurrence-query-difference-retry/reports/continuation.json)。

整体查询输入同时影响 attention 的检索投影、交互投影和残差。因此，输入修正的 AUC 差值不能直接叫作“检索提升”。对 q4-work 和 q8-entry 的同 checkpoint 干预，已经使用 rec-harness 工具分析固定分层子集上的用户配对 BCE：

- q4-work 去掉检索修正后 fav/buy 变差；去掉残差修正后 fav/buy 变好。这支持两条路径在当前权重下作用不同。
- q8-entry 去掉检索修正后 buy 反而变好，没有复现 q4 的同向检索证据。
- 两模型打乱修正的四任务区间均跨零，不能据此认定修正已学到普遍有益的样本特定信息，也不能据此证明修正没有信息。

这些结果条件于固定 checkpoint、5514 行分层子集、4647 名用户和 IPW BCE，不包含训练随机性或分层抽样设计的不确定性，未校正多项干预和候选选择。干预效果不能代替重训收益。见 [诊断解释及工具产物](../query-correction-diagnostics/reports/interpretation.json)。

八组已完成的分路重训分别在 q4-work、q8-entry 来源下，只将修正送入检索、交互、残差，或检索加交互两条 attention 路径；复用对应整体修正模型作为对照。比较需要同时回答：是否优于整体修正、是否优于对应原循环、是否值得相对最佳单轮增加计算。q4/q8 的来源不同，不能将它们的差异单独归因于查询槽数。仍保留预测状态不反馈到工作状态。见 [分路实验设计](../recurrence-query-routes/PLAN.md)。

分路结果：八组都低于对应整体修正和原循环；七组对整体修正的宏 AUC 条件区间完全为负。最好新组 q4 retrieval-only 为 0.828008444，相对原 q4 −0.000464121，未达到预先约定的近似持平候选门槛；相对整体修正的区间跨零，不是零效应或等价证明。同机前向 14.240 ms，原 q4 14.216 ms，未体现可弥补质量损失的计算收益。去掉残差修正的 attention-only 在 q4/q8 都退化，说明冻结权重干预的局部收益没有预测重训提升。九个新增训练已按差值在先、分路在后的顺序入账，累计 101 组，最佳单轮不变。见 [分路最终解释](../recurrence-query-routes/reports/interpretation.json)。

下一轮改测有界混合：让联合入口/工作信息决定第二轮更信任哪一个状态，和同参数的样本无关门比较；分别测试逐通道和逐查询标量两种粒度。保持两轮与无预测反馈，验证门的输入依赖能否带来实际 AUC 收益。它是新的可否证假设，不是上述负结果已经证明的机制。

## 尚未回答：第二轮是否需要重新分配历史注意力

2026-09-09 的只读审查核对了淘宝 146 条、KuaiRec 233 条 episode 和现有实验脚本，没有找到两轮 attention overlap/entropy 或 coverage、novelty、re-attention penalty 的已完成记录。这是当前证据的覆盖缺口，不能写成模型存在冗余读取的问题。

原 q4/q8 循环的两次 L2 共享历史、mask 与参数，查询分别为 `e` 和 `(e+z1)/2`。实际 Q/K 经过投影、分头和 q/k LayerNorm 后，以 `1/sqrt(96)` 缩放进入 SDPA；布尔 mask 的 True 表示有效历史。[实际 attention 实现](../../upstream/model_zoo/QFormerCross8.py)中，注意力汇聚之后还有查询交互与残差，因此最终输出变化不能单独归因于检索分布。此前 [fixed-memory 对照](../recurrence-fixed-memory/reports/interpretation.json)固定整个工作输入，也没有隔离这条作用路径。

本轮八组混合与固定门控诊断闭环后，可优先判断是否需要补两项测量：先在相同 query/head 和有效历史下记录两轮注意力的重叠、JS 距离及按历史长度分组的熵；再固定权重，仅把第二轮注意力概率 P2 换成 P1，保留第二轮交互、V 和残差，观察四任务配对 BCE。前者描述读取是否改变，后者才检验这种重新分配对当前 checkpoint 是否有贡献；两者均不能代替新结构重训。

[现有查询导出器](../query-conditioning/export_queries.py)已有每次前向恰好捕获两次 L2 的 hook，但未保存 K 或注意力概率。若执行新测量，需要在隔离的适配器中核对离线 softmax 与原 SDPA 汇聚的一致性；全 padding 应标记为没有有效注意力，有效长度 1 单列。高重叠、低熵本身不构成冗余或坍缩证据；在这些信息缺失时，不直接增加 novelty penalty。本项尚未运行诊断或新增训练。

## 2026-09-09 有界混合轮已闭环

八组混合全部完成 2193 步、12 项用户配对统计与 11 项同设备计时，累计训练记账数为 109。八组 AUC 点估计都低于同 q 原循环，五组的原循环配对区间完全为负；另外三组 q4 区间跨零。新组最好为 q4 query joint，AUC 0.828288863，对原 q4 为 −0.000183703，条件区间 [−0.000920632, +0.000533342]，平均前向耗时约增加 0.5%。八组均未通过事前队列门槛，最佳单轮与原小 q4 候选保持不变。结论限于这组 rank16、bound0.25 的入口／工作状态混合配置。见[最终判读](../recurrence-query-mixing/INTERPRETATION.md)。

同参数 joint−constant 的结果有明显配置差异：q4 query 为 +0.002704656，条件区间为正；q4 channel 的区间跨零；q8 channel/query 的区间均为负。q4 query 胜过较弱静态门，未转化为相对原循环的提升。

预先固定的 q4 channel 诊断也已完成并单独记账：joint 的 fav 在 zero 和 shuffle 下均降低子集 IPW BCE，其余 joint 区间跨零；constant shuffle 四任务完全不变，constant zero/click 只有极小的正向条件效应。门系数有样本方差并未提供普遍有益条件化的证据。完整训练比较和固定权重的子集诊断分别保留，见[门诊断](../query-mixing-diagnostics/RESULTS.md)。

## 2026-09-09 第二次读取诊断与任务收益差异已完成
