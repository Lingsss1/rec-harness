# 轮次区分与累积状态：淘宝实验结果

本轮发现：**第一轮状态确实能在第二轮产生可测的局部预测收益，收益随任务、历史长度和查询槽变化；但目前的轮次区分更新结构没有提高整体 macro AUC。** “状态被有效利用”与“新结构优于原模型”必须分别判断。

四组正式训练全部成功，每组 2,193 次更新，共用 seed 20262027、HeavyBall.PSGDKron、dense LR 1e-4、sparse Adagrad LR 0.05、clip1、BF16、batch8192。固定两轮、严格历史输入、19 类 action，不反馈预测状态到工作状态。没有新增训练 seed 或重跑正式训练。与原两轮模型、同输入协议 Cross8 比较，不与旧发布协议的 0.8286 直接比较。

## 训练后的整体收益

| 更新参数 | 第二轮携带首轮状态 | macro AUC |
|---|---|---:|
| 原两轮模型 mature_r2 | 是 | 0.767095 |
| 共享更新参数 | 是 | 0.760394 |
| 分轮更新参数 | 是 | 0.760117 |
| 共享更新参数 | 否 | 0.763738 |
| 分轮更新参数 | 否 | 0.756551 |
| 同协议 Cross8 | — | 0.759406 |

完整验证集 2,871,767 行、268,201 用户，500 次共享用户聚类 bootstrap；下列为探索性 95% 区间，固定单 seed，无多重比较校正。

- **分轮更新内，携带状态比不携带提高 macro AUC 0.003566，区间 [0.000342, 0.006399]。** 支持当前结构下累积状态有训练后的条件收益。
- 共享更新内，携带状态的差值为 -0.003344，区间 [-0.006376, 0.000157]，不能断言负效应已确认。
- 两者的直接交互差为 **+0.006910，[0.002235, 0.011162]**。说明本次实验中，携带状态的效果依赖更新参数是否分轮。分轮版本多 384 个有效参数，因此不是纯轮次身份的等容量因果隔离实验。
- 携带状态时，分轮更新相对共享更新为 -0.000277，区间 [-0.003659, 0.002923]，**没有整体提升证据**。
- 分轮＋携带相对原两轮模型为 **-0.006978，[-0.009982, -0.004307]**。相对 Cross8 为 +0.000711，区间跨零。

分轮＋携带相对原两轮模型：点击 AUC +0.001919 [0.001271, 0.002621]；加购 -0.006187、收藏 -0.012503、购买 -0.011139，三项区间均在零以下。点击 BCE 也改善，但另外三项 BCE 变差。它目前呈现任务间取舍，不能作为整体最佳模型替换。

## 固定检查点：第二轮实际利用了什么

预先按用户哈希抽取 183,320 行、16,881 用户，分为发现组和互不重叠的确认组。确认组 91,850 行、8,353 用户。三个固定检查点分别检查原两轮、共享＋携带、分轮＋携带；所有原生预测与无 hook 回放逐行完全一致，诊断前后权重不变，诊断无训练更新。

只在第二次工作 block 输入处移除或替换累积部分，保留第一轮预测状态 y1；这里改变的是整个 q2 输入，影响寻址、交互、残差，不是只改 attention query 的纯中介实验。令干预损失增量为 BCE(干预) − BCE(原生)，正值表示原生状态路径有益。

分轮＋携带模型：

| 干预 | 点击 BCE 增量 | 95% 区间 |
|---|---:|---|
| 移除全部首轮累积输入 | +0.000327797 | [0.000231004, 0.000410681] |
| 同长度分组内换成其他用户的累积输入 | +0.000135693 | [0.000013221, 0.000267972] |
| 交换已学习的两轮更新参数 | +0.000014845 | [0.000001785, 0.000027892] |

前两项支持点击预测使用了与当前样本有关的状态信息。第三项说明点击对轮次参数顺序有小幅依赖，但交换参数也改变第一轮预测状态，不能与 q2 单点干预等同，更不能单凭它推出训练收益。

原两轮模型移除累积输入后，点击 BCE 同样上升 0.000301938，区间 [0.000204574, 0.000394293]；因此这个有益路径并非新增分轮参数才出现。本轮没有直接检验两模型干预增量之差，不能从两个分别显著的结果断言新模型更依赖该路径。

购买任务方向相反：分轮模型移除全部累积输入后 BCE 变化 -0.000061216，区间 [-0.000106613, -0.000000697]；换入其他用户状态后也下降。边界很近且有多重比较，不应夸大，但不能只报告点击的正结果。加购、收藏的整体移除效应区间跨零。直接任务差值另有输出，其中 18 项是在看到参考模型点估计后补充，已标记为额外探索。

## 样本组与查询槽的差异

点击上移除全部首轮累积输入的损失变化：

| 实际有效历史长度 | 确认行数 | BCE 增量 | 95% 区间 |
|---|---:|---:|---|
| 0–1 | 1,663 | -0.000262135 | [-0.000618996, 0.000087315] |
| 2–10 | 7,810 | -0.000158587 | [-0.000389441, 0.000079402] |
| 11–50 | 31,483 | +0.000169951 | [0.000048593, 0.000295471] |
| 51–100 | 50,894 | +0.000519355 | [0.000379805, 0.000651688] |

这不是用“一个显著、一个不显著”推断异质性：长历史减去短历史的**直接差**为 +0.000677942，区间 [0.000403095, 0.000957714]；长历史减中等历史 +0.000349404，[0.000166779, 0.000541070]。当前检查点中，点击的状态路径价值确实随历史长度变化。但训练后分轮模型相对原模型的点击 BCE 改善在这些长度组间的六个直接差全部跨零，尚不能说新结构的训练收益也集中于长历史。

分轮模型四槽逐个移除的点击损失变化（槽从 0 编号）：

| 槽 | BCE 增量 | 95% 区间 |
|---|---:|---|
| 0 | +0.000036303 | [0.000011287, 0.000063732] |
| 1 | -0.000041601 | [-0.000068946, -0.000014294] |
| 2 | +0.000154107 | [0.000105563, 0.000197173] |
| 3 | +0.000097587 | [0.000055197, 0.000135525] |

槽 2 减槽 1 的直接效应差为 +0.000195708，[0.000146082, 0.000244218]，不是所有槽贡献相同。发现组独立选出的组合为 [2,3]；确认组中，联合移除的点击损失超过两个单独移除损失之和 0.000042321，[0.000018166, 0.000066215]，存在非加性。它描述当前网络的联合消融响应，不能直接等同于训练时协同的信息论解释。不同检查点的同编号槽没有已确立的相同语义。

这些结果支持“部分组／槽贡献更大，甚至方向相反”，**不支持“只有这些样本或槽才有效”**。短历史组的零效应未被证明；单个样本的观察标签损失正负也不是个体因果收益。加购、收藏、购买若干长度组正例少于 100，AUC 分组被明确标为不足；分组 AUC 只报告点估计，异质性区间基于 BCE。

## 开销与下一步判断

同一 A800、同一原生 1,024 行 batch、每模型 10 次预热和 40 次 CUDA event 计时。原两轮 14.1575 ms；分轮＋携带 14.3825 ms，增加 1.59%；参数 51,725,028 对 51,724,260，增加 768。这里只计模型前向，不含加载和输入 IO。三个检查点诊断共 7,200 次前向；延迟测量 300 次前向；两项统计各 500 次用户重采样，没有新增训练更新。

保留分轮＋携带作为**点击和状态路由研究候选**；保留共享＋不携带作为相对同协议 Cross8 提升的对照候选（macro AUC +0.004332，[0.001294, 0.007351]）。均不替换原两轮模型。共享＋携带、分轮＋不携带退出优化队列，原始结果继续保留。

下一轮最有根据的方向是：从原两轮模型出发，尝试有上下文条件的槽级／任务级累积门控，控制哪些信息进入第二轮，保持两轮和无预测反馈；使用等参数共享门控作对照。不能按本轮确认组结果直接固定“长历史开、短历史关”并在同一确认组上当作新验证。新候选应在训练数据上学习规则，并另留未用于本轮设计的用户组做确认。本轮不直接追加训练。

全部 273 个完整验证集区间、942 个诊断效应（含负值和不确定项）、覆盖计数与执行限制见 [EVIDENCE.md](EVIDENCE.md)、[full-validation-effects.csv](reports/full-validation-effects.csv)、[diagnostic-effects.csv](reports/diagnostic-effects.csv)。本轮调度器的路径类型错误发生在任何分析子进程前，已修复并保留失败记录；数值实现未改、训练未重跑。
