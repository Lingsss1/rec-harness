# 循环收益的任务差异：完整验证预测分析

**结论：目前支持“收益因任务而异”，不能归纳成“只有某类任务需要循环”。** 两组固定预测中，加购、购买的 AUC 收益相对点击更大；但 q8 同一 checkpoint 的四个任务均依赖第二轮。

复用 2,871,767 行、268,201 用户的已有验证预测，各组 500 次用户配对重采样，四任务及两指标使用相同权重；所有 95% 区间均为探索性描述，未校正多任务及历史模型选择，不包含训练 seed 方差。完整保留四个效果及六个差值。ΔAUC 为正有利，ΔBCE 为负有利。

## 如何理解

- q4 的加购−点击 AUC 效果差为 +0.002725，95% 区间 [+0.001051,+0.004522]；购买−点击为 +0.003903，[+0.001528,+0.006530]。这是直接差异检验，不是凭“一个显著、另一个不显著”推断差异。其他四个 AUC 效果差区间均跨零。
- q4 点击的 AUC 增量不确定，BCE 增加 +0.000163，区间 [+0.000108,+0.000223]；其余三任务 BCE 变化区间跨零。因此不能把排序改善直接称为概率质量或信息量改善。
- q8 四任务的 AUC 增量区间都为正，BCE 变化区间都为负。加购、购买相对点击的 AUC 效果差也为正。这说明收益大小有区别，同时该已训练模型的四任务都依赖第二轮。删除训练所需的整轮，并不等于独立训练一轮模型的性能。
- 两组对照的干预和模型不同，不合并成同一因果效应，也不据此给任务复杂度排序。尤其不能先指定点击读首轮、购买读末轮。
- 之前仅替换第二次 attention 概率的诊断，只支持保留 q4.buy 的重分配；其他任务不确定。这和完整第二轮消融的范围不同，不能互相替代。
- 固定输入下，重复计算可能暴露或更好地利用既有信号；本分析测的是预测收益，不测字面上的新增外部信息，也未验证具体的多步检索机制。

## 下一候选及其限制

保留原两轮和无反馈设计，比较原末轮读出、共享轮次混合、每任务轮次混合。共享对照用于区分首轮状态补充与任务专属自由度的价值。仍需验证同一模型的首轮状态是否能补充末轮，并计入首轮后处理的额外开销。这里只留下研究候选，没有训练新结构。见 [查重与设计说明](../recurrence-research/TASK_DEPTH_READOUT_NOTE.md)。

## 验证与开销

八项离线合成检查通过；q4 历史四任务及宏平均 AUC 区间精确复现。两组用户、行身份及 500 次抽样流一致。正式分析合计 199.510 秒墙钟、565.063 CPU 秒，峰值 0.987 GiB。零模型前向、零新训练、零新增训练 seed、零 GPU 时间，没有读取测试集。

BCE 使用保存概率原 dtype 的 epsilon 裁剪，并转 float64 计算 log/log1p；与源报告 logloss 的浮点路径差异在各结果中逐项记录。每次用户重采样用实际采到的行数归一化。源 AUC 全部在抽样前复现。
