# 根代理对本轮结论的范围与后续安排

本轮四个任务查询候选均丢弃，原最佳 psgd_precond_every_step（macro AUC 0.828623532520）和此前 q4/q8 候选保留原状态。四个相对各自原模型的宏 AUC 用户配对区间全部为负；前向延迟比为 1.7221–1.7517，均不符合预定接近候选门槛。完整数字以 [RESULTS.md](RESULTS.md) 和 [interpretation.json](reports/interpretation.json) 为准。

任务间反应不同是本轮可保留的信息。q4 共享查询相对原 q4 的点击 ΔAUC +0.001335387，95% 区间 [+0.000828810,+0.001827792]；购买 −0.003033478，区间 [−0.005055462,−0.001196829]。点击−购买的直接效果差 +0.004368866，区间 [+0.002371042,+0.006402966]。q8 task−shared 的 macro +0.001513842，区间 [+0.000768576,+0.002448654]，但两者仍差于原 q8；q4 的同一内部对照反而为负。任务条件化未成为整体改进，不能将内部相对收益改称原循环的信息增量。

所有 N 及既有循环结果都沿用原发布 action 的离线输入协议。独立的 [历史行为时间审计](../history-action-availability-audit/RESULTS.md) 发现抽样历史中大量行为标签窗口在目标预测时尚未结束；同一输入协议不证明这些最终标签在请求时已经可知。审计比例不是实际泄漏率或 AUC 受影响比例，正例事件也可能早已发生。模型构造参数前缀/RNG 和静态分组得到验证，不代表优化器轨迹匹配。区间仅描述固定 seed 所得 checkpoint 的用户抽样不确定性，没有新训练 seed 或多重选择校正。

后续 B 是 q4 的 released/mature × 独立训练 R1/R2 四格匹配对照。四格共用 19 类 action 词表、严格早于目标的历史支持、同秒排除且不补历史、相同初始参数和原训练预算。mature 对未结束窗口的三个行为同时隐藏正例与零标签，unknown 不等于成熟负例；click 保留仍依赖缺少事件/到达时间验证的假设。B 的新 released 也改变同秒支持，不能用历史 q4 分数替代。

核心问题是 D_released=R2−R1、D_mature=R2−R1，以及 I=D_mature−D_released；所有四任务和六项直接任务差都保留，交互区间在共同用户抽样内部计算。只有 D_mature 仍呈明确任务差异，才有依据继续优先研究哪些任务适合额外循环；I 本身也不等于泄漏造成的因果 AUC 或完整线上去泄漏效果。固定输入循环改变已有信息的提取与组合，没有新增外部观测。

截至本说明，B 只有模型/loader 源码与有界 CPU 合成验证；没有原数据读、checkpoint、GPU、优化器更新或正式训练。完整 runner/配置/资源协议与四组真实两步 smoke 尚未完成。原差值 z1−e 补跑已结束且无收益，见 [归档结果](../recurrence-query-difference-retry/RESULTS.md)，无需重跑。
