# 任务条件参与第二次检索：待本轮结果后选择

状态：只读源码与历史证据查重后的备选，未实施、未配置、未启动训练或诊断，也没有加入全局执行队列。本轮 R 的八组训练、协议、主指标和全部比较保持原样。不能用本文代替 R 的实际结果。

## 具体路径

共享首轮得到 `e,z1,y1`，保留 `x=(e+z1)/2`。每任务仅在第二次历史检索的 query 投影之后、原 head-wise q_norm 之前增加偏置：

```text
u = shared_w_q(x)
Q2_t = shared_q_norm(u + b[t].to(u.dtype))
b.shape = [4, 384], initialized to zero
```

历史 K/V 和 mask、原 `w_qi(x)`、工作层外部残差均保留。四个任务各有完整的 S 个第二轮工作槽、从共同 y1 开始的第二次预测更新，以及共享权重的最终 post；每个任务状态接原对应 task tower。首轮和第二轮之间仍没有 prediction→work 反馈。它不把原 S 个槽分配成任务槽，也不减少各任务原有的读出宽度。

新增 1536 个参数。第二次工作更新、第二次预测更新和最终 post 需要四份状态；入口、首轮和已有四个任务塔不需要全部复制。不能把这写成整个模型计算四倍，实际训练内存和延迟需另行测量。最先可审的实现保留每个分支原 B/S 形状，真实执行四个分支；共享 K/V 缓存或沿查询轴合并任务是以后才选择的性能实现，不能预称 kernel 或逐位结果保持不变。

## 必要对照与局限

对照也构造同样 `[4,384]` 参数并实际执行四分支，但全部任务使用 `mean(b, dim=0)`。任务偏置与共同偏置都必须对原父模型比较，不能只以两个新增结构之间的差异认定成功。相同参数形状和计算路径不等于相同有效自由度：共同偏置的四行梯度相同，任务偏置允许分化；新增参数、全局 clip 和 PSGDKron 分组及状态都可能改变优化轨迹。

BF16 投影不能直接加 FP32 偏置，否则会改变 q_norm 输入 dtype。偏置先转换为投影 dtype 是候选公式的一部分；零初始化仍需要实际初始函数检查，不能提前宣称逐位恒等。理想算术下，每个 head 内的常数方向会被 LayerNorm 去均值消除；浮点量化下不声称严格不变。本备选没有触发或执行 optimizer-layout shadow，也不声称保持原优化器动态。

这与已有[轮次状态的任务读出](../recurrence-readout-retrieval/QFormerCross8DepthReadout.py)、[查询混合](../recurrence-query-mixing/QFormerCross8QueryMixing.py)、[查询路由](../recurrence-query-routes/QFormerCross8QueryRoutes.py)、[轮次解除参数共享](../recurrence-research/ROUND_SPECIFIC_RETRIEVAL_NOTE.md)及当前 work relay 的位置不同：任务条件会改变实际第二次历史寻址，而非仅在共享检索完成后改变任务读出。查重由 query_design_audit 只读完成；根代理另外核对了原 w_q/q_norm/w_qi 和 task_queries→tower 接线。

## R 结果后的选择原则

如果 R 有达到既定保留门槛的候选，同时预定直接任务效果差显示值得解决的任务折中，这个方案具有更明确的决策用途。如果共享方案已均衡改善，优先巩固其结果和成本，不直接增加任务分支。如果 R 全部失败，也不以单个任务偶然上涨为由自动启动本方案；先重新比较其高计算成本和其他未覆盖路径的证据价值。

独立审查建议把“R 有保留候选且存在任务折中”作为优先触发条件。根代理将其视为排期依据，不作为科学上的必要条件：R 的共享槽通信失败不能证伪任务条件检索。现有[任务异质性证据](../recurrence-research/TASKWISE_RECURRENCE_EVIDENCE.md)只提供动机，没有证明梯度冲突、共享检索瓶颈或本方案的 AUC 收益。本轮结果出来前不扩展成更多变体、标量扫描或新的 GPU 队列。

## 训练、计时完成后的选择复核

R 的八组正式训练和全部计时现已完成，实际[训练与计时独立复核](reports/training-latency-independent-review.json)通过。八组 macro AUC 相对各自原模型均下降约 0.00185–0.00360，前向延迟增加约 7.9%–9.4%，全部不满足质量或接近候选门槛；十四项配对统计尚在进行。本节没有提前使用未完成的置信区间。

两次独立源码复核均建议先保留 q4/q8 各 shared-bias 与 task-bias，共四个有对应控制的配置。根代理采用这个范围：先完成 R 统计、解释和入账，再以独立新轮次检验任务检索条件。只胜过 mean 控制仍不足以成功，必须继续对各自原模型和实际成本判断。R 的共享槽传递失败降低了新增计算的吸引力，但没有测试任务检索；四组新比较可直接填补这一点。

还评估过 `q_norm((1+a_t)*W_q(x)+b_t)` 与其 mean 控制，二者都是零初始化 `[4,384]` 条件参数，新增参数合计 3072。它不是任意标量扫描：非均匀增益可以改变方向。但 shared affine 是此前[完整第二 W_q 解共享](../recurrence-readout-retrieval/QFormerCross8RetrievalUntied.py)所含的一种受限行缩放/平移；本地已有负结果，当前优先问题仍是任务条件本身是否值得引入。因此不把这一档加入下一轮。如果以后加入，任务效果是否因 affine 改变必须直接比较交互差，不能比较两个显著性标签。

文献复核只提供设计动机：[DMN+ §3.3](https://proceedings.mlr.press/v48/xiong16.pdf)以问题和先前记忆共同决定相关性；[MAC §2.2](https://arxiv.org/pdf/1803.03067)让读取同时接受控制状态和先前内容，但自然语言问题分解与这里四个固定任务不同。二者均没有孤立验证本候选的第二 `w_q` 偏置。

根代理另读 [FiLM §2.1、§4.3](https://arxiv.org/pdf/1709.07871)：其视觉推理实验分别训练只有平移、只有缩放与完整仿射条件，说明这两种功能值得区分；不能将其 CNN/语言条件下的表现迁移成 LayerNorm 前任务查询的收益证据。这次查阅没有改变先做四组 bias 的选择，也没有触发新训练、诊断或 memory 入账。
