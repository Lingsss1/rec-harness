# 先浅后深：共享工作块的轮内深度

用户要求“先浅后深跑一轮”。按结构深度解释：在现有最佳dynamic_write基础上，第一轮1次共享工作attention，第二轮2次，即1+2。加入等计算的2+1反序对照。不是训练课程或epoch深度调度。

两个新训练shallow_deep/deep_shallow；复用旧dynamic_write的1+1及Cross8保存结果作参照，无新训练seed。原始发布数据17动作、无mature、width256/q8、两轮、PSGDKron每步LR1e-4、sparseAdagrad .05、clip1、BF16、seed20262027、2193步保持一致。

每轮先读取两流得到u，同一个原layers[1]连续调用depth次、每次都读相同原历史；轮内后一调用接收前一调用输出。然后以最终raw-u为该轮净更新做原动态写入和静态读取/旁路处理。每轮只有一次router评估、一次预测读取；预测不反馈工作状态。入口和末尾模块不变。参数与1+1完全相同；两组工作块总调用数均为3，比1+1增加50%工作块调用，但不等于全模型增加50%耗时。

零门控时与深度匹配的普通去反馈循环检查BF16精确一致，不能要求与1+1输出相等。离线显式两流前向和全参数梯度oracle覆盖1+1/1+2/2+1；构造RNG及原参数保持一致。两个smoke各2步通过后正式各1epoch。不自动重试。

四个保存模型、六个两两对照、每组21指标，共126个区间。500次共享用户聚类bootstrap、固定统计seed20260906；source AUC与用户/物品/标签/长度对齐先验检查。主要顺序效应为shallow_deep与deep_shallow直接差值；相对1+1的差值混有增加计算效应，单独说明。验证集已反复用于探索，单seed区间不包含训练随机性、未做多重校正。四个模型同卡同批1024行，10预热+40计时=200forward，测量不训练。
