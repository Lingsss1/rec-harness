# 本轮结论

动态写入 macro AUC 0.827959464，相对同批原始 Cross8 +0.001899385，配对用户95%区间[0.001038694, 0.002825773]；相对去反馈基线+0.004769994，区间[0.004031924, 0.005570935]。保留为原始Cross8设置下的优化候选；同卡推理开销+14.7%，没有全局最优替换。

加购AUC增量+0.004712783，区间[0.002903390,0.006679058]。点击、收藏、购买AUC区间仍包含零。加购增量与点击/收藏增量的直接差值区间均高于零，但与购买增量的差值区间包含零。因此可以说有任务差异，不能说只有加购有效。

全部动态相对Cross8+0.000792359，区间[-0.000131732,0.001670609]。合并两流相对全部动态-0.002341719，区间[-0.003124778,-0.001534416]；这是全部动态模型中的结构对照证据，尚不能迁移成最佳动态写入模型的机制证明。

统计为单训练seed、500次配对用户重采样、28组未做多重校正的探索性比较，不反映训练seed波动。全部任务和空结果见RESULTS.md及原始统计JSON。下一轮设计见MECHANISM_NOTES.md，尚未启动新训练。
