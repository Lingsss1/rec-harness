# 下一步可证伪的问题

当前 dynamic_write 的含义是写入系数依赖输入；读取和旁路仍有可学习静态系数，不等于关闭读取/旁路。单凭该组高分不能证明多流状态本身有效。

第一轮两流相等，因此读取差值和旁路混合项恒为零；第一轮动态写入产生两流差异。第二轮的写入最终通过两流均值进入预测，写入系数之和可以表现为残差更新幅度调节。这提供了更便宜的替代解释：收益可能来自更新门控，不一定来自保留两条可区分状态。

优先的匹配训练消融：

1. dynamic_write 仅第一轮使用输入相关写入，第二轮保留静态写入。
2. dynamic_write 仅第二轮使用输入相关写入，第一轮保留静态写入。
3. collapsed_write：第一轮预测后合并双流，其他与 dynamic_write 相同。
4. tied_write：两流使用相同动态写入增量，区分平均更新调节与差异状态控制。
5. dynamic_write 的读取、旁路静态系数固定为零，检查是否依赖额外静态路由协同。

固定当前原始发布数据、宽度256、q8、两轮、seed、优化器和2193步，不引入mature，不增加训练seed。现有 dynamic_write 和 Cross8 保留为匹配参照；若运行环境或基础配置变化，须单列不可直接比较的因素。这里仅为下一轮设计，尚未启动这些新训练。

保存模型上的关门或合并干预可检查依赖，但有分布外干预风险，不能替代重新训练的结构消融。当前验证集已用于选模型，后续同一验证集结果属于探索性证据，不称独立确认。
