REC · LR 02
第二次 LR · 货架电商 CVR · 迭代过程

Loss 连续加深仍未增益，迭代方向可能错了

① IPS / 全空间校正先纠正曝光选择偏差，结果没有稳定超过 Base。
② DR 误差修正同时建模观察误差与填补误差，仍受高方差影响。
③ SNIPS 归一化对 propensity 权重归一化，缓解极端权重但未解决根因。
④ Imputation Tower增加全空间估计与 stop-gradient，复杂结构仍未带来确认增益。
迭代信号：四轮都在回答“Loss 怎么更精确”，但没有回答“每个 batch 是否有足够正例可学”。

最终定位：batch 512 平均不到 1 个 CTCVR 正例

×
batch 512期望正例数仅约 0.7
→

控制变量：把 batch 提升到 4096 后，期望正例数约 5.6；先改变可学习信号，再比较 Loss。

最终排查结论

不是“公式还不够复杂”IPS、DR、SNIPS 与 Imputation 已充分延伸。
不是只看最终 AUC 就能发现AUC 无法显示 batch 内正例供给。
需要内部诊断视野样本计数、激活与梯度状态应进入 Agent 上下文。
诊断口径：CTCVR 正例率约 0.14%；期望正例数按 batch size × positive rate 估算。
这一页只讲定位，不提前报效果。先算 512×0.14%≈0.7，再算 4096×0.14%≈5.6。结论是训练信号供给不足，不是继续堆 Loss。

REC · HUMAN × AGENT
两轮 LR 的共同结论

两轮 LR 形成分工：Agent 做深，人重定义问题

Agent｜方向内高吞吐LR1 快速证伪调参、Cross 与 a2a；LR2 完成 IPS、DR、SNIPS、Imputation。
Human｜重定义问题LR1 改变交互作用位置；LR2 从 Loss 公式转向 batch 样本充分性。
Harness｜扩展信息半径保留成功与失败路径；下一步让样本、激活和梯度诊断进入 Agent 上下文。
配图：Agent 信息半径 Before / After；内部诊断系统化接入是下一步方向，不计入本次已完成结果。
这页才给人机协同结论。Agent 的优势是沿一个可检验方向快速做深；人的价值是根据失败证据改变问题定义；Harness 的作用是让两者共享完整历史和诊断，而不是让 Agent 单独取代人。

规则 01

未 OPEN，不能 KEEP

阻止模型引用没有真正读取的文档。

规则 02

未 KEEP，不能引用

答案的证据链可以机械回放与审计。

规则 03

重复请求自动短路

不重复消耗搜索预算，状态转移保持确定。

价值：每次 interaction 都有明确的 state diff，训练反馈可以绑定到具体动作，而不是只给整条轨迹一个模糊终局分数。
