Importance Estimation for Neural Network Pruning

Molchanov et al.，CVPR 2019｜一句话：把 2017 的 Taylor 通道分数系统化为一阶/二阶、跨层可比较的结构重要性估计，并用真实移除损失校验。

Taylor-FOTaylor-SO>93% 相关性

1. 问题与“真值”

目标不是解释一个样本，而是回答：移除参数或结构单元 m 后，最终 loss 改变多大？论文把可靠但昂贵的真值定义为实际移除所造成的损失变化（以平方消除正负）：

Im = [ L(W | wm=0) − L(W) ]²

对每个单元都真正置零并评估，复杂度太高；于是用当前训练中已有的梯度/曲率做代理。

2. 一阶与二阶推导

标量参数的一阶近似。令 δwm=−wm：
ΔL ≈ gm δwm = −gmwm ImFO = (gmwm)²
结构单元/神经元。若 S 是一个 filter、channel 或结构组，联合置零的正确一阶项是先求有符号和再平方：
ISFO = ( ∑i∈S giwi )²

不要随手改成 ∑|gᵢwᵢ|：那会消除组内抵消，回答的是另一个问题。

加入曲率。
ΔL ≈ −gSTwS + ½ wSTHSSwS ISSO = (ΔL)²

完整 Hessian 不可承受，论文讨论利用二阶近似/经验 Fisher 等可计算形式。二阶更贴近非线性，但内存和估计噪声更高。

与 Activation × Gradient：若把干预对象从权重 w 换成中间激活 z，同一推导直接得到 (∑z·∂L/∂z)²。因此它不是另一套理论，而是相同 Taylor 干预估计在不同变量上的实例。

3. 关键工程增强

问题论文思路/工程含义
跨层尺度不同分数要基于统一的损失变化定义并适当归一化，避免每层单独手调敏感度。
BatchNorm 重参数化可围绕 BN 的缩放/偏置参数计算 Taylor-FO-BN，使一个 channel 的门控更明确。
单批次梯度噪声在多样本/多 minibatch 上累计贡献；排序稳定性比一次分数更重要。
一次删太多导致近似失真迭代少量移除，并在剪枝间微调；论文是贪心闭环，不是“一次算完永久有效”。

4. 证据强度与边界

相关性校验

论文在 ImageNet 现代网络上，把估计贡献与可靠的真实重要性估计比较，报告 超过 93% 的相关性。这是“排序代理接近实际移除”的直接证据。

端到端剪枝

在 ResNet-101 上报告移除约 30% 参数、降低 40% FLOPs，而 Top-1 准确率损失约 0.02%；同时比较多种剪枝基线。

外推限制

相关性来自视觉结构化剪枝，不代表推荐多任务网络的神经元分数必然也有 93%。必须在本模型用实际 shuffle/ablation 重新做 rank calibration。

5. 用在当前精排模型的算法

# Phase A: 一次反传得到候选排序
for batch in stratified_batches:
    outputs, acts = model.forward_with_hooks(batch, modules)
    L = weighted_multitask_loss(outputs, labels)
    grads = autograd.grad(L, acts)
    for module, z, g in zip(modules, acts, grads):
        score[module] += square(sum(z * g, within_unit_axes))
score = average_over_samples(score)

# Phase B: 干预校准，不训练模型

推荐同时算总 loss、各任务 loss 与业务离线指标。梯度分数的平方方便与论文重要性一致；若关注促进/抑制方向，另存有符号项。

6. 为什么仍需要 Shuffle

Taylor 是一次局部近似，能同时扫描大量单元；Shuffle 是实际前向干预，保留该神经元的边际取值集合、打乱与样本的对应关系，用来测模型对“样本特异信息”的依赖。

二者回答略有不同：置零/Taylor 近似“移除信号”；shuffle 近似“保留分布但破坏信号对样本的对齐”。如果两者一致，证据更强；若不一致，本身就是诊断信号——可能存在均值偏置、饱和、交互或分布外干预。

7. 局限/失败模式

  • 大幅、成组干预时高阶项不能忽略；Top-K 单元联合 shuffle 也不等于分数相加。
  • 在训练收敛点，权重梯度可能接近零；激活梯度通常更适合部署后诊断，但仍有饱和。
  • 多任务总 loss 的权重决定排序，业务关键任务可能被低权重淹没。
  • BatchNorm、LayerNorm、残差与尺度重参数化会影响 raw score，须层内对照与实际干预。
  • “重要”只表示当前 checkpoint 的依赖，不直接导出扩容、剪枝或冷启方案。

8. Leader 尖锐问答

Q1：2019 相比 2017 新在哪里？

从通道经验准则升级为统一的损失变化定义，系统推导一阶/二阶估计、跨层排序和 BN 版本，并直接报告与真实移除重要性的高相关性。

Q2：>93% 是不是能直接作为我们方案有效性的证据？

只能佐证 Taylor 排序在论文的 ImageNet/网络条件下有效。我们的推荐模型、loss 和干预不同，必须把梯度排序与实际 shuffle/消融的相关性作为本地验收门槛。

Q3：二阶一定比一阶好吗？

不一定。二阶理论更完整，但 Hessian/Fisher 估计贵且噪声大。诊断阶段先用一阶粗筛，若一阶与干预相关性差，再对少量候选引入 IG、HVP 或二阶估计更划算。

Q4：为什么分数要平方？

论文把重要性定义成损失变化的平方，以消除方向并惩罚大变化。若我们还关心模块让哪个任务变好/变坏，需要同时保存 signed ΔL 估计，不能只留平方。

Q5：梯度小是不是就不重要？

不是。可能是饱和、冗余补偿或当前 batch 不覆盖触发场景。低分结论必须经过跨时间分桶和低分 shuffle 对照。

Q6：如何避免挑 Top-K 后“自证循环”？

预注册 K、指标、样本窗和显著性规则；同时运行同层随机、Bottom-K、等规模模块对照；在独立 holdout 时间窗复验。

Q7：高敏感模块的优化动作是什么？

先分类原因：容量瓶颈看宽度/梯度冲突；异常依赖看特征泄漏/尺度；关键但脆弱看归一化和稳健训练。诊断只缩小搜索空间，不自动给唯一处方。
