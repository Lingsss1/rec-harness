EXECUTIVE ANSWER

一句话说清“为什么有效”

两个项目的共同点不是都用了某个 Attention 或某篇论文，而是先通过失败簇定位真实缺口，再只补那个缺口。

最佳结构 = 机制补全 × 正确位置 × 可训练统计 × 梯度边界

短视频命中“关系缺失”：原始历史 item 之间没有交互；货架命中“估计器失效”：IPS 被 clip 退化、DR 辅助梯度污染共享表征、极稀疏正例让 batch 内统计量不可用。

BEST STRUCTURES

最终结构：改在哪、为什么刚好

切换两张卡片对照。每张都把“改动位置—机制—证据—边界”放在同一屏里。

六路原始行为序列商品点击、商品曝光、商卡视频曝光等实时序列
→
每路 1 层 Self-Attention先让历史 item 彼此交互，补上序列内二阶关系
→
MLP → 32d + LayerNorm每路受控压缩，六路共新增 192d
→
Concat → Share-bottom后续虚拟 Token、HSTU、残差与多任务头保持不变
改动 1 · 对称补齐六路

不是只在某一路做特例；所有缺少序列内交互的实时序列使用同构分支，避免信息通道能力不一致。

改动 2 · 放在聚合前

如果先被 Target Attention 或 MLP 压成一个向量，历史 item 间的局部关系已不可逆丢失。

改动 3 · 主干不动

共享主干与预测任务保持不变，把收益更可信地归因到“原始序列交互”这一变量。

为什么它有效

  1. Target Attention 建模 candidate→history 相关性，不等于 history↔history 依赖。
  2. HSTU 接收的是主干压缩后的虚拟 Token，不直接看到六路原始 item 序列。
  3. Self-Attention 在压缩前补关系，MLP 32d 与 LN 再控制容量和尺度。
  4. 所以它增加的不是泛化的“更深网络”，而是此前不存在的可辨识关系。

前面的版本为什么不过

  • 调参/优化器：只能改善已有目标的训练，不能创造缺失关系。
  • ML-DCN：增强的是已拼接、已压缩表征上的 Cross，位置偏后。
  • a2a：提供更多特征信号，但仍没有显式表达原序列内部 item×item。
  • 因此连续失败不是“白跑”，而是把搜索逐步逼到真正空白。

A · SNIPS 替代硬阈值 IPS

clip=0.1 时约 80% 点击样本撞下限，权重几乎恒为 10；clip=0.01 又导致方差爆炸。SNIPS 让权重尺度随 batch 分布自适应。

B · 隔离辅助塔梯度

Imputation 塔读取共享特征，但入口 stop-gradient；双稳健修正留在 loss 层，共享表示由 CTR/CVR 主任务更新。

C · 512 → 4096

这不是普通调参，而是估计器能否工作的统计前提。A/B 在 512 下仍不过 Base，单改 batch 后才首次翻正。

pCTCVR = pCTR · pCVR   |   w_raw = click / clip(pCTR)   |   w_SNIPS = w_raw / stopgrad(mean_clicked(w_raw))

为什么它有效

  1. SNIPS 保留不同 pCTR 样本的相对校正，又控制朴素 IPS 的权重尺度。
  2. DR 用 Imputation 估计误差，再用可观测点击样本残差修正，降低只靠一种估计的风险。
  3. stop-gradient 将“辅助估计”与“主表示学习”解耦，避免同量级梯度污染主干。
  4. batch 4096 提供约 5.7 个联合正例/批，使 batch 内估计不再频繁退化。

为什么小 batch 会误判方法

  • 正例率约 0.14%，batch 512 的期望联合正例仅约 0.7。
  • 很多 batch 没有或只有极少正例，SNIPS 均值、DR 残差与 CTCVR 学习都高噪声。
  • Memory 曾据此把方向标成 rejected；人的追问指出“配置是否支撑机制”仍未验证。
  • 保留方案、只改 batch 复跑，使 CVR/CTCVR AUC 约提升 0.3pp，修正原结论。

正例充分性小实验

拖动 batch size，直观看 0.14% 正例率下的期望联合正例数。它不是每批固定值，但能揭示训练制度是否合理。

MODEL BRIDGE

LR 与“对应模型”怎么拼起来

模型代码回答“系统原本怎样计算”，LR 回答“哪一处机制被证明值得改变”。不要混用版本号。

短视频模型：改原始序列支路，不改主干任务

答辩结构显示：稀疏/统计/历史序列先处理并拼接，进入 Share-bottom MLP、虚拟 Token、HSTU、残差合并与 CTCVR/CTR 任务。

  • 原 HSTU 的输入不是六路原始行为 item。
  • 最终改动落在序列聚合前：Self-Attention → MLP 32d → LN → concat。
  • 保持下游不动，让实验更接近单变量归因。

商品卡 v31：骨架证据与 LR loss 证据互补

v31 代码页描述 10,900d 宽输入、三路 Target Attention、96d bypass 和独立 CTR/CVR 双塔；货架 LR 最终页描述 ESCM²-DR-SNIPS 与 Imputation 修正。

  • v31 解释 prediction backbone 与三项 loss 的基础关系。
  • LR 解释如何修正点击选择偏差、权重方差与辅助梯度。
  • 二者可以联合学习，但不能声称 v31 就是 LR 图中的 v20-SNIPS。
最稳妥的答辩说法：“我用模型代码还原了主干的数据流，再用 LR 的实验链定位改动层级。短视频的收益来自表征结构补全；货架的收益来自目标估计与训练统计制度修正。版本材料来自不同快照，所以我只合并机制，不强行合并版本号。”

“做了什么”要讲成决策贡献

不是把 Agent 的所有动作都归到自己名下，而是明确你在哪些关键节点提供了研究判断与上线闭环。

01

搭建长周期 ReAct

把假设、代码修改、训练、指标解释和 Memory 更新串成可重复实验单元，让单次试验能跨版本积累。

02

用失败簇决定切路

让 Agent 在既定方向内高吞吐延伸；当同类变体密集失败时，由人判断是否已经到达路径边界。

03

提出关键反事实

追问 HSTU 实际处理哪一层表示，以及 ESCM² 失败是否只是 batch 内正例不足，把隐藏前提变成可检验变量。

04

完成证据闭环

不仅看离线 AUC，还校对线上曝光、消耗、预期花费、分层流量变化，并保留结论适用边界。

EVIDENCE HYGIENE

事实、推断与边界分开说

点击筛选。面试里主动区分三层证据，可信度会明显高于只报结果。

Fact

六路各加 Self-Attention

每路再经 MLP 压缩到 32d、LayerNorm 后拼入 Share-bottom，共新增 192d。

Fact

512 → 4096 后翻正

正例率约 0.14%；复跑后 CVR/CTCVR AUC 约 +0.3pp，完整实验口径 +0.29pp。

Inference

命中的是缺失机制

DCN/特征增强失败与插入点差异共同支持：短视频收益更可能来自原序列关系补全，而非通用增容。

Inference

曝光下降是预算重排

曝光降、消耗和预期花费升，且损失集中于低价值用户，支持“更精准 CVR 改变流量分配”的解释。

Boundary

v31 ≠ v20-SNIPS

两份材料来自不同模型/版本快照。可连接其机制层级，不应声称是一份完整累计代码链。

Boundary

相关增益不是普适定理

不能由本项目推出 DCN 永远无效、SNIPS 总优于 IPS，或扩大 batch 必然提升任何稀疏任务。

DEFENSE SCRIPT

答辩时这样讲

先给判断，再给机制、实验和结果。避免从版本流水账开始。

90 秒项目讲稿

“我做的两条 LR 都不是直接堆模型，而是用长周期 ReAct 找到结构真正缺失的机制。短视频项目里，连续的 DCN 与特征方向没有收益，我回看数据流后发现 HSTU 处理的是主干压缩后的虚拟 Token，六路原始行为序列只有候选引导的聚合，没有 item 之间的交互。因此在每路聚合前加一层 Self-Attention，再用 MLP 压到 32d、LN 后拼入主干，下游任务不动，离线 AUC +0.09pp，短视频场景预期花费 +2.084%。

货架项目里，表征增强和 NISE 失败后，我们切到 ESCM²。初版在 batch 512 下被判无效，但我追问 0.14% 正例率是否让 batch 内估计失效：每批期望只有 0.7 个正例。保留 SNIPS、DR 和 Imputation 梯度隔离，仅把 batch 调到 4096 后，CVR/CTCVR 约 +0.3pp，货架整体预期花费 +1.488%。所以我的核心贡献是把 Agent 的高吞吐实验变成可审计的决策链，并在路径切换、未验证前提与线上归因上提供关键判断。”

高频追问自测

如果 Self-Attention 有效只是因为参数更多，你怎么证明是“缺失关系”而不是容量？

不能仅凭一次正向实验完全证明。当前最强证据是：多组同类增容/Cross 变体未增益；最终改动发生在信息被压缩前；下游主干不变。进一步严谨验证应做参数量匹配的 MLP 对照、Self-Attention Shuffle/Zero、只开部分序列的消融，并比较等 FLOPs 条件下的收益。
