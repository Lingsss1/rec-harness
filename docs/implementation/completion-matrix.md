## 接续工作

Amazon 开发记忆导出已增加[控制器冻结锁校验](amazon-memory-lock.md)，在读取 study 前拒绝配置变更或缺锁。真实 Amazon v3 两次只读导出与原记忆完全一致，源配置与事件链未变化。

Amazon 独立开发记忆已补齐[来源信息 v2](amazon-source-memory.md)：从设计卡绑定原始引用及未核验/版本未知状态，导入时重算并核对，确认信息不导出。它不是论文正文核验，也不伪造原始图快照。

通用图记忆新增[来源转移 v4](source-memory-transfer.md)，保留 Method→Source 及未核验/版本未知状态，容量门控仍按完整闭包执行。普通图继续导出 v3，旧包不改写；Amazon 使用上述独立的来源信息 v2。

新任务已补齐[方法—来源图关联](method-source-graph.md)：通用模型及 Amazon 开发图创建 Source/DERIVED_FROM，并保留论文方法的 origin。原始引用可追溯，内容与版本仍显式未核验；来源不充当本地实验或机制支持。

新模型任务已增加[方法卡来源准入](method-source-admission.md)：无可定位来源的 `paper_claim` 在实现前拒绝，来源不足的想法仍可作为 Agent 假设研究。此门槛只校验标识，不等于论文内容级验证；旧冻结合同保持兼容。

Amazon 新拒绝记录已接入[优化器失败轨迹](rejected-role-traces.md)：保留拒绝原因和真实传输状态，原始无效响应仅作引用；测量转交排除被拒角色，避免把流程失败当成模型缺口。前缀与旧格式边界通过测试，尚未开展新的真实优化器任务。

Amazon 失败角色已补齐[拒绝事件即时归档](amazon-rejection-archive.md)，包括返回草稿；校验提交输入与拒绝原因绑定，不依赖后续人工重开。旧历史拒绝事件不补造档案，新路径经过模拟角色和恢复测试。

失败生成的原始产物继续补齐：[返回工作区草稿](returned-agent-workspace.md)在隔离执行结束后、响应准入前单独保留，覆盖非法 JSON 和未完成源码。草稿不作为可训练或可晋升实现；新增成功传输路径已有上述真实工具调用验收，失败/超时分支仍由工程测试覆盖。

工具/Harness 生成档案已补齐[正常及失败调用的事件/CAS 绑定](evolution-generation-archive.md)。新工具演化任务默认冻结启用 Codex 内置搜索，显式禁用仍生效；工具来源记录使用实际响应合同支持的源码说明与 limitations。历史配置和收据不回写，真实论文路线及内容级核验仍待验收。
