# 诊断执行与测量提交之间的恢复

诊断启动前记录 `diagnostic_submitted`，绑定测量身份、作业序号、费用任务和实际输入/运行配置 hash。若 CPU 进程已经完成而控制器尚未提交 `diagnostic_completed`，后续恢复通过 `recover_completed_cpu_job` 核验原输入、进程终止收据和收集产物，再完成测量提交，不另开作业。

测量输出从已验证的内容寻址产物读取，而非可修改的 `results/measurement.json` 副本。已结算或被控制器按中断保守结算的原费用保留，不重复扣费；尚在运行态的预留仅结算一次。记录提交后的重复读取仍保持事件和费用不变。

没有成功终止证据、输入不匹配或旧作业缺少提交身份时停止，保留原成本和文件，不把观察失败当作重新执行的许可。正常执行失败仍形成 invalid 测量；该变化不将失败结果升级为成功。

定向检查覆盖进程完成后测量提交前中断、结果副本修改不改变收据结果、未知结果禁止重跑、进程输入被改后拒绝且费用不变。既有 CPU 收据恢复检查负责活进程/失败进程的拒绝。此前真实 jail 验收只证明完成记录后的重复读取；本次控制器提交中断路径暂由故障注入测试覆盖。
