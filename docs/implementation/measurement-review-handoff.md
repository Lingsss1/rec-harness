# 测量审查输入随工具转交保留

自主测量审查能使用已提交的激活和 block-score 聚合观测。过去工具开发转交只带 GapCard、基础 Experiment 分数及审查响应，导致工具作者无法看到审查曾引用的完整公开观测。

`measurement_gaps.evolution_context` 现在从触发缺口之前唯一匹配的 `measurement_reviewed` 事件读取并校验原始 `input_ref`，将完整输入作为 `measurement_review_input` 交给工具作者。另附输入 hash、审查事件身份和用途说明。核对 task、protocol、model、审查结论、缺口要求，以及激活/block-score 观测与触发前图快照的一致性。输入来自 CAS，不从最新控制器上下文或未来结果重建。

旧档案没有绑定的审查输入时保留原有响应范围，不补造历史输入。预声明缺口没有自主审查时保持原语义。既有冻结工具 campaign 不重写；新工具初始化冻结这份扩展上下文。

这些数据是工具开发证据，不代表运行时权限：`public-aggregate-measurement-v1` 仍只提供公开开发评分行，不提供激活数组、checkpoint、原始历史或新观测。需要这些输入的工具不能据此声称可执行或已验证。本改动不扩大出站材料授权，也未发送任何新材料。

测试使用真实事件链、图和 CAS，以及脚本审查响应，覆盖精确输入保留、未来观测隔离、只读重复导出、输入篡改及错误模型绑定拒绝。它不是新的真实自主缺口或工具效用验收。

验证：测量发现、自动控制器、项目联合调度与优化器转交共 41 项测试通过（54.928 秒）；公开目录边界、语法与 diff 检查通过。没有新增 Codex 调用、真实推荐训练或工具晋升。
