# 后继研究中的工具注册信息

诊断工具激活时，除源码快照和验证计划 hash 外，还冻结 `validated-diagnostic-registration-v1` 注册摘要：入口和输入输出契约、验证适用条件、六阶段通过记录的报告 hash、声明的每次调用成本，以及注册表内的可回退候选。

摘要随实际诊断记录进入后继研究，并保存在对应 `ToolVersion` 节点。报告 hash 指向源注册表的已提交验证依据；摘要不复制验证分数或评估样本标识，也不作为独立模型效果或机制证据。

`source_tool_predecessor` 表示增量生成使用的源码前驱，`rollback_candidate_id` 表示同一注册表中实际存在的上一发布版本。跨 campaign 继承源码不会凭空建立本地回退目标。旧冻结配置没有注册摘要时继续按原格式执行，旧节点不被追写。

项目级连续两次工具更新测试检查六阶段引用、前驱源码、调用成本、本地回退空值，以及冻结配置、诊断事件与工具节点的一致性。验证结果详见对应提交记录。
