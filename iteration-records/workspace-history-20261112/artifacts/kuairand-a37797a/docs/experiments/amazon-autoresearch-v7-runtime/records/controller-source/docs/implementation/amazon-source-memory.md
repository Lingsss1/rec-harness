# Amazon 跨轮记忆的论文来源信息

Amazon 自动研究使用独立的开发记忆格式，通用图包 v4 不会自动扩展它。此前这里只传设计卡中的来源字符串，没有显式保留来源的未核验状态。

启用 `require_method_sources` 的新任务，在导出论文方法时生成 `method_source_provenance`：绑定完整方法卡 hash，保留去重后的原始引用及引用 hash，标为 agent_reported_unverified、source_version unknown、retrieved_content_ref null。这个记录来自设计卡，不伪装成独立审稿、原始论文正文或已有 Source 图快照。

含该记录的包使用 `amazon-development-memory-v2`；没有记录时继续输出 v1。v2 校验重新从设计卡计算应有的来源记录，要求完全相同。改写“已验证”状态、替换引用、删除记录，即使重新计算包 hash，也会被拒绝。v1 不接受新增来源字段，旧冻结任务不补造来源核验。

导入后的上下文压缩保留该字段，开发读数仍通过原有引用与 seed 检查。来源信息不产生机制证据，不升级历史结论，也不包含确认或最终测试结果。

34 项相关测试通过，覆盖导出幂等、来源绑定、上下文保留、篡改拒绝、确认排除、旧格式与 Amazon 项目/控制器恢复。使用合成设计卡和虚构引用，没有新增真实 Codex 调用、训练或科学效用结论。

完整核心检查通过：公开边界、语法及 451 项测试（430 项通过、21 项环境条件跳过）。源码变更尚未纳入 v18 安装包。
