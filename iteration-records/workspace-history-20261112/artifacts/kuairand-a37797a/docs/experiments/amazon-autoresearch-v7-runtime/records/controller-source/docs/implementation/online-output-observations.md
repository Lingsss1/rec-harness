# 在线合成研究的模型输出观测

小型隔离任务可在冻结协议中显式启用：

```json
{"output_activation_observations": true}
```

主机从同一次独立训练的两份可复现预测收据计算最终标量输出的数量、均值、RMS、标准差，以及按第一个输入特征正负分组的输出均值和数量。空分组不捏造均值，限制中明确说明。计算不需要额外训练或推理；工作计入原评估费用。它不是隐藏层激活、块级干预或机制证明。

观测生产器的文件hash在任务/在线套件中冻结。主机核对两份预测CAS、重复性与原主机指标，然后保存公开摘要、实验血缘和当前模型身份。初始基线的实验编号如 `baseline-0` 与模型编号 `root` 分开处理；后续保留候选后的观测属于新的incumbent。无效训练或不一致收据不能产生有效观测。

公开行使用dataset标签 `synthetic-output`，通过已实现的 `public-observation-measurement-v2` 输入合同供工具读取。角色和工具只获得聚合量及scope/limitations，不获得验证目标、权重或逐样本预测。所有组都启用相同冻结协议，因此无工具、现有工具与候选工具三组看到同一类基础观测；派生工具执行继续单独计费。原有未启用此选项的协议不新增字段或执行。

内置在线工具验证现在能在每轮生成新模型观测，并检验消费这些观测的工具。选用v2时在 `tool_runtime.contract` 声明合同，reference、shadow、online三个套件仍必须匹配。这里只覆盖合成任务的标量输出观测；不能据此声称Amazon内部激活/块级工具的在线效用已经完成。真实推荐任务的独立在线验证和工具自主发现实例仍需后续证据。

新增4项测试覆盖解析统计量、空分组、输入配置/生产器hash、预测收据一致性，以及开发和确认各自两轮三组控制器。后者实际执行模型train/predict与诊断worker函数，角色与CPU启动器为夹具；验证新incumbent身份、角色送达、零增益比较和终态无新增执行，不算真实Codex效用实验。519项全量回归通过，零跳过，141.203秒。

真实CPU证据位于 `rec-harness-runs/online-output-observation-v1/cpu-acceptance.json`：两个独立隔离模型进程加一个v2工具进程，主机独立复算与工具输出RMS均为约0.1787726947。公开请求CAS及全部源代码hash已绑定，缓存复用未增加执行或费用；无Codex调用、Amazon训练或GPU任务。首次配置因使用普通示例guardrail在启动前被拒绝，零作业；初始脚本和目录保留，修正配置后在新目录完成验收。
