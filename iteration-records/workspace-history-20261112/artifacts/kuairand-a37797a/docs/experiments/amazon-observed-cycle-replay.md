`amazon-observed-cycle-replay-v1/acceptance.json` 已通过实际隔离验收。来源为输入嵌入偏移候选的完整七角色恢复周期，world hash 为 `7385666c099bc44f36a97d12727e2355415dbcb9fd0adf6dddfa5502da3408e7`。旧固定训练档案仍为 audit_only，本入口没有为其补造研究上下文。

转换器重新审计开发矩阵、角色事件和成本账本，保留实际角色上下文、源码和收据。根部基线 HR@10 0.5535 必须与设计前可见数据一致；候选原分数 0.5540、选择 discard，故周期后的选中分数仍为 0.5535。政策不能绕过原门槛将其晋升。

历史资源向量为 study 7672.274366401136 GPU 槽位秒、其中本候选 1194.4143040701747 秒，以及 campaign 累计 11 次 CLI 调用（包括四次历史失败）。验收显式选择两个回放系数均为 1，故回放预算为 7683.274366401136 单位；这不是新的 GPU 消耗，也不是货币价格。CPU/token 成本不包含在此预算内，原事件账本仍是成本审计来源；world 不等同于完整运行环境备份。

同一确定性策略、seed 42，在两个独立非特权、禁网络的策略进程序列中得到完全相同的报告和轨迹。完整 world 未挂载，首个输入不含候选节点或分数。预算少一个单位时，周期不会被揭示；新源码动作返回 unsupported。重复转换完全一致，源控制器与 study 事件头不变。没有新增 Codex 调用、训练或模型推理，没有读取最终测试。

首次隔离尝试使用的旧策略运行时缺少 runtime_hashes，执行前失败，记录保留于 `acceptance.log` 和 `replay-a/failure.json`。随后创建含逐文件哈希的新运行时 runtime-v2，成功结果保留于 replay-a-v2、replay-b-v2。产品入口现会在初始化时明确拒绝该旧格式，而不是关闭校验。

支持范围为继续一个已观察周期或停止，不能模拟新提示、工具、模型源码、周期内另一角色决策或并行 GPU 调度。这证明真实档案可在明确边界内回放，不是在线效用、更多任务条件、完整多周期 world 或最终测试验收。
