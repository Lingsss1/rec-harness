# 显式研究 Skill 身份与传输

方案 §5.5 要求优化器能核对角色使用的 Skill 版本。新传输支持按角色配置 `role_skills`，每项仅含 `name` 和 `content`；正文属于冻结配置，直接进入 Codex 的实际 stdin 提示词。不是通过声明版本号推断曾读取某个主机文件。

直接和隔离 Codex 共用校验：角色必须存在、名称合法且同角色内不重复、正文非空。复制输入以隔离调用方后续修改。没有 Skill 时仍生成原 v1 指令收据；有 Skill 时生成 v2，记录顺序、名称与正文 hash。

请求归档保留完整正文，归档读取重新核对提示词尾部、prompt hash、schema hash 与显式 Skill hash。只改版本元数据或正文、未同步实际传输提示词会被拒绝。通用及 Amazon 的决策轨迹从核验后的归档提取 `skill_versions.explicit`，不将其插入旧的角色可见上下文。

配置覆盖通用模型、Amazon、工具/Harness 演化和 Harness 前缀验证。只改变显式指令传入，不新增角色调用。自动 Skill 发现和实际执行仍未知；附属文件、依赖、路径解析及安装的 Skill 发布不在此接口内。

针对性测试覆盖直接传输 stdin、隔离传输失败时保留请求、正文篡改拒绝、非法配置、真实事件/CAS 轨迹投影，以及未配置角色的 v1 兼容。测试中的进程和角色使用桩，不声明新的真实 Codex 验收。

验证：完整源码回归 456 项全部通过、零跳过，87.446 秒，启用 Torch 与 Linux OS 测试。收据和日志位于 `explicit-role-skills-v1` 运行归档。本轮新增 Codex 调用和真实推荐训练均为 0；尚未纳入 v19 安装包。
