# 优化器测量转交保留可见观测

优化器基于决策轨迹提出 MeasurementGap 时，原接口仅投影开发评分与既有诊断输出，丢失了角色可见的激活和 block-score 聚合。因此既有量可能再次被建议为“缺失测量”，工具作者也看不到原解释的限制条件。

新接口在每条 `trace_evidence` 中保留原有 `activation_diagnostics` 和 `block_score_diagnostics`。仅接受当前模型、已提供开发类别/seed 条件下的完整公开观测字段；观测量须为有限数值，并保留 scope 和 limitations。不接受额外私有路径字段。诊断前置失败或观测不符合合同的轨迹不进入可转交证据。

主机拒绝将引用轨迹里已经提供的观测量再次提议为缺失输出。有效新量仍须通过已有前置条件、缺口与独立验证合同。`load_context` 从冻结配置和已提交转交事件导出这些证据，不重新查询来源的当前状态，不扩大工具运行时输入权限。

26 项相关测试通过：原测量发现、优化器转交和 Amazon 准入 25 项，以及新增已提交转交的只读重复导出测试。覆盖原值和限制保留、已有量拒绝、错误模型/条件、非有限值、失败状态和私有字段拒绝，以及中断恢复。

真实 Amazon v3 历史只读检查：7 条角色轨迹中 5 条满足转交准入，重复投影完全一致，36 事件的来源链未改变。该历史没有激活/block-score 行（0 条），因此不能把它当成本次新增观测字段的真实传输验收。收据在 `optimizer-observation-handoff-v1/acceptance.json`。本轮新增 Codex 调用和训练均为 0。
