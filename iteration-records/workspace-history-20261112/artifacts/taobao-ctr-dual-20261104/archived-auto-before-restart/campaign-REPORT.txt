研究问题：Does restricting the explicit multiplicative block in the target-aware scorer improve validation ranking without changing learned capacity? Source inspection verifies q=target_category+target_brand and h=history_category+history_brand+action+recency, so q*h ties same-field, cross-field, and target-context terms into one block. This structural restriction is observed; harmful interference is only a hypothesis. Across the nine supplied successful trajectories ordinary DIN remains incumbent (AUC 0.6133619861190683, Logloss 0.19679464647483236). Full/half DIN count corrections reach 0.6131714801466076/0.6131537617707302 with worse Logloss; half pooling improves its own reference to 0.6108065192309597 but remains below DIN. DIN versus pooled AUC gains are +0.0026743907094257 on category_match_present (2516922 samples,129821 positives) and +0.0002617449892484 on category_match_absent (717129 samples,29616 positives). These exploratory differences motivate checking relevance construction but do not diagnose this mechanism. New source access permits a distinct, bounded intervention; the prior request for normalization replication remains unresolved because seed variation is not exposed. No further count coefficient tuning.
机制假设：Removing off-diagonal category-brand products from the explicit fourth scorer input can impose a useful field-consistent relevance bias. Independently removing target-action/recency products may help or harm; the primary both-removed candidate and two single-removal controls separate those factors. This changes which multiplicative statistics are supplied to the existing nonlinear scorer, not event counts, input availability, or value aggregation. No higher-rank theorem, new discovery, or local benefit is asserted.
相近工作差异：Use four standalone modules with identical Model.__init__ and parameters: ordinary_product flags A=0,B=0 returns q*h exactly; cross_only A=1,B=0 returns D+q*(a+r); context_only A=0,B=1 returns q*(c+b); primary same_field_product A=1,B=1 returns D=q_c*c+q_b*b. No learned gates, extra tokens, changed embedding widths, extra labels, new features, normalization change, seed override, optimizer or loss change. Floating-point association differs between decomposed products. The first three scorer blocks remain summed and action/recency still affect scoring and values, so this is partial explicit-product restriction only. Label-free diagnostics compare all four product settings at each same frozen checkpoint, separately from retrained-arm outcomes; 512 ordered rows and encoded-ID-match caveats apply.
