终止后复盘：问题与下一轮可检验缺口

状态：原实验继续保持终止。本文件不授权启动实验，不修改个人知识，也未加入任何研究 Agent 的输入。

一、核心问题
增强循环产生了更多研究产物，但缺少把这些产物转为实验动作、候选资格、预算分配和分支退出的控制机制。当前数据不支持“记忆一定有害”或“auto 不会局部停留”的结论。

优先级 P0：运行与证据接口
- 给 replicate、probe、switch_branch、freeze_candidate、finish_search、cancel 分别定义可执行动作。当前研究作业固定 seed42，分析中的 seeds43/44 复核请求无法兑现；STOP 跳出研究循环后仍可进入最终评估，不能代表安全取消。本轮实际停止使用了单独的冻结/终止流程，没有因此新增评估。
- 把执行故障、准入错误、科学负结果、用户终止和正常完成分开。主机错误由主机修复，禁止把“修复读取器”的责任写成模型改造反馈。
- 保留最高单次观察、已复核候选、当前研究分支父模型三个独立状态。重复结果和反例可改变证据等级，不能只在长文本中提醒，而机器仍锁定最高单次 AUC。
- 在研究中开放事先受预算约束的配对重复。模型种子重复与独立 Agent 轨迹重复分别统计。固定源码/配置/种子重放都漂移的候选先做有限的固定状态探测；未解决时标为待查，不无限全量重训。

优先级 P1：搜索与知识
- 同时保留少量机制不同的候选问题；每次说明当前主问题、最强替代解释、最能改变选择的实验，以及继续/换方向的条件。
- 为分支分配可执行的预算和退出条件。停滞应结合新增机制证据、预测质量、成本与剩余资源判断，不能简单规定连续几次未涨 AUC 就放弃，也不能永久深挖。
- 将事实、解释、反例和下一步建议分层。事实保留，解释可被后续结果修订，下一步建议随阶段过期。检索应能找出反例和替代问题，避免所有问题都由当前解释继续展开。
- 按需反思：矛盾、显著结果、分支停滞和阶段结束时反思；稳定的重复对照只记录变化。将不可变协议、旧证据通过 ID 引用，减少每阶段重复叙述。
- 让行业方案首先提供可检验的前提和探测方法，而不要求立即采用其架构。成立条件不清时可以设计低成本探测；明确不适用时保留拒绝原因。
- 反思记忆与多路径探索是不同设计维度。相近工作包括 Reflexion 与 Tree of Thoughts，不能把已有组件组合本身当创新；本场景的价值须通过等起点、等预算的工作流消融检验。

优先级 P1：诊断与评测
- 独立固定状态 probe 接口，支持少量训练批次的输出/梯度/更新检查，避免每次正确性诊断都执行完整训练。
- 将固定前512条候选诊断改为受控的分层样本或全验证流式统计。分组包括历史长度、目标匹配支持、行为覆盖和训练用户频次，预先固定采样规则并报告分母。
- 对已有最佳路线先做多种子、关键对照及统一设备成本复核；不把重复使用同一个验证集得到的细小优势当稳定收益。
- 不通过重新划分或重换种子宣称恢复独立测试。当前提前评估、重跑和中途修复应持续披露；本数据上的回测仅能补稳定性诊断。
- 成功分别衡量：模型质量、机制证据、与已有方案的差异、资源成本。对照分支胜出是有价值结果，不应包装成原复杂机制获证。

二、模型侧的三个候选问题

A. 固定计算预算下的历史压缩（优先调查）
新元数据诊断：验证集3,234,051条曝光中，2,774,063条（85.7767%）的因果可用前缀超过128条，中位长度460；模型只读取最后128条。诊断仅使用历史起止索引与验证日索引，未读标签或测试样本。
问题：旧行为和不同类型行为的证据是否因最近截断丢失？截断普遍并不等于旧行为有效。
候选机制：保留近期原始事件，并用类目/品牌、行为类型和时间摘要表示较老事件，在固定 token 或计算预算内提供更完整的证据。不需要历史商品 ID，也不引入数据没有的消费额/停留时间。
对照：最近128、同覆盖范围的分层采样、同覆盖范围的无行为语义摘要、加入相同旧信息的简单因果统计。所有对照享有同样的原始历史可见范围。
否证：优势在对齐覆盖范围或加入简单旧历史统计后消失；或预处理、存储、检索成本抵消模型阶段收益。
最近工作：DGIN 已有分组、统计与动态摘要；原始 item_id 等字段假设不完全适合本数据。这里是待核查的适配/机制差异，尚无新颖性结论。
协议：下一轮搜索前重新声明并冻结历史输入协议，不能与旧的 last128 结果直接当成同信息量比较。

B. 有效统计的低成本表示（优先整理已有证据）
事实：auto最佳模型 AUC0.6209488，验证推理记录33.52秒；DIN为0.6133620/16.01秒。已有 r0027-latest_endpoint 为0.6208079/27.92秒，说明可能已有更便宜的近似质量点；不同执行时段的计时须统一重测。
第一步：做统计族消融、去除重复计算/排序、比较参数量和统一成本，先建立可靠的效率基线。这些工程变化不能当新建模贡献。
后续机制假设：训练时以因果统计作为辅助监督，让较小历史编码器学习可用的强度和顺序表示，推理时移除昂贵的精确统计分支。
对照：轻量骨干、直接统计输入、真实统计辅助任务、同预算的打乱/无关辅助任务。预处理和辅助训练的成本全部计入。
否证：在同质量要求下没有端到端成本优势，或效果只来自额外参数、训练量或通用正则化。

C. 紧凑的目标条件语义读出（保留未完成假设）
r0040完整语义池化向量退步，不能直接推出语义补充无用；r0042 的 relevance_dot/relevance_magnitude/relevance_projection 因用户终止未取得完整结果，不能记为科学失败。
候选问题：将类目/品牌与分行为历史池化的关系压缩成少量目标相关性读出，是否比加入完整池化向量更易利用？
对照：点积相关性、只读幅度、固定历史投影，匹配输入维度和参数；预声明低精确匹配支持切片，报告样本量与两项指标。
否证：未稳定胜过等容量对照；收益只在未经预声明的小切片，或成本不可接受。
这是一条已有未完成假设，不是本次复盘新提出或验证的创新。

短历史是适用边界，不宜直接设计复杂路由
auto最佳在1—16历史切片的AUC0.5734566，DIN为0.5745702，但Logloss改善（0.1556692 vs0.1575900）。该切片41,805条、1,444个正例，尚无多种子稳定性。此前固定长度回退和部分支持掩码控制均未证明有效。先复核指标权衡和支持差异，再决定是否值得建立新路由机制。

三、建议推进顺序
1. 完成 P0 状态机与证据接口，验证用户取消、故障、配对重复均按声明执行。
2. 复核少量现有参考与关键对照，建立质量/成本基线；不立即扩大搜索。
3. 对上述不同问题做有限、预声明的可区分探测，比较它们能否提供新增证据。
4. 对有支持的方向开展连续机制研究；无支持或超分支预算时保留反例并换方向。
5. 用等起点、等调用/时间预算对比事实记忆与解释性记忆，独立重复 Agent 轨迹；不能用本轮两条路径作记忆因果结论。
所有任务字段、方向、知识卡、分支预算和接口权限放在外部合同及运行器，固定 Agent 指令保持通用。个人知识继续关闭。
