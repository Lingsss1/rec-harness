2.3. Representative Models
2.3.1. Stacked Unified Interaction
This paradigm arranges sequential modeling and feature interaction as consecutive modules. The sequence module first encodes the behavioral history, and the feature interaction module then combines this representation with user, target-item, and context features.
•
HiFormer (Gui et al., 2023) pools the behavior history with target attention, tokenizes heterogeneous fields and task queries, and applies hierarchical HiFormer blocks to the stacked tokens.
•
RankMixer (Zhu et al., 2025) pools the history with target attention, tokenizes concatenated ranking fields into chunks, and alternates parameter-free Token Mixing with per-token MLPs.
•
Zenith (Zhang et al., 2026) separately embeds user and item identifiers, pools historical item attributes with target attention, tokenizes context and target attributes, and applies Zenith interaction blocks.
•
TokenMixer (Jiang et al., 2026) combines target-aware sequence summaries with global and group tokens, then applies reversible token mixing and per-token feed-forward networks.
•
UniMixer (Ha et al., 2026) flattens histories with user and context fields, then chunk-tokenizes them for UniMixing-Lite blocks.
•
HeMix (Wang et al., 2026) combines fixed and feature-conditioned queries with low-rank token mixing over recent and earlier histories.
•
SSR (Yu et al., 2026) uses target-attention sequence pooling and multi-view competitive sparse filters with dense fusion.
2.3.2. Layer-wise Unified Interaction
This paradigm integrates sequential and non-sequential representations throughout every network layer.
•
OneTrans (Zhang et al., 2025) injects sequence and partitioned non-sequential tokens into every block, using mixed attention, a shared sequence FFN, and token-specific FFNs.
•
HyFormer (Huang et al., 2026b) encodes the sequence per layer, decodes global queries, and enriches them with non-sequential tokens.
•
MixFormer (Huang et al., 2026a) mixes non-sequential queries, uses cross-attention to retrieve information from the updated sequence, and fuses the resulting representations.
•
INFNet (Li et al., 2025b) organizes categorical, sequential, and task tokens around a hub for layer-wise aggregation and broadcasting.
•
EST (Liu et al., 2026) uses cross-attention to sequence representations and feature-specific feed-forward layers.
•
TokenFormer (Zhou et al., 2026) represents fields, histories, and targets as tokens with full interaction and sliding-window Flex Attention.
•
LONGER (Chai et al., 2025) encodes local groups with inner Transformers and joins compressed long-term history with recent queries.
•
UltraHSTU (Ding et al., 2026) extends HSTU-style sequential transduction (Zhai et al., 2024) with hybrid attention that combines sparse and full attention in each interaction layer.
