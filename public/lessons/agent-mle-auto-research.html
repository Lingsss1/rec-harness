01Agent-as-MLECode Tree SearchStateless Memory

AIDE

把机器学习工程重写成“在代码空间里优化一个可执行解”的问题。它不维护一段无限增长的对话，而是维护解树：每个节点是一份脚本，每条边是一次 Draft、Debug 或 Improve。

Memory 关键：Σ(T) 只抽取分数、超参和调试线索，注入 Draft/Improve 提示；节点本身保持自包含。

02Agent-as-MLEMCTSSelective Memory

ML-Master

AIDE 证明了代码树搜索有效，但“把整棵树摘要给模型”仍然可能造成上下文污染。ML-Master 用 MCTS 式多轨探索，并只把父节点与同深度兄弟节点的经验送入推理过程。

Memory 关键：只读直接父节点和同层兄弟节点；父节点提供纵向因果链，兄弟节点提供横向反例。

03Agent-as-MLEWeb RetrievalTargeted Refinement

MLE-STAR

MLE-STAR 不从空白内部知识开始，而是先从 Web 检索任务适配模型，再用消融定位最值得改的代码块。外循环选组件，内循环只深挖该组件，解决“每轮都重写全管线”的粗粒度探索问题。

Memory 关键：外循环读取历史消融摘要以减少重复选块；内循环读取同一组件的历史尝试作为反思反馈。

04Agent-as-MLEPolicy × OperatorScoped Memory

AIRA

AIRA 的价值不只是一套更强 Agent，而是把 Agent-as-MLE 形式化为“搜索策略 × 算子集”。论文证明：换成 MCTS 或进化搜索并不会自动变强，算子和 Memory 作用域必须与策略共同设计。

Memory 关键：Draft/Improve 读取当前节点的 children/siblings；Debug 读取整个祖先调试链。

05Auto ResearchOpen-ended LoopArchive

The AI Scientist

The AI Scientist v1 把自动科研从“某个子任务”扩展为完整生产线：Idea → Novelty Check → Code/Experiment → Plot → Paper → Review，并把完成的 idea 与 reviewer feedback 加回档案库。

Memory 关键：下一轮 idea 读取历史 archive；实验阶段读取当前执行历史和 journal；写作阶段读取结构化 notes 与 figures。

06Auto ResearchProgressive TreeExperiment Manager

The AI Scientist-v2

v2 去掉人工代码模板，并把线性实验升级为四阶段的渐进式树搜索。Experiment Manager 在阶段边界选择 checkpoint、重复关键实验，并用专门节点管理超参、消融、复现与聚合。

Memory 关键：子节点继承父节点 artifact；Manager 读取整阶段候选的结构化摘要；超参/消融清单用于查重。

07Auto ResearchMulti-roleTop-program Pool

Agent Laboratory

Agent Laboratory 用角色分工而不是单个全能 Agent：PhD、Postdoc、ML Engineer 与 Professor 分别负责文献、计划、实验、解释和写作；mle-solver 维护 top-program pool，paper-solver 维护可编译的论文。

Memory 关键：每个角色只读取其职责需要的阶段上下文；mle-solver 读取 top pool 与有限错误历史，paper-solver 读取计划/结果/文献。

MEMORY BLUEPRINT

三层 Memory 设计

最常见错误是把全部历史拼进 prompt。更稳的做法是完整保存 artifact，再为不同角色和操作动态生成有限视图。

Artifact Memory · 事实层代码、commit、配置、日志、指标、图、review。只追加、可复现，是最终证据源。
Episodic Memory · 轨迹层parent/sibling、操作、假设、结果、失败原因。支持 lineage、对比和恢复。
Semantic Memory · 规律层从多次实验蒸馏的经验、禁忌和适用条件；必须保留 evidence pointer 和置信度。
ExperimentMemory { artifact: {commit, config, logs, metrics, plots}, episode: {parent, hypothesis, operator, outcome, failure_class}, semantic: {claim, scope, confidence, evidence_ids}, views: {debug_lineage, improve_siblings, reviewer_global} }
核心原则

Memory 的“存储”与“提示词读取”必须解耦。原始记录永不被摘要覆盖；Debug、Improve、Reviewer 分别读取不同视图。

RECOMMENDED READING ORDER

推荐阅读顺序

做工程 Agent：AIDE → ML-Master → MLE-STAR → AIRA。先理解 artifact tree，再分别看 memory scope、组件归因、policy × operator 联合设计。

做自动科研：The AI Scientist → AI Scientist-v2 → Agent Laboratory。先看端到端 archive，再看阶段化树搜索，最后对比多角色与 top-program pool。

做 RecHarness：优先精读 AIRA、ML-Master、AI Scientist-v2；它们分别对应 Router/Skill 联合设计、局部记忆视图和阶段 checkpoint/replay gate。
