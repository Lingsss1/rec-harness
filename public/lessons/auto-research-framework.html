REC HARNESS · RSI · BEGINNER'S GUIDE

从零理解 RecHarness

它是一组帮助 Codex 长期优化推荐与排序模型的研究 Skills。目标不是让 Agent 更忙，而是让每一次诊断、失败和 GPU 实验，都提高下一轮研究决策的质量。

先抓住一个比喻

Codex 是研究员，GPU 工作区是实验室，诊断工具是仪器，Memory 是实验记录本；RecHarness 让四者在证据约束下形成闭环。

1 个根 Codex开放推理与最终判断
3 个公开 Skills诊断、记忆、工具演化
2 个改进对象模型能力与研究能力
1 个外部工作区训练、数据与评估

四个词，建立共同语言

理解架构不需要先读 Agent 论文。后面的算法，本质上都是让这四个角色可靠协作。

Agent

会行动的模型

读取状态、选择下一步、调用工具、观察结果并继续行动。这里就是 Codex。

Harness

外部研究规程

包住 Agent 的状态、工具、证据格式与门槛，让开放推理可复现、审计和回滚。

RSI

递归式自我改进

Recursive Self-Improvement：用上一轮工作产生的证据，改进下一轮解决问题的方法。

Skill

专业工作流

规定何时触发、读什么输入、如何处理、输出什么，以及哪些结论不能越界。

与普通训练脚本的区别：脚本执行固定算法；Agent 决定下一步；Harness 保证“决定—执行—证据—记忆”不断链。RecHarness 位于 Codex 与训练平台之间，不是训练平台本身。

普通 Agent 为什么难做长程研究？

单轮想出一个改法不难。难的是几十轮后仍能分清事实、解释、失败原因和可复用规律。

另一条研究线：Bandit 如何分配实验预算

当前三 Skill RSI 是正在探索的能力演化方案；Bandit-Routed Harness 是另一条仍然重要的研究方法。它不负责诊断或记忆本身，而是回答：在候选很多、GPU 预算有限时，下一批实验应该投向哪里？

STABLE SEARCH SPACE

Arm：宽而稳定的方向

例如表征几何、特征信息、交互结构、监督目标。Arm 数量慢速变化，用于跨很多轮积累方向级先验。

→

GENERATOR OUTPUT

Idea：Arm 下的具体机制

生成器主要产生 Idea，而不是每次新建 Arm。例如“对某层加正交约束”属于表征几何 Arm。Idea 可快速增加、去重、验证和淘汰。

→

EXECUTABLE CHOICE

Candidate：可运行候选

把 Idea 变成明确代码改动、预计收益、信息价值、成本、风险、最小实验和证伪条件，才进入昂贵预算竞争。

为什么 Idea 必须位于 Arm 下面

如果每个新 Idea 都成为一个 Arm，生成器会让 Arm 无限膨胀：历史样本被摊薄，后验无法积累，新方向还会凭高不确定性长期抢占探索预算。稳定 Arm 提供慢速方向先验，Idea 层负责快速试错，兼顾知识迁移和创新。

VANILLA THOMPSON SAMPLING

标准 TS 在做什么

对每个 Arm a： θ̃ₐ ~ Posterior(θₐ | history) 选择 a* = argmaxₐ θ̃ₐ

每轮从各 Arm 的成功率后验抽一个可能值，既偏向历史表现好的 Arm，也会因不确定性探索样本少的 Arm。二元收益时常用 Beta(α,β) 后验。

REC HARNESS BANDIT

不是“纯 TS”，而是分层受约束组合

U(c)=P(win | Candidate, Idea, Arm) × conservative_gain + λ × information_value − μ × cost − ν × risk

即使内部采用后验采样，最终也要考虑跨场景保守收益、信息价值、实验成本、风险、承诺连续性和组合槽位。因此更准确叫层次化、成本感知的 Bandit Portfolio。

SLOT 01Commit

完成已经承诺的最小调查预算，避免每轮追逐新 Idea。

SLOT 02Exploit

选择现有证据最强、保守预期收益为正的候选。

SLOT 03Explore

选择不确定性或信息价值高、成本可控的新机制。

SLOT 04Diagnose

用一次实验解决关键歧义，为后续多轮减少错误选择。

层次化后验怎样更新

一次 Candidate 结果： Idea posterior ← 强更新（直接检验该机制） Arm posterior ← 弱更新（只提供方向级部分证据） Crash / OOM ← 更新成本与执行风险，不把科学假设记为失败 Invalid run ← 不更新收益后验

弱更新 Arm 的原因是：一个具体实现失败，不等于整个宽方向错误；强更新 Idea 则能快速淘汰局部机制。多场景收益通常取较保守的一侧，避免只在单个数据集刷分。

Bandit 研究线解决“选哪个”

把历史结果、不确定性、收益上限、信息价值和成本压缩为有限预算下的序贯选择；适合候选已经结构化、奖励可比较的阶段。

当前 RSI 尝试解决“凭什么选、以后会不会更会选”

Diagnostic Toolkit 提供内部证据，Memory 保存长期规律，Tool Evolver 补齐测量盲区。它们可以反过来给 Bandit 更好的特征、先验和信息价值估计。

二者的组合位置：三 Skill 是研究能力层；Bandit 是可插拔的预算选择层。理想闭环是“诊断与 Memory 产生更好的 Candidate 表征 → Bandit 分配下一批实验 → 结果回写 Memory → 测量缺口触发 Tool Evolver”。当前公开代码重点展示三 Skill 路线，不代表 Bandit 方法被否定或删除。

三个模块：作用与算法

诊断只生产测量；Updater 只决定什么跨轮保留；Evolver 只验证新的测量方法。职责隔离避免一次相关性同时污染工具、模型和长期结论。

01

Diagnostic Toolkit

回答“模型内部发生了什么”。消费框架无关数组或结构化表，不依赖 TensorBoard、KML 或指定训练平台。

WHY定位机制

最终指标只能判输赢。

INPUT三类输入

Embedding、Hook NPZ、配对干预表。

PROCESS多级证据

几何、健康度、AXG、Shuffle/Zero。

OUTPUT可审计报告

JSON、Markdown、排名与区间。

算法 A：四类表征坍塌

Zc = Z - mean(Z) Centered Energy = mean(||Zc_i||²) → 完全坍塌 Mean Pairwise Cosine → 方向集中 Effective Rank = exp(-Σ pₖ log pₖ) → 维度集中 类内/类间距离 → 类条件或局部坍塌

多指标是必要的：方差可能漏掉“有幅值但同方向”，平均余弦又可能漏掉少数奇异方向承载全部信息。

算法 B：Activation × Gradient 只做候选筛选

AXG(hook, objective) = mean(|activation ⊙ gradient|) 仅比较同一 objective、同一可比层组；选择等宽 Top / Middle / Bottom。

它近似局部敏感度，表示当前模型是否依赖信号，不代表扩大模块一定提升验证指标。

算法 C：配对 Shuffle / Zero 推进到干预证据

同一 batch、权重与 seed：Δᵢ = metric(originalᵢ)-metric(perturbedᵢ) 汇总 mean(Δ)、block-bootstrap CI、P(Δ>0)、跨 seed 稳定性。

Shuffle 破坏对应关系但保留边际分布；Zero 同时改变信息与尺度。两者配合区分依赖、冗余与偏置/尺度效应。删除模块仍需重训练。

02

Harness Updater

回答“多轮实验教会了什么”。默认演化 Memory，不持续重写工具、Prompt、训练代码或评估协议。

WHY防止失忆

上下文窗口不是数据库。

INPUT完整运行摘要

改动、指标、诊断、成本和失败。

PROCESS慢速合并

逐轮记账，按触发器更新知识。

OUTPUT下一策略

Lesson、Avoid、Plateau 与队列。

results.tsv快速账本
episodes.jsonl不可变摘要
failures.jsonlCrash/OOM/Invalid
lessons.json条件性知识
strategy.jsonIncumbent 与队列

算法 A：运行状态与科学结论分离

keep=指标与护栏过门；discard=有效但不优；provisional=预注册调参窗口； crash=执行失败；invalid=协议不可比较。

所有状态追加历史，只有 keep 替换 incumbent；discard 恢复旧代码。Crash 和 Invalid 不能评价科学假设。

算法 B：触发式 Consolidation

触发：5 个有效实验 / 两次独立同机制证据 / incumbent 改善 / 连续 3 次未改善 / 重复失败 / 假设族耗尽 / 人工检查点 文本梯度：observation → mechanism → bounded change → falsifying metric

Lesson 必须带适用范围、支持 Episode、反证、置信度和证伪条件。两次独立结果才 supported；机制证据与重训练一致才 confirmed。

算法 C：检索式上下文

下一轮只读 Strategy、最近 5–10 个 Episode、匹配当前模块/指标的 Lesson 和相关 Failure Avoid。完整日志用稳定 ID 按需追溯。

03

Diagnostic Tool Evolver

回答“缺失哪种观测才能更快决策”。它不为一次性格式处理或论文新颖性制造工具。

WHY补测量盲区

重复歧义持续浪费 GPU。

INPUT决策合同

缺口、目标决策、基线与预算。

PROCESS文献与验证

比较论文、隔离实现、预注册门槛。

OUTPUT晋升决定

accepted / rejected / synthetic-pass。

先写决策合同，再搜索论文

observed ambiguity → missing information → decision it could change → cheapest falsifying test

缺口必须影响实验选择/预算、现有工具无法回答、Artifact 可合法获得、预计可复用，而且能预先定义增量价值。

01Paper Fidelity方程与参考输出
02Synthetic注入信号与负对照
03Robustness边界与确定性
04Shadow Data两种真实条件只读
05Utility胜过两类基线
06Cost运行与维护可接受

为什么六级门槛缺一不可

论文正确≠实现正确；合成正确≠真实模型有用；产生新指标≠改善决策。最后比较的是能否减少错误实验、缩小候选或更早发现无效前提。

一个失败实验，如何走完闭环？

假设精排模型加入更深交互层后 AUC 未提升。点击步骤，查看每一阶段的输入、输出和算法边界。

STEP 01 · OBSERVE

先把“没涨”拆成可比较事实

记录代码身份、训练预算、指标、Guardrail、运行状态和成本。此时不能直接得出“更深交互无效”。

输入

Baseline 与新模型的同协议结果。

输出 / 决策

有效但未改善的 Episode；进入 Diagnose，而不是盲目调参。

核心规则

运行结果与科学解释分离；OOM、Crash、Invalid 都不能直接证伪机制。

它不是什么

当前公开实现比旧版概念图更克制，以下三点是准确描述项目的关键。

不是独立多 Agent 平台

不创建永久角色或新的 Agent Runtime；Codex 只在任务独立、有界时使用原生子 Agent。

本质是 Codex 原生 Skill 组合。

不只有 Thompson Sampling

Bandit 研究线可以使用后验采样，但还包含 Arm–Idea 分层、成本/风险/信息价值效用和四槽 Portfolio；当前三 Skill RSI 则是并行探索的能力层。

两条方法可组合，不是互相替代。

不是训练与数据平台

不包含业务模型、内部数据、Checkpoint、GPU Controller 或项目专用训练实现。

用户工作区负责执行与最终验收。

零基础常见问题

如果只记住这里的答案，也能正确描述 RecHarness。

RSI 是让 Agent 修改自己的模型权重吗？

这里主要改进研究流程：诊断工具、长期记忆和下一假设。基础 Codex 模型本身并未被 RecHarness 训练。

为什么不把全部历史塞进 Prompt？

历史不断增长且含冲突与过期结论。结构化 Memory 能检索相关部分，并通过稳定 ID 回到完整证据。

为什么诊断不能直接决定模型赢家？

诊断回答内部依赖与几何状态；模型选择回答重训练后的泛化表现。前者缩小搜索，后者才最终验收。

什么时候才值得演化新工具？

同一盲区反复影响实验选择、现有工具无法回答、Artifact 可获得，并能预先定义“怎样证明增量价值”时。

目标不是自动产生更多 Idea，
而是提高每一个实验的信息收益。

Codex 保留开放判断；诊断把内部状态变成证据；Memory 把多轮成败变成经验；工具演化再把反复缺口变成经过验证的新能力。模型与研究方法因此一起进步。
