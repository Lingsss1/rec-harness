整场答辩的总叙事

两项工作不是割裂的：都在研究如何把模型迭代变成可验证、可复用的闭环。

30 秒版本

“我的核心工作，是提升模型迭代的有效性与可信度。”

RecHarness 解决有限实验预算下“往哪里搜、如何复用历史经验”，并完成线上业务验证；UA-OPD 解决蒸馏中“哪些局部监督真正可学”，虽然最终证伪了加权假设，但定位出 Cold-Start 与数据分布对齐才是关键控制变量。

2

RecHarness：有限预算下的推荐模型自进化

必须能同时讲清：为什么需要 Bandit、LLM 做什么、Memory 做什么、何时 Jump。

一句话：RecHarness 把“选择优化方向”和“生成具体代码修改”解耦：Bandit 用验证结果分配实验预算，LLM 在选定方向内提出假设并修改代码，Experiment Skill 跨轮沉淀成功与失败经验。

2.1 三层控制结构

Level 1 · Human Context

人定义目标、验证指标、合法边界与候选 edit arms。人不逐轮手工调参，但保留目标与风险控制权。

Level 2 · Bandit Router

根据各 arm 的历史成功/失败验证反馈维护后验，决定有限 trial 投向哪些方向。

Level 3 · Skill + LLM

LLM 读取 incumbent、日志、趋势和 Experiment Skill，在选定 arm 内生成假设、代码 patch 与实验。

2.2 为什么不是“让 LLM 自己选方向”

自由 LLM 搜索的问题

  • 方向开放，容易重复、发散或被近期文本反馈带偏。
  • 每次候选都要生成、训练、验证，错误探索成本高。
  • LLM 对 exploration/exploitation 的概率校准不稳定。

Bandit 的价值

  • 把验证分数压缩为显式后验状态，跨轮积累证据。
  • 优先利用高潜 arm，同时保留对不确定 arm 的探索概率。
  • 方向选择可审计，代码生成仍保留 LLM 的开放能力。

2.3 Thompson Sampling 与成功信号

对每个方向 a：θₐ ~ Beta(αₐ, βₐ)
每轮从各后验采样 θ̃ₐ，选择 Top-G 个 arm 并行实验。
成功后：αₐ ← αₐ + 1；失败后：βₐ ← βₐ + 1。

局部 trial 成功需同时满足：候选可执行、组内标准化增益 > 0、且不低于历史 incumbent。

注意：后验不是假设 arm 具有永恒固定成功率，而是当前 incumbent 与上下文下的局部证据，用于预算分配。

2.4 Incumbent、Memory 与 Jump 的分工

机制解决的问题答辩表达
Incumbent promotion只有验证指标提升的可执行候选才能成为下一轮基线。避免搜索退化，保证 best-so-far 单调不降。
Experiment Skill记录 incumbent、成功 patch、失败原因、验证趋势和 avoid rules。它影响“arm 内怎么改”，不覆盖 Bandit 的标量证据。
Basin ceiling窗口 W 内 incumbent 平均改善率低于阈值 τ，视为局部盆地饱和。不是一次失败就跳，而是基于近期提升速度触发。
Jump + retuning开放结构级 arm；结构改动可先局部重调 R 轮，再与跳前 incumbent 比较。给高影响结构变化一个适应窗口，避免按首轮分数误杀。

3

UA-OPD：从漂亮假设到严谨否证

这一章最容易被追问。核心不是包装负结果，而是讲清楚为什么结论可信、发现了什么真实机制。

一句话：UA-OPD 用目标任务 Anchor 梯度衡量每个 Teacher-KL 轨迹片段的局部可蒸馏性，尝试修复失败 Teacher–Student 对；最终多波次实验表明，局部加权无显著收益，Cold-Start/SFT 引起的数据分布对齐才是关键。

3.1 OPD 为什么会失败

OPD 的基本流程

Student 自采样→Teacher 对 Student prefix 打分→token 级 KL / reward→更新 Student

失败对的本质

Teacher 更强不等于 Teacher 的局部 token 监督对当前 Student 可利用。同族、同尺度接近时，分布可能近似；Teacher 可以在 sequence level 区分好坏，却未必提供新的局部更新方向。

3.2 方法与一阶理论

片段 i 的 OPD loss 梯度：gᵢ = ∇ LOPD,i(θ)
目标任务 Anchor 梯度：gA = ∇ Lanchor(θ)
在片段 i 上更新：θ′ = θ − ηgᵢ

一阶展开：Lanchor(θ′) ≈ Lanchor(θ) − η · ⟨gA, gᵢ⟩
定义 Utilityᵢ = ⟨gA, gᵢ⟩。正值预计降低 Anchor loss，负值可能冲突。
边界：Utility 是当前 checkpoint 附近的一阶局部估计，不保证多步优化的全局收益；所以必须通过真实训练和独立评测验证，不能只看离线 utility。

3.3 五种加权模式

模式做法它回答什么问题
Vanilla原版 OPD，全量训练。UA 方法的主对照。
Random-50随机保留同等比例片段。收益是否只是减少 token / 正则化效应。
Hard正 utility 中选择 batch top 50%，权重 0/1。强筛选能否去掉冲突监督。
Soft轨迹内 median/MAD robust 标准化后 sigmoid 加权。连续权重是否比硬切更稳。
SoftTraj轨迹 utility 均值 → batch robust 标准化 → sigmoid → 均值归一为 1 → clamp[0,2]。预算中性地做轨迹间重新分配。

3.4 门禁验证：三个会把结论带偏的坑

错误门槛

0.118

192 样本 split-half cosine 仍仅 0.118；per-prompt 梯度在 probe 空间近正交，旧 0.5 门槛原理上不可达。后续改为 pool 规模硬门槛。

bf16 舍入

99.99%

ε=3e-4 时参数扰动几乎都是 no-op；bf16 ε≥0.03 才恢复可靠，正式实验使用 0.1。

方向稳定

≥24

至少 24 prompts 后 utility 排名稳定：Spearman ≥0.94，top50 overlap 0.92。

3.6 负结果真正带来的机制发现

风格迁移 ≠ 能力迁移

Base-init 的 A1/A3 中位响应膨胀到 31744 token，20-gram 重复率 0.95–0.99，distinct-1 仅 0.001–0.003。OPD 学到的是退化性循环，不是有效长推理。

Cold-Start 改变可学习分布

SFT 把正确率从 5.38 拉到 17.88，并显著减少循环与触顶；A2/A4 保持健康轨迹形态。局部加权无法从没有信号的循环中“筛出知识”。

最强表述：“我没有把无收益解释成实现失败。我们先修复门禁与精度问题，再用官方多轮协议、随机对照、独立种子和 Cold-Start 控制变量逐步锁定结论。最终否证的是‘局部重加权足以修复失败对’，并确认真正的控制变量在 Student 的初始数据分布与可恢复轨迹。”

5

高压问答库

先说结论，答案控制在 30–60 秒；老师继续追问时再展开公式和实现。

RecHarness

Q1：这不就是 AutoML / HPO 吗？创新在哪里？

结论：不是固定配置空间里的标量搜索，而是预算约束下的代码级模型迭代控制系统。

证据：arm 代表可解释的修改维度，LLM 在 arm 内生成不可枚举的代码 patch；Bandit 负责方向预算，Experiment Skill 负责文本经验，Jump 负责结构级跃迁。HPO 很难覆盖损失重写、pooling 改造、序列交互结构等开放修改。

边界：RecHarness 仍依赖人定义目标与 arm，不是无边界的通用自动科学家。

Q2：为什么 Thompson Sampling 比 UCB 或 ε-greedy 更合适？

这里 trial 贵、预算小、反馈二值且 arm 数有限。Thompson Sampling 用 Beta 后验自然表达不确定性，能在利用高成功率方向时保留对少样本 arm 的探索，并支持每轮采样 Top-G 并行执行。UCB 也可行，是后续消融方向；选择 TS 是因为实现简洁、概率匹配直观且适配小预算 Bernoulli 反馈。

Q3：把连续验证增益压成二值 reward，不会损失信息吗？

会损失幅度信息，这是设计取舍。二值化让不同模型、指标和 trial 尺度下的后验更新更稳；同时不是简单看 Δ>0，而是要求可执行、组内优于平均且不低于 incumbent。幅度信息仍保留在 validation trace 与 Experiment Skill 中，供 LLM 生成下一步假设。后续可研究 contextual/continuous reward bandit。

Q4：Memory 会不会把早期错误经验不断放大？

Memory 不直接改 Bandit posterior，也不决定 arm，只在 arm 被选后影响具体假设；标量验证证据与文本经验被刻意分离。失败经验以 avoid rules 记录，incumbent promotion 又要求真实验证提升。因此 Memory 能影响提案，但不能绕过验证。

Q5：为什么需要 Basin Jump？直接把结构 arm 一直放进 Bandit 不行吗？

结构 arm 成本更高、首轮分数可能因未适配而偏低。一直开放会浪费预算；永不开放又会困在局部最优。我们用窗口内 incumbent 改善率判断饱和，再开放 jump arm，并允许 R 轮 retuning 后再比较，兼顾成本与结构潜力。

Q6：47.92% 的提升是否可能来自更多试验或不同预算？

消融使用相同 GPU 时间预算、相同底模与四个并行 trial/round。47.92% 是 23/48 非基线 trial 相对 round-start best 的改善比例；Random 为 11/49。因预算近似一致，这个对比主要衡量路由效率，而不是试验数量优势。

Q7：线上收益如何归因于 RecHarness，而不是普通工程调参？

最终候选当然仍是具体模型结构，不是“Agent 本身”直接在线。归因链是：系统在同一人定义搜索空间中积累失败经验 → 判定局部瓶颈 → 路由到 sequence encoder upgrade → 从 Memory 中识别缺失的原始序列 item-item 交互 → 生成 Self-Attention+MLP 候选 → 离线 AUC 与线上指标同向验证。我们主张的是发现与试验配置效率，不夸大为完全无人干预。

Q8：为什么弱模型提升 85.85%，强模型只提升 12.58%？

弱基线通常存在更多显著结构和训练缺口，绝对可优化空间更大；强基线更接近局部上限，因此相对增益缩小。关键不是所有模型同幅提升，而是五类架构均提升，强 HSTU 仍有 12.58%，支持迁移性。

UA-OPD

Q9：UA-OPD 的核心创新和 GradAlign 有什么区别？

GradAlign 通常做问题级 RL/RLVR 数据选择；UA-OPD 面向 Teacher–Student 蒸馏，把 Student on-policy rollout 切成 256-token 局部片段，评估 Teacher-KL 梯度与目标任务 Anchor 梯度的对齐，研究的是“局部可蒸馏性”和失败 Teacher 修复。

Q10：Utility 正值为什么能说明有用？

一阶泰勒展开给出局部解释：对片段梯度下降一步后，Anchor loss 的变化近似为 -η⟨gA,gi⟩；内积为正时预计降低目标 loss。但它只是一阶、局部、单步估计，不能替代真实训练，所以最终结论以多臂训练和独立评测为准。

Q11：为什么用有限差分，不直接算每个片段梯度？

逐片段显式反传会带来很高的显存和计算开销。有限差分沿 Anchor 方向做两次扰动前向，可估计大量片段在该方向上的梯度投影。但 bf16 对扰动尺度敏感，因此我们专门做 epsilon 门禁并把 3e-4 修正为 0.1。

Q12：epsilon=0.1 会不会太大，破坏一阶近似？

epsilon 不是拍脑袋选的：bf16 下 3e-4 的 99.99% 参数扰动被舍入吞掉，ε≥0.03 后与可靠参考的 Spearman 才达到 0.95+；0.1 在可观测性与局部性间取了保守余量。仍需承认它是近似，最终由真实训练结果兜底。

Q13：split-half cosine 这么低，Anchor 梯度是不是根本不可信？

旧门槛确实不合理。诊断发现 per-prompt 梯度在 probe 空间近正交，split-half cosine 随样本数按几何规律增长，192 样本仍只有 0.118，所以 0.5 原理上不可达。更合适的判据是 utility 排名稳定性：≥24 prompts 后 Spearman≥0.94、top50 overlap 0.92。我们废弃了错误门槛，而不是硬调参数通过。

Q14：为什么需要 Random-50？

Hard 只训练一半片段，若没有 Random-50，就无法区分“utility 选择有效”与“少训练一半 token 带来的正则化/预算变化”。Random 保持同等保留比例，是识别 utility 信号增量的必要消融。

Q15：SoftTraj 为什么要均值归一到 1？

为了预算中性：不改变总 loss 质量和总体 token 权重，只在轨迹之间重新分配。否则任何变化都可能来自整体梯度尺度改变。MAD=0 时权重自动退化为全 1，也避免无区分信号时注入随机噪声。

Q16：Wave 2 看起来 Hard 比 Random 好，为什么后来又说无效？

Wave 2 是旧数据与单轮 avg@16，噪声约 2pt。用官方数据、3 轮×16 池化为 avg@48 后，Hard 40.62、Random 40.19，差值远小于 σ≈1.2pt，且排序不稳定。正确做法是以后者为主结论，并把 Wave 2 当作促使我们升级评测协议的阶段性证据。

Q17：负结果是否只是实验规模不够？

不能声称彻底排除小效应，但已通过多重证据收紧范围：官方 avg@48、五臂对照、独立 seed 的 train+eval 复合噪声约 0.38pt、Base-init 与 Cold-start 两种起点、三波一致。结论是“当前方法的收益小于可检测噪声，且不是主要控制变量”，而不是数学上证明永远无效。

Q18：既然 UA-OPD 没收益，这项工作价值在哪里？

价值有三层：第一，修正了 split-half 门槛、bf16 有限差分、评测完整性等会制造假结论的工程问题；第二，严格否证“局部加权足以修复失败对”；第三，用 Cold-Start 对照和轨迹分解定位真正机制：失败对缺少可恢复 on-policy 信号，OPD 主要诱导循环式风格迁移，SFT 数据分布对齐才制造可学习轨迹。

Q19：为什么 Cold-Start 有效而 Utility 加权无效？

Base-init 轨迹主要是错路或重复循环，没有可被局部重加权挽救的新知识；筛选只能在已有信号中重分配，不能凭空创造信号。SFT 直接改变 Student 的初始输出分布，减少循环、提高正确轨迹比例，使 Teacher 监督进入可利用区域，因此是更上游的控制变量。

Q20：A2 19.62 和 A4 19.44，能否说 Vanilla 优于 SoftTraj？

不能。差值仅 0.18pt，小于 avg@48 σ≈1.2pt，应说“统计不可区分，SoftTraj 无可测增益”。同样不能把 19.62 相对 SFT 17.88 直接说成确定收益，因为 SFT 当前是 avg@16、噪声更大，需同协议 avg@48 才能定论。

Q21：线上/评测中遇到过最危险的数据问题是什么？

A4 首轮评测曾因 vLLM worker OOM 导致样本静默丢失，续跑逻辑又把残缺文件当完整，制造了 macro 20.77 的假值。核对每题样本数后重跑完整三轮，修正为 19.44。沉淀是：完整性校验应成为评分前置门禁，不能只检查文件是否存在。

个人贡献与业务判断

Q22：这些工作里你个人最核心的贡献是什么？

按“问题—方法—落地”回答：我参与 RecHarness 的框架/实验/工业验证与论文沉淀；在 UA-OPD 中负责方法假设、加权策略、门禁诊断、训练评测链路、多机实验与负结果机制分析。不要只罗列代码文件，要强调你做出的关键判断与推进闭环。

Q23：如果再给两周，你优先做什么？

第一，统一 SFT 为 avg@48，彻底闭合 Cold-Start 后续增益口径；第二，在独立 validation pool 上验证 utility 排名泛化，而不是只看训练 batch；第三，把“是否存在可恢复轨迹”做成前置门禁，只有通过门禁才启用 segment weighting；RecHarness 侧则补 contextual/continuous bandit 与更严格线上长期指标。

Q24：你如何证明自己不是只会跑实验？

举三个“改变研究方向的判断”：把 LLM 自由搜索拆成 Bandit 路由与 arm 内生成；发现 split-half 0.5 门槛原理不可达而废弃；发现 20.77 是残缺样本假值并重建评测协议。共同点是从现象定位控制变量，并把判断固化为可复用机制。

术语速查

确保英文缩写第一次出现时能给出中文含义和本项目中的作用。

Incumbent

当前已验证的 best-so-far 实现；新候选只有超过它才晋升。

Edit Arm

可解释的优化方向，不是具体 patch；例如结构、损失、融合位置、训练策略。

Experiment Skill

由跨轮实验摘要形成的文本指南，记录成功经验、失败规则与趋势。

HR@10 / NDCG@10

Top-10 是否命中与考虑排名位置折损的推荐指标。

XAUC

跨用户/群体聚合的排序区分指标；越高越好。具体内部定义按业务口径。

OPD

On-Policy Distillation：Teacher 在 Student 当前实际访问的状态/prefix 上提供监督。

Anchor Gradient

目标任务验证信号在当前 Student 上诱导的更新方向。

MAD

Median Absolute Deviation，抗离群值的 robust 尺度估计。

avg@48

每题 16 次采样、3 个轮次合并，共 48 次采样的池化评测。
