04 · 真实实验路径

失败没有白跑，它们逐步缩小了解空间

这条路线的价值不在于“Agent 一次猜中”，而在于连续失败被组织成了能触发换路、也能被重新审判的证据链。

V1–?

表征侧：cross-attention / 独立属性通道 + gate

组合信息被现有 embedding 吸收，gate 未产生明显选择行为。

持平 · 边界确认
NISE

非点击样本 pseudo-label / entropy 正则

半监督熵占 CVR loss 绝大多数，真实点击监督被稀释。

未复现
IPS

1 / pCTR 逆倾向加权

clip=0.1 时大量样本权重撞到 10，退化为“点击 BCE 恒定 ×10”。

机制退化
DR

加入 imputation 塔预测残差

权重仍饱和；imputation 梯度还会反向污染共享 embedding。

AUC 掉点

归一化权重 + imputation 输入 stop-gradient

权重方差问题缓解，但 batch=512 下归一化后每样本权重几乎都等于 1。

05 · 模型原理

从 ESMM 到 ESCM²-DR-SNIPS

先用 ESMM 把 CVR 通过概率链外推到全曝光空间，再用反事实估计修正“只有点击样本能观测转化”的选择偏差。

pCTR曝光后点击概率
P(O=1|X)
×
pCVR点击后转化概率
P(Y=1|O=1,X)
=
pCTCVR曝光后转化概率
P(O=1,Y=1|X)
A · SNIPS

让权重自适应归一

IPS 用 1/pCTR 补偿低点击倾向样本，但方差高。SNIPS 再除以点击子集的权重均值，以少量偏差换取稳定方差。

w_raw = click / clip(pCTR)
w = w_raw / stop_grad(mean_clicked(w_raw))
B · DOUBLY ROBUST

给误差再配一个估计器

Imputation 塔预测 CVR-BCE 残差。倾向模型或误差模型任一较准，整体估计仍可保持稳健。

L_err = δ_hat + w·(BCE - δ_hat)
L_imp = (stop_grad(BCE) - δ_hat)²
C · STOP-GRADIENT

只读共享表征，不反向污染

Imputation 塔需要共享 embedding 作为输入，但其梯度与主 loss 同量级。切断输入反传，把双稳健性留在 loss 层。

imp_input = stop_gradient(shared_emb)
δ_hat = imp_tower(imp_input)

08 · 结果与解读

离线首次过 Base，线上预算分配更集中

上线结果不能只看“曝光下降”。需要结合消耗、预期花费、用户分层和 pCTCVR 分桶理解排序行为变化。

+0.3ppbatch 4096 后 CTCVR AUC
+0.3ppbatch 4096 后 CVR AUC
+0.975%AB 期货架整体消耗
+1.488%AB 期货架整体预期花费

曝光为何下降？

下降主要来自低价值用户层：U1、U2、U0-流失贡献约 74% 的整体曝光下降，U4+ 基本不动。更合理的解释是 CVR 精度提升后，eCPM 排序减少了低价值水量曝光。

为什么整体 P/COC 可能误导？

低 pCTCVR 桶校准改善明显但转化量权重很小；高桶占了大多数转化量，决定汇总指标方向。这是典型的分桶结构被总量加权淹没，需警惕合成谬误。

09 · 答辩式总结

这份 LR 的贡献，是把“模型优化”变成可持续搜索系统

Agent 的价值高吞吐跑变体、调研候选、组织证据，缩短从“无增量”到“下一方向表”的链路。
人的不可替代性发现 Agent 结论里的隐藏假设，重写问题，并对成本、风险和候选优先级做取舍。
Memory 的杠杆把失败从一次性成本变为边界证据，使跨周、跨版本迭代不会反复踩同一个坑。

最终范式：Agent 延伸路径，人切换路径，Memory 保存证据；模型收益是这套协作闭环的验证结果。
