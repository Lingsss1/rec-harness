2. Ranking：哪些神经元重要？

目的不是直接找“最佳架构”，而是把 neuron/module 按预计损失影响排序，缩小下一轮剪枝或扩容实验的范围。

2.1 梯度公式到底是什么

论文 Eq.1 里的梯度不是权重梯度 ∂L/∂W，而是损失对隐藏激活的梯度：

Ingrad = (1/|D|) Σx∈D | an · ∂L/∂an |

对当前的 sigmoid + BCE 模型，梯度可以完整化简：

①　∂L/∂s = p - y
②　s = Σn vnan + b　⇒　∂s/∂an = vn
③ 链式法则　∂L/∂an = (∂L/∂s)(∂s/∂an) = (p-y)vn
④ 重要性　In(x) = |an(p-y)vn|
为什么乘上 activation？只看梯度会把“非常敏感但当前根本没有被激活”的单元也排得很高。Taylor 展开告诉我们：若把激活从 a 删除到 0，变化量是 δ=-a，因此 loss 的一阶变化约为 -a·∂L/∂a。
L(a+δ) ≈ L(a) + (∂L/∂a)δ
删除神经元：δ=-a
|L(a→0)-L(a)| ≈ |a·∂L/∂a|

2.2 对权重的梯度又是什么

虽然 MISO 排名用的是 ∂L/∂a，反向传播还会继续经过 ReLU 到隐藏权重：

∂L/∂zn = (∂L/∂an) · 1[zn>0]
∂L/∂Wn,j = (∂L/∂zn) · xj
∂L/∂bh,n = ∂L/∂zn

所以隐藏神经元 h₃ 即使有非零 ∂L/∂a₃，如果它的 pre-activation z₃≤0，ReLU 会让 ∂L/∂z₃=0，本样本不会更新 h₃ 的输入权重。

2.5 PyTorch 怎么拿到这个梯度

saved = {} def forward_hook(module, inputs, output): saved["activation"] = output.detach() output.register_hook( lambda grad: saved.__setitem__("gradient", grad.detach()) ) handle = target_module.register_forward_hook(forward_hook) model.eval() # 关闭 dropout，但不能 torch.no_grad() logits = model(features) loss = bce_with_logits(logits, labels) loss.backward() a = saved["activation"].reshape(-1, hidden_dim) g = saved["gradient"].reshape(-1, hidden_dim) score = (a * g).abs().mean(dim=0)
Ranking 能诊断和不能诊断什么

能：低价值单元、主要承载预测的模块、重要性集中位置、优先剪枝/扩容候选。

不能直接：扩容后的重训收益、相关神经元的独立因果贡献、跨模型宽度的公平 raw-score 比较。

3. Alignment：内部状态是否偏离参考？

Ranking 问“谁重要”，Alignment 问“它工作得是否像我们预期”。论文把 normalization 前后的经验分布与标准正态比较，用于发现不稳定 normalization 或 representation module。

Align(l) = 1 - ½ [ DKL(pprel || N(0,1)) + DKL(ppostl || N(0,1)) ]

3.1 KL 在测量什么

DKL(p||q) = ∫ p(z) log[p(z)/q(z)] dz
直方图估计： DKL ≈ Σi pi log(pi/qi)

KL 非负，两个分布相同才为 0。从信息论看，它是数据来自 p 时却用 q 编码所付出的额外期望信息量。这里作者把它当作“偏离参考状态”的诊断量。

3.2 先用高斯近似把公式算懂

如果把一层的激活近似为 N(μ,σ²)，相对标准正态的 KL 有闭式解：

DKL(N(μ,σ²)||N(0,1)) = ½( μ² + σ² - 1 - log σ² )

交互实验：拖动 normalization 前后统计

曲线和 KL/Alignment 会即时更新。默认值对应文中讲解示例。

3.3 实际实现：抓 normalization 的输入和输出

stats = {} def norm_hook(name): def hook(module, inputs, output): pre = inputs[0].detach() post = output.detach() stats[name].update(pre, post) # 在线累计 histogram 或 mean/variance return hook for name, module in model.named_modules(): if isinstance(module, (nn.BatchNorm1d, nn.LayerNorm)): module.register_forward_hook(norm_hook(name))

若按论文的“经验分布”实现，应该使用固定 bins：所有层共享相同边界，例如 [-8,8] 的 201 个区间。qᵢ 应是标准正态 CDF 在区间两端之差，而不是只取中心点 pdf。

理论依据只支持“分布偏离”，不支持“越高斯越好”LayerNorm 只约束每个样本在 feature 轴上的均值和方差；RMSNorm 连零均值都不保证。论文同时要求 pre/post 接近 N(0,1) 缺乏普适理论。因此更可信的扩展是比较健康 checkpoint 的经验分布，而不是强制标准正态。
Alignment 能诊断和不能诊断什么

能：均值/方差漂移、重尾或异常值、normalization 前后状态异常、最值得检查的 norm block。

不能直接：表示语义质量、最终 NE、某种 normalization 替换一定有效。并且 Alignment 可小于 0，它不是概率。

4. Comparison：两个模型从哪里开始不同？

论文没有给 Comparison 的固定公式。它是一类跨模型、跨层或跨训练阶段对照内部状态的操作。最重要的是使用同一批样本并逐层对齐。

构造一个最小可审计的 layer signature：

signaturel = [mean, std, q01, q50, q99, RMS, zero_fraction, grad_norm, histogram]

例如定义：

Cl = |μA,l-μB,l| / σpool,l
　　+ |log σA,l - log σB,l|
　　+ JS(histA,l, histB,l)

交互实验：模型 B 的第 3 层发生漂移

拖动 layer 3 drift。下游 layer 4 也会被放大影响，但“第一个明显跳变层”通常比“最大差异层”更值得先检查。

为什么它有理论合理性

对确定性前馈网络，如果两个模型在相同输入下前两层状态接近，而从第 3 层开始系统性分离，那么差异来源很可能位于第 3 层或其紧邻上游。这个思想类似 change-point localization 和 representation drift analysis。

但最大 divergence 不等于根因：上游很小的改变可能被下游放大。因此需要介入验证：

  1. 把好模型的第 3 层 module 暂时换入坏模型；
  2. 或对第 3 层做 activation patching；
  3. 观察输出差异和 loss gap 是否明显缩小。
for batch in fixed_calibration_loader: states_a = collect_same_named_layers(model_a, batch) states_b = collect_same_named_layers(model_b, batch) for layer in common_layers: sig_a = summarize(states_a[layer]) sig_b = summarize(states_b[layer]) divergence[layer] = distance(sig_a, sig_b) candidate = first_stable_divergence_jump(divergence) validate_with_module_swap_or_activation_patch(candidate)
Comparison 能诊断和不能诊断什么

能：版本差异集中位置、训练漂移开始层、相邻架构最值得做介入的模块。

不能直接：证明最大差异层就是根因；也不能在不同宽度模型间未经对齐直接逐 neuron 比较。

6. 你复现时应该按什么顺序做

  1. 先把上面的三神经元模型跑通。用 autograd 得到的 ∂L/∂a 必须与手算 (p-y)v 一致。
  2. 再接真实 CTR baseline。先只选 3-5 个 MLP/interaction module，不要 hook 全模型。
  3. 验证 Ranking 是否真的预测编辑收益。逐个扩容/剪枝，画 MIS score 与重训 ΔNE 的 Spearman 相关。
  4. Alignment 做两套。一套严格使用论文 N(0,1)；一套使用健康 checkpoint reference，分开报告。
  5. 明确写出 Comparison 公式。论文没给定义，所以你的距离、阈值、层对齐方式必须进入实验协议。
  6. 最后才做闭环。冻结动作空间、Top-k、预算和停止条件，避免人工看完信号后临时挑动作。
