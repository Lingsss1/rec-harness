论文精讲 · 理论基础 01

Pruning CNNs for Resource Efficient Inference

Molchanov et al.，ICLR 2017｜一句话：用 Activation × Gradient 近似“把一个通道删掉会让损失变多少”，从而低成本排序。

Taylor 一阶近似结构化剪枝梯度敏感性来源

1. 它真正解决的问题

卷积网络有大量通道。逐个把通道置零并跑完整验证集，能得到最可信的消融重要性，但成本是“通道数 × 推理成本”。论文寻找一个在反向传播中顺手得到的代理分数，用于贪心地删掉影响最小的 feature map。

已训练模型→梯度打分→删低分通道→微调→循环

2. 核心推导：为什么是 Activation × Gradient

定义干预。某个通道激活向量为 z，把该通道删除等价于 z → 0，因此扰动 δz = −z。
对当前点做一阶 Taylor 展开。
L(z + δz) ≈ L(z) + ∇zL · δz δz = −z ⇒ ΔL = L(0) − L(z) ≈ − ∑m=1M (∂L/∂zm) zm
变成可比较分数。忽略方向、对空间位置和样本聚合：
S(z) = | (1/M) ∑m=1M zm · ∂L/∂zm |

M 可包含 batch 与空间位置。z 表示该位置“存在了多少”，梯度表示“损失对它的局部斜率”；两者乘积是把它推到 0 时的一阶损失变化。

关键边界：梯度不是“真实因果重要性”，而是当前样本、当前参数点附近的局部导数。它之所以有用，是因为目标干预明确（置零），Taylor 展开给出了可检验的近似；不是因为“梯度天然等于重要性”。

3. 论文提供了什么证据

排序证据

论文将 Taylor 准则与随机、权重大小、平均激活、APoZ 等通道准则比较，并通过逐步剪枝后的精度/损失表现检验排序质量。

端到端证据

在 AlexNet、VGG-16 和 3D CNN 等架构/任务上，交替执行剪枝与微调，展示 FLOPs、实际延迟与准确率之间的权衡；也包含迁移学习场景。

不能外推的部分

这是 CNN 通道剪枝证据，不直接证明推荐模型任意内部神经元、任意 shuffle 干预都可靠。可迁移的是 Taylor 打分逻辑，不是原实验结论。

4. 工程实现

# 诊断阶段，不更新参数也可以
model.eval()                 # 固定 dropout / BN 统计
scores = zeros(num_units)
for batch in diagnostic_loader:
    logits, activation = model.forward_with_hook(batch, target_module)
    activation.retain_grad()
    loss = task_loss(logits, batch.label)
    model.zero_grad(set_to_none=True)
    loss.backward()
    # 保留符号后先在 unit 内求和，再取绝对值；避免位置级绝对值改变定义
    batch_score = abs((activation * activation.grad).sum(sample_and_token_axes))
    scores += batch_score
scores /= number_of_samples
实现决策建议
对谁求梯度对模块输出 activation，而非只对权重；它更贴近“移除该表示”的干预。
目标标量推荐用线上一致的总 loss，同时另报各任务 loss，避免多任务权重掩盖。
跨层比较报告 raw score 与层内 percentile；跨层尺度可能受归一化和重参数化影响。
样本固定时间窗、分桶采样，多批次均值并给 bootstrap 置信区间。

5. 与“梯度粗筛 + Shuffle 验证”的关系

梯度负责搜索效率：一次反传同时给成千上万个单元打分，适合从 25M Dense 参数的复杂精排网络中找候选模块。

Shuffle 负责干预验证：一阶近似可能因非线性、饱和、单元交互失真。对候选模块执行配对 shuffle，直接测 AUC/LogLoss/任务指标变化，可以淘汰梯度假阳性。

推荐闭环：梯度 Top-K → 与随机/低分/同层对照做 shuffle → 多 seed 重复 → 只把稳定显著的模块称为“模型依赖”，不要直接称为根因。

6. 局限与失败模式

  • 局部线性：置零是大扰动，跨过 ReLU/门控边界时一阶近似会偏。
  • 梯度饱和：预测很确信时梯度小，但表示仍可能关键。
  • 冗余与交互：单元单独低分不等于成组不重要；多个替代通路会藏住作用。
  • 重参数化：功能相同的网络可因激活尺度不同得到不同 raw score。
  • 训练目标不等于业务指标：对 loss 敏感不必然对 GAUC、时长或收入敏感。

7. Leader 尖锐问答

Q1：为什么梯度能代表重要性？

因为我们先定义了明确干预 z→0，再用 Taylor 展开近似这次干预的损失变化，得到 z·∂L/∂z。它是有数学来源的局部代理，不是绝对真值。

Q2：既然有梯度，为什么还要 Shuffle？

梯度只看局部斜率；shuffle 是实际前向干预，能暴露非线性、饱和和交互导致的排序错误。前者低成本粗筛，后者高成本验真。

Q3：为什么不是直接逐个置零？

全量逐个消融最直观，但模块数大时成本线性爆炸，而且置零本身可能是训练分布外。先粗筛可把干预次数压到 Top-K。

Q4：高分模块是不是就该扩容？

不是。高分只说明当前模型/数据依赖它。可能是有效容量，也可能是错误捷径或上游尺度异常；要结合 shuffle、分桶指标和结构证据决定扩容、修特征还是正则化。

Q5：论文是视觉剪枝，凭什么用于推荐？

可迁移的是对任意可微中间表示成立的 Taylor 推导。任务有效性必须在推荐 Base 上重新验证，尤其对 embedding、序列模块和多任务梯度分别做校准。

Q6：怎样证明分数稳定？

固定 checkpoint，在多个独立 batch/时间片计算 rank correlation、Top-K overlap 和 bootstrap CI；再检查不同 loss、不同 seed 下结论是否一致。
