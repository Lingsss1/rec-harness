1. 先用一句话理解整个模型

QFormerCross11 先用 8 个可学习 Query 压缩用户上下文与目标商品字段，再让同一组 Query 去读取最长 100 步的行为序列；最终把 8×256 展平后送入单任务 MLP，预测 high_watch。

01

字段压缩

不同稀疏字段先独立 Embedding、投影为统一 256 维 Token，再由少量 Query 主动聚合。

02

序列条件化

字段 Query 作为用户—目标状态，Cross-Attention 只取回与当前状态相关的历史行为。

03

固定瓶颈

无论字段数和历史长度如何，塔的输入固定为 8×256，计算量与下游接口稳定。

3. 像 Transformer 一样拆开一个 QFormerCross11 Layer

一层只有一条不断更新的 Query 主干。它依次经过 Self-Attention、CrossValue Attention 和 FFN；每个子层都带 Residual + LayerNorm。原始字段或序列 (X) 从侧面进入 CrossValue，只提供 K/V，不在层间被覆盖。

4. CrossValue：不只“看哪里”，还显式构造乘性交互

普通 Cross-Attention 返回 Value 的加权和；这里再把“当前 Query 的交互投影”与“取回的特征”逐元素相乘，使每个 Query—特征对产生显式条件交互。

q = Wq(Q) k = Wk(X) A = softmax(qkᵀ / √d_head / T + mask) F = A · Wfi(X) # 注意力取回的字段/行为摘要 I = Wqi(Q) ⊙ F # Query 与摘要逐元素相乘 CrossValue(Q,X) = Wo(Wpair(I))

Attention 负责路由

Wq/Wk 决定当前 Query 应该读取哪些字段或哪些历史事件，解决“从哪里取信息”。

Hadamard Product 负责交互

Wqi(Q) ⊙ F 让相同历史特征在不同 Query 状态下产生不同响应，解决“取回后如何与当前目标交叉”。

配置中 token_dim=256、num_heads=4，因此每个 Head 的维度是 64，缩放项为 (1/sqrt{64}=1/8)。默认还对每个 Head 的 Q/K 做 LayerNorm，以稳定注意力 logits。

5. 第一阶段：8 个 Query 压缩非序列字段

QFormerCross11 复用 V10 的 NonRecursiveCrossValueStage。Learnable Query 先被当前样本的字段均值条件化，然后连续经过 2 个完整 Transformer 式层。

c = LayerNorm(Wcontext · masked_mean(Xfield)) Q₀ = LayerNorm(Qlearnable + c) for l = 1..2: Q′ = LayerNorm(Q + SelfAttention(Q)) Q″ = LayerNorm(Q′ + CrossValue(Q′, Xfield)) Q = LayerNorm(Q″ + FFN(Q″))
Self-Attention8 个 Query 之间交换信息，减少槽位重复。
→
CrossValue每个 Query 从固定字段 Token 中读取并交叉。
→
FFN256 → 1024 → 256，逐 Query 做非线性变换。
为什么先用字段均值条件化 Learnable Query？纯共享 Query 对所有用户从同一起点出发；加上当前样本的 pooled context 后，第一次 Self-Attention 之前就知道“这是谁、目标是什么”，更容易形成样本相关的读取策略。

6. 第二阶段：字段 Query 带着目标，读取原始行为序列

第一阶段输出直接成为第二阶段的 Query。QFormerCross11 的核心约束是：层间只传播 Query，行为 Token 流 (S) 始终保持为进入该阶段时的原始值。

Q⁰ = Qfield S = sequence_tokens for l = 1..3: Q′ = LayerNorm(Qˡ + SelfAttention(Qˡ)) Q″ = LayerNorm(Q′ + CrossValue(Q′, K=S, V=S)) Qˡ⁺¹ = LayerNorm(Q″ + FFN(Q″)) S 在三层中从不被覆盖；只有 Q 持续演化。

稳定证据源

每一层都能重新访问同一份未经递归改写的行为证据，避免后层只能看到前层压缩后的中间表示。

逐层改变问题

虽然 K/V 固定，Query 已吸收前层结果，所以后层实际用“更新后的问题”再次读取原始历史。

Original-X 不等于每层输出相同固定的是证据流 K/V，不是 Query。Self-Attention、CrossValue 和 FFN 都会更新 Query，因此三层仍然具有不同的读取分布与交互结果。

8. 为什么代码包同时带 V8、V10、V11？

不是三个并行主模型，而是一条结构演进链。QFormerCross11 继承 V8 的完整输入、路由和 Tower，只替换两类 QFormer Stage。

QFormerCross8对称递归 CrossValue多次 CrossValue
→ 最后一次 Self-Attn
→ 最后一次 FFN

强调逐层残差交叉、延后 Query 混合。它提供完整模型骨架。

QFormerCross10只恢复字段阶段的标准层顺序字段：Self → Cross → FFN
序列：保留 V8 递归

验证非序列字段是否更适合逐层完整处理。

QFormerCross11当前 KuaiRec 焦点模型字段：Self → Cross → FFN
序列：Self → Cross → FFN

两阶段都固定原始 K/V，只让 Query 在层间演化。

“NonRecursive”容易误读它不是没有层间递归：(Q_{l+1}) 仍依赖 (Q_l)。它表示不再使用 V8 那种只堆叠 CrossValue 的显式高阶递推，而是恢复每层完整的 Self-Attention、CrossValue 与 FFN。

11. 阅读这份实现时，最容易说过头的四件事

Q1：关掉 Q3 后 AUC 更高，能否证明它是“坏 Query”？
只能说明在这个固定 Checkpoint、固定验证协议下，Q3 输出对最终打分产生了负贡献或冗余贡献。它可能与其他 Query 重复、与 Tower 权重失配，也可能在别的随机种子或重训练后重新有用。
Q2：Original-X 一定比更新 K/V 更好吗？
不能普遍断言。它提供稳定、可重复访问的原始证据流，但也限制了源 Token 自身的层级变换。当前证据只支持它在记录的 KuaiRec 实验中形成更强 Incumbent。
Q3：8 个 Query 是否各自对应一种可解释兴趣？
没有离散语义约束，编号本身没有含义。要给 Query 命名，至少需要注意力分布、Activation×Gradient、Shuffle/Zero 与跨样本稳定性证据。
Q4：固定 Checkpoint 上的 Query 路由能否替代重训练？
不能。路由干预回答“当前模型依赖什么”；从头改变 Query 数量或结构后训练，才回答“新结构是否能达到更好的最优点”。
最准确的模型总结QFormerCross11 是一个以 latent queries 为信息瓶颈的两阶段推荐编码器：第一阶段形成用户—目标条件，第二阶段以该条件读取原始行为证据；CrossValue 用注意力选择与乘性交互结合建模条件关系，最终由 Query 路由和 MLP 完成高观看预测。
